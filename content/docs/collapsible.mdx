## Reveal optional details

```tsx
<Collapsible defaultOpen>
  <CollapsibleTrigger>Advanced options</CollapsibleTrigger>
  <CollapsibleContent>Keep the useful details close.</CollapsibleContent>
</Collapsible>
```

Collapsible is native `details`, Trigger its direct-child `summary`, and
Content a `div`. Enter, Space and pointer activation toggle the summary. Keep
a descriptive trigger and visible focus; do not put buttons or links inside it.
The marker is decorative.

Content stays mounted. Closing hides it from keyboard navigation without
clearing values or disabling form fields. Closed fields still contribute to
FormData. Native form reset restores uncontrolled inputs, without changing
disclosure state.

## Own state once

```tsx
const [open, setOpen] = useState(false)

<Collapsible open={open} onOpenChange={setOpen}>
  <CollapsibleTrigger>Reading notes</CollapsibleTrigger>
  <CollapsibleContent>Saved for later.</CollapsibleContent>
</Collapsible>
```

Choose controlled `open` or initial `defaultOpen`; never combine them or change
ownership during a mount. Write state through `onOpenChange`. `onToggle`
observes native events, including synchronization; it is not a second state
writer. An owner may decline a change. No-op requests do not notify.

At hydration, uncontrolled state adopts the native open state and calls
`onOpenChange` if it changed. Controlled `open` restores its value silently.
`onToggle` is not replayed for an earlier event.

A shared native `name` creates an exclusive group. Nested disclosures do not
toggle parents. Use [Accordion](/docs/accordion/) for a shared selection owner
and disabled items. Collapsible has no native disabled prop or Button render API.

## Add motion and dynamic content

```tsx
import { MotionProvider } from '@cognitap/radiant/motion/react'

;<MotionProvider>
  <Collapsible motion="inherit">
    <CollapsibleTrigger>Details</CollapsibleTrigger>
    <CollapsibleContent>{details}</CollapsibleContent>
  </Collapsible>
</MotionProvider>
```

The provider springs natural height. Content keeps its size; rapid reversals
retarget the current spring. Local `motion="off"`, theme off and live reduced
motion settle height and marker feedback. Native open/closed semantics stay
immediate. Before hydration, native details owns visibility.

Keep one Content wrapper in normal flow. Resize observation follows its
children, wrapping text, images and replacements. Avoid absolute positioning,
transforms and percentage heights that depend on the animated container.
The height enhancement needs `::details-content`; unsupported browsers retain
native disclosure behavior. Without JavaScript, native details still works;
application controls require hydration. See [motion setup](/docs/foundations/motion/).

## Parts and customization

| Component   | Native style/ref target | Identity              |
| ----------- | ----------------------- | --------------------- |
| Collapsible | `details`               | `collapsible`         |
| Trigger     | `summary`               | `collapsible-trigger` |
| Content     | `div`                   | `collapsible-content` |

Parts accept native props, className, typed theme style and real DOM refs.
Identities are additive `data-slot` tokens; states use `data-state="open|closed"`.
Content keeps its generated ID. Set `--rad-collapsible-padding` on the root for
local spacing. Preserve native composition and hidden-content behavior.
`useCollapsible()` returns the nearest state and `setOpen`, or null outside one.
When a content action collapses itself, return focus to the summary.

## Public props

Each named part's prop type and `CollapsibleState` are exported.

| Collapsible prop            | Purpose / default                                            |
| --------------------------- | ------------------------------------------------------------ |
| `open` / `defaultOpen`      | Controlled state or initial local state; initially closed    |
| `onOpenChange`              | Receives the next boolean change request                     |
| `onToggle`                  | Native details event observation                             |
| `className`, `style`, `ref` | Customization and ref on the native details                  |
| `data-slot`                 | Additional identity tokens; retains the base token           |
| `motion`                    | `inherit` (default) or `off`; height and marker presentation |
| Other native props          | Remaining details attributes/events and children             |

Use [Accordion](/docs/accordion/) for shared selection and disabled items, or
[Dialog](/docs/dialog/) for a modal task.
