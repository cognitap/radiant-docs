## Usage

Collapsible renders native `details` and `summary`, so it opens and closes before JavaScript loads, and a shared `name` groups disclosures natively. Use [Accordion](/docs/accordion/) for a set of related sections, [Tabs](/docs/tabs/) to switch between peer panels, and [Dialog](/docs/dialog/) or [Popover](/docs/popover/) for content that overlays the page.

```tsx
<Collapsible>
  <CollapsibleTrigger>Shipping details</CollapsibleTrigger>
  <CollapsibleContent>Standard delivery in two days.</CollapsibleContent>
</Collapsible>
```

## State

Use `defaultOpen`, or `open` with `onOpenChange`. Passing both is a type error, and switching owners after mount throws. `onOpenChange` fires only for requests from the user or `setOpen`; a controlled owner can refuse one by keeping `open`. `onToggle` observes the native event. Use `onOpenChange` to write state. A toggle made before hydration is kept when uncontrolled and restored to `open` when controlled.

```tsx
const [open, setOpen] = useState(false)

<Collapsible open={open} onOpenChange={setOpen}>…</Collapsible>
```

Closed content stays mounted, so its fields keep their values and still submit. Collapsible submits nothing itself, and form reset leaves the open state unchanged.

`useCollapsible()` returns `{ open, contentId, setOpen }` inside a Collapsible and `null` outside. When an action in the content closes the panel, move focus back to the summary.

## Accessibility

The summary is the control and announces expanded or collapsed. Its text is its accessible name. Keep one CollapsibleTrigger as a direct child, and put buttons and links in the content, not the trigger. Closed content is skipped by reading and focus.

| Key   | Behavior                                     |
| ----- | -------------------------------------------- |
| Tab   | Moves to the summary, then into open content |
| Enter | Toggles the focused summary                  |
| Space | Toggles the focused summary                  |

## Motion

Content height animates between closed and its natural height, springing under a [MotionProvider](/docs/foundations/motion/). The chevron rotates 90 degrees. Open state changes at once; motion never delays it. Turn motion off with `motion="off"`, a theme motion mode of `off`, or the reduced-motion preference. Set the duration with `--rad-collapsible-duration`.

## Styling

`className`, `style` and `ref` reach each part's host. A caller `data-slot` adds to the built-in token, so select with `[data-slot~=collapsible]`.

| Part               | Host      | `data-slot`           | Data attributes              |
| ------------------ | --------- | --------------------- | ---------------------------- |
| Collapsible        | `details` | `collapsible`         | `data-state="open\|closed"`  |
| CollapsibleTrigger | `summary` | `collapsible-trigger` | `data-state`                 |
| CollapsibleContent | `div`     | `collapsible-content` | `data-state`, generated `id` |

`--rad-collapsible-*` tokens cover gap, radius, corner shape, border, background, color, padding, focus ring, content color and size, and duration.

## API

### Collapsible

| Prop              | Type                                       | Default |
| ----------------- | ------------------------------------------ | ------- |
| open              | boolean; controlled state                  | None    |
| defaultOpen       | boolean; uncontrolled initial state        | false   |
| onOpenChange      | (open: boolean) => void                    | None    |
| onToggle          | (event: ToggleEvent) => void; native event | None    |
| name              | string; native exclusive group             | None    |
| motion            | inherit / off                              | inherit |
| className / style | string / ThemeStyle                        | None    |
| ref               | `Ref<HTMLDetailsElement>`                  | None    |
| Other props       | Native details props                       | Native  |

### CollapsibleTrigger

| Prop              | Type                              | Default  |
| ----------------- | --------------------------------- | -------- |
| children          | ReactNode; visible label and name | Required |
| className / style | string / ThemeStyle               | None     |
| ref               | `Ref<HTMLElement>`                | None     |
| Other props       | Native summary props              | Native   |

### CollapsibleContent

| Prop              | Type                                  | Default |
| ----------------- | ------------------------------------- | ------- |
| children          | ReactNode; stays mounted while closed | None    |
| className / style | string / ThemeStyle                   | None    |
| ref               | `Ref<HTMLDivElement>`                 | None    |
| Other props       | Native div props; `id` is replaced    | Native  |
