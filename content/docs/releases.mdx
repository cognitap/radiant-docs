Radiant is experimental. The version badge in this site's header identifies the
installed package used by its build, and the dependency is pinned explicitly.

## Radiant 0.0.3

This release includes the harmonised ten-family system: Button, Link, Field,
Input, Checkbox, RadioGroup, Dialog, Collapsible, Accordion and Card. It also
ships the shared `ThemeScope` API and eight presets.

The site currently demonstrates [Button](/docs/button/) and complete
[profile form recipes](/docs/recipes/profile-form/). More component pages can
be added as the catalog is documented.

## Upgrade from 0.0.2

Version 0.0.2 was the earlier Button-only package. Version 0.0.3 includes
breaking changes to action props, composition and themes. Check the
[library changelog](https://github.com/cognitap/radiant/blob/main/CHANGELOG.md)
and migration guidance before changing your application's pin.

## Preview a library change

The docs repository can explicitly preview a packed local package. Those builds
show a **Local candidate** label and may contain unpublished APIs. Public builds
use the exact released dependency pin; a local candidate is not a release.
