Radiant is experimental. The header identifies the exact installed package used
by this site. Keep package JavaScript and CSS on the same version.

## Latest release

The current release changes class merging and the compiled stylesheet. A size, width, style or font-family utility needs a [type hint](/docs/foundations/composition/#functional-css). `styles.css` no longer defines unused utilities such as `container` or `hidden`, and it no longer sets Tailwind's `--spacing`. See [installation](/docs/getting-started/#choose-a-styling-route).

Combobox, Autocomplete and MultiSelect lists hide when an ancestor dialog or popover closes. A timed Toast pauses while a touch is held. A segmented ToggleGroup indicator follows an ancestor `dir` change. Prose list padding, `pre` scrolling and inline code skip `data-rad-not-prose` and `data-slot`.
See the [release notes](https://github.com/cognitap/radiant/releases/tag/v0.0.79).

## Upgrade existing themes

Example themes live at `@cognitap/radiant/examples`, and the core entry
retains `defaultTheme`. `expressive` was removed; start from `soft` or `jelly`.
A theme that set Button's shadows, fonts or press motion under
`components.button` can move them to the `control.action` and `motion` roles,
so every family follows.

Motion uses explicit entrypoints and dedicated layout slots/parts. Review the
[motion guide](/docs/foundations/motion/) before adopting layout animation.
Custom fonts remain application-owned. Earlier themes may need to adopt
[typography roles](https://github.com/cognitap/radiant/blob/v0.0.5/docs/theming.md#component-roles-and-earlier-themes),
which can change wrapping and layout.

For older Button-only integrations, consult the
[theme migration](https://github.com/cognitap/radiant/blob/v0.0.3/docs/theming.md#migration-from-button-centred-themes)
and [release history](https://github.com/cognitap/radiant/releases).

## Preview a library change

Packed local packages show a **Local candidate** label and can contain
unpublished APIs. Public builds use the exact released dependency pin;
a local candidate is not a release.
