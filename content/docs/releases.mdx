Radiant is experimental. The header identifies the exact installed package used
by this site. Keep package JavaScript and CSS on the same version.

## Latest release

The current release adds [ScrollArea](/docs/scroll-area/) with themed bars and native wheel, touch and keyboard scrolling.
See the [release notes](https://github.com/cognitap/radiant/releases/tag/v0.0.32).

## Upgrade existing themes

Example themes live at `@cognitap/radiant/examples`. Move imports of `themes`,
`radiant`, `soft`, `expressive`, `glass`, `sharp`, `jelly` and `ticket` there;
the theme definitions are unchanged. The core entry retains `defaultTheme`.

Motion uses explicit entrypoints and dedicated layout slots/parts. Review the
[motion guide](/docs/foundations/motion/) before adopting layout animation.
Custom fonts remain application-owned. Earlier themes may need to adopt
[typography roles](https://github.com/cognitap/radiant/blob/v0.0.5/docs/theming.md#component-roles-and-earlier-themes),
which can change wrapping and layout.

For older Button-only integrations, consult the
[theme migration](https://github.com/cognitap/radiant/blob/v0.0.3/docs/theming.md#migration-from-button-centred-themes)
and [release history](https://github.com/cognitap/radiant/releases).

## Preview a library change

Packed local packages show a **Local candidate** label and can contain
unpublished APIs. Public builds use the exact released dependency pin;
a local candidate is not a release.
