## Usage

Use Stage around a widget your app builds, such as a map, an editor or a canvas, so it gets the same frame as Radiant's own surfaces. StageActions holds controls beside the title, StageBody holds the widget, and StageFooter holds whatever follows it. Stage gives none of them a meaning. Use [Card](/docs/card/) for static content about one subject and [AspectRatio](/docs/aspect-ratio/) for media without a frame.

```tsx
<Stage>
  <StageHeader>
    <StageTitle>Route map</StageTitle>
    <StageDescription>Station to lake.</StageDescription>
    <StageActions>
      <Button onClick={zoomIn}>Zoom in</Button>
    </StageActions>
  </StageHeader>
  <StageBody aspectRatio={3 / 2}>
    <RouteMap />
  </StageBody>
  <StageFooter>
    <Button onClick={share}>Share route</Button>
  </StageFooter>
</Stage>
```

### Hold the body while content streams

## Accessibility

Stage is a `<div>` with no role. To make it a landmark, pass `role="region"` and `aria-labelledby` with the StageTitle `id`. StageTitle renders a heading, `h2` by default; choose `level` to fit the page outline. Set `aria-busy` on StageBody while its content loads. Reading and focus order follow the source order at every width.

## Motion

Stage, StageTitle and StageDescription transition color, background and border over `--rad-motion-color-duration`. Reduced motion removes the transition.

## Styling

Stage is a size container, so its parts follow the Stage's width, not the viewport. Below 30rem, the actions sit under the description and footer items stack at full width. From 30rem, the actions sit beside the title and footer items share a wrapping row.

| Part             | Element                                     | data-slot                               |
| ---------------- | ------------------------------------------- | --------------------------------------- |
| Stage            | `div`, grid, size container named `stage`   | `stage`                                 |
| StageHeader      | `div`, grid                                 | `stage-header`                          |
| StageTitle       | `h1`–`h6` by `level`                        | `stage-title`                           |
| StageDescription | `p`                                         | `stage-description`                     |
| StageActions     | `div`, wrapping row                         | `stage-actions`                         |
| StageBody        | `div`, grid; AspectRatio with `aspectRatio` | `stage-body`, `aspect-ratio stage-body` |
| StageFooter      | `div`, column, then wrapping row            | `stage-footer`                          |

Caller classes win, and a caller `data-slot` adds tokens after the part's own. `components.stage` or `--rad-stage-*` variables set radius, background, color, border, shadow, padding, gap, header-gap, actions-gap, footer-gap, title-size, title-weight and description-color. Gaps fall back to the spacing scale and padding to the surface padding. Forced colors use system canvas and text colors and drop the shadow.

## API

Every part takes the native props of its element, `className`, `style` as ThemeStyle, additive `data-slot` and a ref.

| Stage prop | Type                  | Default |
| ---------- | --------------------- | ------- |
| padding    | tight / normal / airy | normal  |
| ref        | `Ref<HTMLDivElement>` | None    |

| StageTitle prop | Type                      | Default |
| --------------- | ------------------------- | ------- |
| level           | 1 / 2 / 3 / 4 / 5 / 6     | 2       |
| ref             | `Ref<HTMLHeadingElement>` | None    |

| StageBody prop | Type                   | Default |
| -------------- | ---------------------- | ------- |
| aspectRatio    | number, width ÷ height | None    |
| ref            | `Ref<HTMLDivElement>`  | None    |

StageHeader, StageActions and StageFooter take `Ref<HTMLDivElement>`; StageDescription takes `Ref<HTMLParagraphElement>`. `aspectRatio` must be finite and greater than zero.

Exports: `Stage`, `StageHeader`, `StageTitle`, `StageDescription`, `StageActions`, `StageBody`, `StageFooter`; types `StageProps`, `StageHeaderProps`, `StageTitleProps`, `StageDescriptionProps`, `StageActionsProps`, `StageBodyProps`, `StageFooterProps`, `StageHeadingLevel`.
