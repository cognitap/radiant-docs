## Usage

Use Stage around a widget your app builds, such as a map or a canvas, so it gets the frame Radiant's own surfaces use. Stage gives the actions, body and footer no meaning. Use [Card](/docs/card/) for static content about one subject and [AspectRatio](/docs/aspect-ratio/) for media without a frame.

```tsx
<Stage>
  <StageHeader>
    <StageTitle>Route map</StageTitle>
    <StageDescription>Station to lake.</StageDescription>
    <StageActions>
      <Button onClick={zoomIn}>Zoom in</Button>
    </StageActions>
  </StageHeader>
  <StageBody aspectRatio={3 / 2}>
    <RouteMap />
  </StageBody>
  <StageFooter>
    <Button onClick={share}>Share route</Button>
  </StageFooter>
</Stage>
```

## Examples

### Hold the body while content streams

With `aspectRatio`, StageBody keeps its size while a [Skeleton](/docs/skeleton/) swaps for content, so the page does not shift. Content taller than the box is clipped; put it in a [ScrollArea](/docs/scroll-area/) to scroll. The box leaves room for the focus ring of a control that fills it.

### Expand into a dialog or panel

With `expandTo`, StageExpand moves the Stage into a modal `dialog` or docked `panel` without remounting its parts, so widget state, focus and scroll survive. An IntersectionObserver rooted outside the Stage sees the parts leave when expanded.

```tsx
<Stage expandTo="panel">
  <StageHeader>
    <StageTitle>Route map</StageTitle>
    <StageActions>
      <StageExpand
        expandLabel="Expand route map"
        collapseLabel="Collapse route map"
      >
        <ExpandIcon />
      </StageExpand>
    </StageActions>
  </StageHeader>
  <StageBody>
    <RouteMap />
  </StageBody>
</Stage>
```

## Accessibility

Stage is a `<div>` with no role. To name it, pass `role="group"` (or `role="region"` for a landmark) and `aria-labelledby` with the StageTitle `id`; the A2UI Stage does this for you. StageTitle renders a heading, `h2` by default; choose `level` to fit the page outline. Set `aria-busy` on StageBody while its content loads. Focus follows source order at every width. An expandable Stage wraps its parts in a `<dialog>`: role `generic` while collapsed, modal and named by StageTitle when expanded. Escape or a backdrop click collapses it.

## Motion

Stage parts transition colors over `--rad-motion-color-duration`; under MotionProvider, the expanded view springs open. Reduced motion removes both.

## Styling

Stage is an inline-size container, so its parts follow its width, not the viewport; in a box that sizes to its content, it takes 20rem. Below 30rem, actions sit under the description and footer items stack. From 30rem, actions sit beside the title and footer items share a wrapping row.

| Part             | Element                                     | data-slot                               |
| ---------------- | ------------------------------------------- | --------------------------------------- |
| Stage            | `div`, grid, inline-size container `stage`  | `stage`                                 |
| StageHeader      | `div`, grid                                 | `stage-header`                          |
| StageTitle       | `h1`–`h6` by `level`                        | `stage-title`                           |
| StageDescription | `p`                                         | `stage-description`                     |
| StageActions     | `div`, wrapping row                         | `stage-actions`                         |
| StageBody        | `div`, grid; AspectRatio with `aspectRatio` | `stage-body`, `aspect-ratio stage-body` |
| StageFooter      | `div`, column, then wrapping row            | `stage-footer`                          |
| Expanded view    | `dialog`, container `stage` while open      | `stage-expanded`                        |
| StageExpand      | [Button](/docs/button/)                     | `button stage-expand`                   |

`components.stage` or `--rad-stage-*` variables style it; spacing falls back to surface and spacing scales.

| Variables                                                             | Sets                 |
| --------------------------------------------------------------------- | -------------------- |
| `radius`, `corner-shape`, `background`, `color`, `shadow`             | Frame                |
| `border-width`, `border-style`, `border-color`                        | Border               |
| `padding`, `gap`, `header-gap`, `actions-gap`, `footer-gap`           | Spacing              |
| `title-size`, `title-weight`, `description-color`, `description-size` | Title, description   |
| `expanded-width`, `panel-width`                                       | Expanded view widths |

Forced colors use system colors and drop the shadow.

## API

Every part takes the native props of its element, `className`, `style` as ThemeStyle, additive `data-slot` and a ref.

| Stage prop   | Type                      | Default |
| ------------ | ------------------------- | ------- |
| padding      | tight / normal / airy     | normal  |
| expandTo     | dialog / panel            | None    |
| side         | start / end, for panel    | end     |
| open         | boolean                   | None    |
| defaultOpen  | boolean                   | false   |
| onOpenChange | `(open: boolean) => void` | None    |
| ref          | `Ref<HTMLDivElement>`     | None    |

| StageExpand prop | Type   | Default  |
| ---------------- | ------ | -------- |
| expandLabel      | string | Required |
| collapseLabel    | string | Required |

| StageTitle prop | Type                      | Default |
| --------------- | ------------------------- | ------- |
| level           | 1 / 2 / 3 / 4 / 5 / 6     | 2       |
| ref             | `Ref<HTMLHeadingElement>` | None    |

| StageBody prop | Type                   | Default |
| -------------- | ---------------------- | ------- |
| aspectRatio    | number, width ÷ height | None    |
| ref            | `Ref<HTMLDivElement>`  | None    |

StageHeader, StageActions and StageFooter take `Ref<HTMLDivElement>`; StageDescription takes `Ref<HTMLParagraphElement>`. `aspectRatio` must be finite and positive.

Exports: `Stage`, `StageHeader`, `StageTitle`, `StageDescription`, `StageActions`, `StageExpand`, `StageBody`, `StageFooter`; types `StageProps`, `StageHeaderProps`, `StageTitleProps`, `StageDescriptionProps`, `StageActionsProps`, `StageExpandProps`, `StageBodyProps`, `StageFooterProps`, `StageHeadingLevel`.
