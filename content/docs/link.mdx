## Choose the right link

`Link` renders a native anchor and stays server-renderable. Give it a meaningful
`href` and descriptive text. Enter follows the destination; Space scrolls.
Without `href`, an anchor is not a normal keyboard navigation target.

`inline` and `subtle` inherit surrounding text size. The action treatments
`solid`, `soft`, `outline` and `ghost` share [Button](/docs/button/)'s `tone`
and `controlSize`. Use Button to change something or submit a form.

## Spring feedback

<MotionLinkDemo />

Use `MotionLink` for an action-shaped anchor with Button's press/release spring:

```tsx
import { MotionProvider, MotionLink } from '@cognitap/radiant/motion/react'

;<MotionProvider>
  <MotionLink
    href="/account"
    variant="solid"
  >
    Open account
  </MotionLink>
</MotionProvider>
```

The provider adds no DOM. `motion="inherit"` uses the theme profile;
`motion="off"` suppresses spatial feedback. System reduced motion always wins.
Inline/subtle links never compress. Caller scale styling keeps ownership;
use local off for custom external scale styles. Navigation is never delayed.

## New tabs, downloads and unavailable destinations

`external` supplies `target="_blank"` and `rel="noopener noreferrer"` for any
URL, unless you set those props. Write “opens in a new tab” in the link text.
Modified and middle clicks, targets and `download` retain native behavior.

Links have no `disabled` or `pending` prop. For an unavailable destination,
explain why and render noninteractive text, or omit the link. `aria-disabled`
does not stop navigation. Use Button for asynchronous actions.

## Router adapter

<RouterLinkDemo />

The example uses Next.js `next/link`; plain Link needs no router. Forward all
resolved `LinkRenderProps`, including children, ref, handlers, target and rel,
to one anchor. The same `render` callback works with MotionLink. The fallback
`href` satisfies NextLink's required destination.

A custom router calls the supplied `onClick` once before navigation and honors
`event.defaultPrevented`. It intercepts only ordinary same-origin navigation;
modified clicks, downloads and other targets belong to the browser. Do not nest
anchors or pass resolved props through another Radiant Link.

## Public props

Root `className`, `style`, native attributes and ref reach the real anchor.
Children provide its accessible name; hide decorative icons and keep focus visible.

`LinkProps`, `LinkRenderProps` and `LinkVariant` come from `@cognitap/radiant`.
`MotionLinkProps` comes from `@cognitap/radiant/motion/react`.

| Prop                        | Purpose                                                 | Default    |
| --------------------------- | ------------------------------------------------------- | ---------- |
| `href`                      | Native path, fragment or URL                            | —          |
| `variant`                   | `inline`, `subtle`, `solid`, `soft`, `outline`, `ghost` | `inline`   |
| `tone`                      | `accent`, `neutral`, `warning`, `danger`                | `accent`   |
| `controlSize`               | `small`, `medium`, `large`; action dimensions           | `medium`   |
| `external`                  | New-tab target and safe rel defaults                    | `false`    |
| `target`, `rel`, `download` | Native anchor behavior                                  | Native     |
| `render`                    | Forward resolved props to one native/router anchor      | Native `a` |
| `motion`                    | MotionLink only: `inherit` or `off`                     | `inherit`  |
| `ref`                       | Real `HTMLAnchorElement`                                | —          |
| `className`, `style`        | Anchor customization, including typed tokens            | —          |
| Other native props          | Events, `aria-*`, data attributes                       | Native     |

Choose themes and modes through [System foundations](/docs/foundations/).
