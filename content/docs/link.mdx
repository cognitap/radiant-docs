## Usage

Use [Button](/docs/button/) for actions such as saving. Use [NavLink](/docs/nav-link/) to mark the current page in a navigation list.

For a router, forward the props from `render`, including the ref and children, to an anchor or a router component that renders one. Let the browser handle modified clicks and downloads.

## Accessibility

Use link text that names the destination. Enter follows the link. Space scrolls the page. If the link opens a new tab, say so in its text.

## Motion

For [press springs](/docs/foundations/motion/) on button variants, use `MotionLink` inside `MotionProvider` from `@cognitap/radiant/motion/react`. Use `motion="off"` to disable the spring.

## Styling

Set `components.link` in your [theme](/docs/foundations/theming/) to style text links. Button variants share Button's styling and sizing.

## API

| Prop          | Default       | Use                                                                |
| ------------- | ------------- | ------------------------------------------------------------------ |
| `href`        |               | Set the destination.                                               |
| `variant`     | `inline`      | Choose `inline`, `subtle`, `solid`, `soft`, `outline`, or `ghost`. |
| `tone`        | `accent`      | Choose `accent`, `neutral`, `warning`, or `danger`.                |
| `controlSize` | `medium`      | Set the size of button variants.                                   |
| `external`    | `false`       | Defaults to `target="_blank"` and `rel="noopener noreferrer"`.     |
| `render`      | Native anchor | Supply an adapter for your router.                                 |

Explicit `target` and `rel` values override the `external` defaults.
