## Usage

Wrap a key in `Kbd`. Use `KbdGroup` for a combination. Bind shortcuts in your app and keep a [Button](/docs/button/) available for the same action.

## Accessibility

Keys stay out of the tab order. Give the action its own accessible name. Use `aria-keyshortcuts` on the action when it has a binding.

## Styling

Use `components.kbd` or `--rad-kbd-*` to style the keycaps. Set `--rad-kbd-gap` for spacing in a combination. Combinations wrap and default to left-to-right order inside RTL text.

## API

| Prop              | Type             | Default  |
| ----------------- | ---------------- | -------- |
| children          | ReactNode        | Required |
| `dir` on KbdGroup | Native direction | ltr      |

Both components render `<kbd>`. Pass `className`, `style`, and `ref` to style or access that element.

Exports `Kbd`, `KbdGroup`, `KbdProps`, and `KbdGroupProps`.
