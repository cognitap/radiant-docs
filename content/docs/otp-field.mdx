## Usage

Use OTPField for a fixed-length verification or approval code. Use [Input](/docs/input/) for free text or codes without slots, and [PasswordInput](/docs/password-input/) for passwords. Verify submitted codes on your server.

```tsx
<Field
  label="Verification code"
  required
>
  <OTPField
    name="code"
    length={6}
  />
</Field>
```

## State

Choose one value owner per mount: `value` with native `onChange`, or `defaultValue`. Passing both, switching owners, a non-string value or a value longer than `length` throws a TypeError. A controlled owner can refuse an edit by not storing it.

`length` and `mode` are fixed per mount; remount with a new `key` to change them. Typing and paste drop characters the mode does not allow: `numeric` keeps digits, `alphanumeric` keeps ASCII letters and digits with their case. IME composition is filtered when it ends.

The code submits natively as one string under `name`, and `form` associates a field outside its form. The native `pattern` requires a complete code, and `required` rejects an empty one. Reset restores `defaultValue`; controlled owners reset their own state in `onReset`. `disabled` leaves the value out of form data; `readOnly` keeps it submitted but blocks typing and paste.

## Accessibility

Every OTPField needs an accessible name. Wrap it in [Field](/docs/field/) for a label, description and error, or pass `aria-label` or `aria-labelledby`. Screen readers meet one textbox; the slots are `aria-hidden` and never take focus. `autocomplete="one-time-code"` lets browsers offer codes from SMS or email.

| Key                      | Behavior                                    |
| ------------------------ | ------------------------------------------- |
| Tab / Shift+Tab          | Move focus in and out of the single input   |
| Typing                   | Fill the active slot and advance            |
| Backspace                | Delete before the caret                     |
| Left / Right             | Move one slot, following the text direction |
| Shift+arrows, select all | Native text selection                       |
| Paste                    | Insert the filtered code at the selection   |
| Enter                    | Submit the enclosing form natively          |

## Motion

OTPField does not animate. The active slot outline and invalid styles change immediately.

## Styling

A transparent native `<input>` covers the slots, so `className`, `style` and `ref` target it with `data-slot="input otp-field"` and `data-control-size`. Style the visible layout with `parts.wrapper` (`data-slot="otp-field-wrapper"`) and `parts.slot` (`data-slot="otp-field-slot"`). Slots carry `data-active` at the caret and `data-invalid` when invalid.

Slots share the `--rad-input-*` variables. `--rad-otp-field-gap` sets spacing, default 0.375rem, and `--rad-otp-field-slot-size` sets slot width, default the control height. The theme sets both through `components.otpField.gap` and `slotSize`. Keep the focus outline visible on the active slot.

## API

### OTPField

| Prop                 | Type                                        | Default             |
| -------------------- | ------------------------------------------- | ------------------- |
| value / defaultValue | string                                      | None; one owner     |
| onChange             | `ChangeEventHandler<HTMLInputElement>`      | None                |
| length               | integer from 1 to 32                        | 6                   |
| mode                 | `OTPFieldMode`: numeric / alphanumeric      | numeric             |
| controlSize          | small / medium / large                      | medium              |
| name / form          | string                                      | None                |
| required / disabled  | boolean                                     | Field's, else false |
| readOnly             | boolean                                     | false               |
| aria-invalid         | Native; mirrored as `data-invalid` on slots | Field's             |
| spellCheck           | boolean                                     | false               |
| parts                | `{ wrapper?, slot? }` of className / style  | None                |
| className / style    | string / ThemeStyle on the native input     | None                |
| ref                  | `Ref<HTMLInputElement>`                     | None                |
| Other props          | Native input attributes and events          | Native defaults     |

OTPField owns `type="text"`, `inputMode`, `autoComplete`, `pattern` and `maxLength`; they are not props.

Exports `OTPField`, `OTPFieldProps` and `OTPFieldMode`.
