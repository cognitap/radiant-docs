## Usage

Use Slider when an approximate value is easier to choose by feel, such as volume or brightness. Use [Input](/docs/input/) with `type="number"` for exact or very large values, [Meter](/docs/meter/) or [Progress](/docs/progress/) for read-only levels, and [RadioGroup](/docs/radio-group/) for a few named options. Slider has one thumb, so it cannot select a start and an end.

```tsx
<Field label="Volume">
  <Slider
    name="volume"
    min={0}
    max={100}
    step={5}
    defaultValue={40}
  />
</Field>
```

## State

Choose one value owner per mount: `value` with `onChange`, or `defaultValue`. Read `event.target.valueAsNumber`. Passing both, switching owners or passing a non-finite number throws a TypeError; remount with a new `key` to change owners. With neither, the value starts at the midpoint of `min` and `max`. The browser clamps values to the range and snaps them to `step`.

With `name`, the form submits the value as a string, such as `"1.25"`. A disabled slider submits nothing. Reset restores `defaultValue`; controlled owners reset their own state in `onReset`. A range always has a value, so `required` and `readOnly` are not accepted.

## Accessibility

The input has the native slider role. Give it a name with [Field](/docs/field/), `aria-label` or `aria-labelledby`. The browser supplies the current, minimum and maximum values. Add `aria-valuetext` for units, such as "40 percent". Inside Field, its description and error IDs come before your own `aria-describedby`.

| Key                   | Behavior                                   |
| --------------------- | ------------------------------------------ |
| ArrowRight / ArrowUp  | Increase by `step`; ArrowLeft in RTL       |
| ArrowLeft / ArrowDown | Decrease by `step`; ArrowRight in RTL      |
| PageUp / PageDown     | Change by a larger, browser-defined amount |
| Home / End            | Set to `min` / `max`                       |

## Styling

Slider renders one native `<input>`, so `className`, `style` and `ref` all target it. It carries `data-slot="slider"`, `data-control-size`, `data-orientation` and `data-invalid` when invalid; style disabled with `:disabled`. Vertical sliders put higher values at the top and default to a 12rem length. Forced colors restore the native slider.

Override `--rad-slider-*` variables in `style` or `components.slider` in a theme:

```tsx
<Slider
  aria-label="Volume"
  style={{
    '--rad-slider-track-size': '.5rem',
    '--rad-slider-thumb-size': '1.5rem'
  }}
/>
```

Variables cover height, length, track size, radius and color, thumb size, radius, color, border and shadow, corner shape, invalid and disabled colors, and focus.

## API

### Slider

| Prop                 | Type                                      | Default             |
| -------------------- | ----------------------------------------- | ------------------- |
| value / defaultValue | number                                    | None; one owner     |
| onChange             | `ChangeEventHandler<HTMLInputElement>`    | None                |
| min                  | number / string                           | 0                   |
| max                  | number / string                           | 100                 |
| step                 | number / string; `"any"` removes snapping | 1                   |
| orientation          | `Orientation`: horizontal / vertical      | horizontal          |
| controlSize          | small / medium / large                    | medium              |
| name / form          | string                                    | None                |
| disabled             | boolean                                   | Field's, else false |
| aria-invalid         | Native; mirrored as `data-invalid`        | Field's             |
| aria-valuetext       | string                                    | None                |
| className / style    | string / ThemeStyle                       | None                |
| ref                  | `Ref<HTMLInputElement>`                   | None                |
| Other props          | Native input attributes and events        | Native defaults     |

Not accepted: `type`, `role`, `required`, `readOnly`, `size`, `children` and the `aria-valuenow`, `aria-valuemin`, `aria-valuemax` and `aria-orientation` attributes.

Exports `Slider`, `SliderProps` and `Orientation`.
