## Usage

Use NavLink in a sidebar or other application navigation. Set `active` from the current route. Use [Link](/docs/link/) for links that need no current-page styling.

## State

The active link exposes `aria-current="page"`. To use a router, forward the props from `render`, including the ref and children, to its anchor.

Use `NavLinkGroup` to disclose nested links. Add a `NavLinkGroupTrigger` and put the destinations in `NavLinkGroupContent`. Use `defaultOpen` for the initial state or `open` with `onOpenChange` to control it.

## Accessibility

Give the navigation a name. Tab visits visible links and group triggers. Enter follows a link. Enter or Space opens and closes a group.

## Motion

Groups use [Collapsible](/docs/collapsible/) motion. Set `motion="off"` on a group to turn off its animation.

## Styling

Use `components.navLink` in your [theme](/docs/foundations/theming/) for active, hover, and focus styles. Use `parts` to style the icon, label, or description.

Set `indicatorColor` to outline the current page.

## API

| NavLink prop          | Default       | Use                                   |
| --------------------- | ------------- | ------------------------------------- |
| `href`                | Required      | Set the destination.                  |
| `active`              | `false`       | Mark the current page.                |
| `icon`, `description` |               | Add context to the visible label.     |
| `controlSize`         | `medium`      | Choose `small`, `medium`, or `large`. |
| `render`              | Native anchor | Supply a router adapter.              |
