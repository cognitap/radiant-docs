## Usage

Use Card when several items about one subject sit side by side, such as projects in a grid. A single section in the page flow needs only a heading and content. Use [Alert](/docs/alert/) for a message with a tone, [Dialog](/docs/dialog/) or [Drawer](/docs/drawer/) for a focused task that interrupts the page, [HoverCard](/docs/hover-card/) for a preview on hover or focus, [EmptyState](/docs/empty-state/) for a placeholder and [Separator](/docs/separator/) between sections.

```tsx
<Card>
  <CardHeader>
    <CardTitle>Studio note</CardTitle>
    <CardDescription>Kiln schedule for this week.</CardDescription>
  </CardHeader>
  <CardContent>The glaze fires overnight.</CardContent>
  <CardFooter>
    <Button onClick={save}>Save note</Button>
  </CardFooter>
</Card>
```

## State

Card has no state, value or callbacks, and submits nothing. A form inside it owns values, validation, reset and submission. Disabling the surface does not disable its children.

## Accessibility

Card is a `<div>` with no role. To make it a landmark, pass `role="region"` and `aria-labelledby` with the CardTitle `id`. CardTitle renders a heading, `h2` by default; choose `level` to fit the page outline. CardDescription is a `<p>` and is not linked automatically.

A link card has one tab stop, named by the title text alone, and screen readers list it as a link in a heading. Keep other controls out of it; they sit under the link layer and cannot be clicked. Do not wrap the card in `<a>`, which names the link with all its text.

| Key             | Behavior                                      |
| --------------- | --------------------------------------------- |
| Tab / Shift+Tab | Visit links, buttons and fields in DOM order  |
| Enter           | Follow a link; in a link card, the title link |

## Motion

Every part transitions color, background and border over `--rad-motion-color-duration`. Reduced motion removes the transition. To animate cards as they move or resize, see [layout motion](/docs/foundations/motion/#animate-layout).

## Styling

| Part            | Element              | data-slot          |
| --------------- | -------------------- | ------------------ |
| Card            | `div`, grid          | `card`             |
| CardHeader      | `div`, grid          | `card-header`      |
| CardTitle       | `h1`–`h6` by `level` | `card-title`       |
| CardDescription | `p`                  | `card-description` |
| CardContent     | `div`                | `card-content`     |
| CardFooter      | `div`, wrapping row  | `card-footer`      |

Parts can appear in any order. Caller classes win, and a caller `data-slot` adds tokens after the part's own. `components.card` or `--rad-card-*` variables set radius, corner-shape, background, color, border, padding, gap, header-gap, footer-gap, shadow, title-size, title-weight, description-color and description-size. Forced colors use system canvas and text colors and drop the shadow.

## API

Every part takes the native props of its element, `className`, `style` as ThemeStyle, additive `data-slot` and a ref.

| Card prop | Type                  | Default |
| --------- | --------------------- | ------- |
| style     | ThemeStyle            | None    |
| data-slot | string                | card    |
| ref       | `Ref<HTMLDivElement>` | None    |

| CardHeader prop | Type                  | Default     |
| --------------- | --------------------- | ----------- |
| style           | ThemeStyle            | None        |
| data-slot       | string                | card-header |
| ref             | `Ref<HTMLDivElement>` | None        |

| CardTitle prop | Type                      | Default    |
| -------------- | ------------------------- | ---------- |
| level          | 1 / 2 / 3 / 4 / 5 / 6     | 2          |
| style          | ThemeStyle                | None       |
| data-slot      | string                    | card-title |
| ref            | `Ref<HTMLHeadingElement>` | None       |

| CardDescription prop | Type                        | Default          |
| -------------------- | --------------------------- | ---------------- |
| style                | ThemeStyle                  | None             |
| data-slot            | string                      | card-description |
| ref                  | `Ref<HTMLParagraphElement>` | None             |

| CardContent prop | Type                  | Default      |
| ---------------- | --------------------- | ------------ |
| style            | ThemeStyle            | None         |
| data-slot        | string                | card-content |
| ref              | `Ref<HTMLDivElement>` | None         |

| CardFooter prop | Type                  | Default     |
| --------------- | --------------------- | ----------- |
| style           | ThemeStyle            | None        |
| data-slot       | string                | card-footer |
| ref             | `Ref<HTMLDivElement>` | None        |

Exports: `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`; types `CardProps`, `CardHeaderProps`, `CardTitleProps`, `CardDescriptionProps`, `CardContentProps`, `CardFooterProps`, `CardHeadingLevel`.
