## Usage

Use TagsInput when people type their own values, such as labels or recipients. Choose something else when:

- [MultiSelect](/docs/multi-select/): values must come from a fixed list of options.
- [Tag](/docs/tag/): you only show removable values and people don't type new ones.
- [Input](/docs/input/): you need one string.

```tsx
<Field
  label="Topics"
  required
>
  <TagsInput
    name="topics"
    defaultValue={['research']}
    maxCount={4}
  />
</Field>
```

## State

Use `defaultValue`, or `value` with `onValueChange`, not both; the owner stays fixed per mount. Values must be distinct, trimmed, nonempty strings, or TagsInput throws. A controlled owner can refuse a change, and the draft text stays.

Enter, a separator or a pasted line break commits the draft. Duplicates are ignored; rejected or excess tokens stay in the draft. `validate` returns true to accept, or false or a message to reject.

Each committed value submits under `name` as a repeated field; read it with `FormData.getAll`. Draft text never submits. Form reset restores uncontrolled values and clears the draft. `disabled` submits nothing. `readOnly` submits its values, blocks edits and skips `required`. `required` checks the committed array, and an invalid submit focuses the text input.

## Accessibility

The text input is a native textbox; name it with [Field](/docs/field/) or `aria-label`. Each tag's remove Button is named `Remove <value>`. Rejected input sets `aria-invalid="true"` and shows a polite live message linked by `aria-describedby`.

| Key                         | Behavior                                        |
| --------------------------- | ----------------------------------------------- |
| Enter                       | Commit the draft when it isn't blank            |
| Separator (default `,`)     | Commit the text before it                       |
| Paste with separators       | Split and commit; rejected tokens stay as draft |
| Backspace on an empty draft | Remove the last tag                             |
| Tab / Shift+Tab             | Visit each remove Button, then the text input   |
| Enter / Space on remove     | Remove that tag and return focus to the input   |

IME composition and Ctrl, Meta or Alt combinations never commit. An `onKeyDown` or `onPaste` that calls `preventDefault` wins.

## Motion

Nothing animates. Remove Buttons use `motion="off"`.

## Styling

`className`, `style` and `ref` reach the text input. Style the other hosts through `parts`.

| Host          | Attributes                                          | Styled by       |
| ------------- | --------------------------------------------------- | --------------- |
| Wrapper       | `data-slot="tags-input-control"`                    | `parts.wrapper` |
| Each tag      | `data-slot="badge tag"`                             | `parts.tag`     |
| Remove Button | `data-slot="tag-remove"`                            | `parts.remove`  |
| Text input    | `data-slot="input tags-input"`, `data-control-size` | Root props      |
| Error message | `data-slot="tags-input-error"`                      | `parts.error`   |

`components.tagsInput.gap` sets `--rad-tags-input-gap`, which defaults to `0.5rem`.

## API

### TagsInput

| Prop                 | Type                                                               | Default             |
| -------------------- | ------------------------------------------------------------------ | ------------------- |
| value / defaultValue | `string[]`; one owner                                              | None / `[]`         |
| onValueChange        | `(value: string[]) => void`                                        | None                |
| separators           | `readonly string[]`; single characters                             | `[',']`             |
| validate             | `(value: string) => boolean \| string`                             | None                |
| maxCount             | number; nonnegative integer                                        | No maximum          |
| controlSize          | small / medium / large                                             | medium              |
| name / form          | string; `form` reaches every hidden input                          | None                |
| disabled / required  | boolean                                                            | Field's, else false |
| readOnly             | boolean                                                            | false               |
| aria-invalid         | Native                                                             | Field's             |
| parts                | `{ wrapper?, tag?, remove?, error? }`, each `{ className, style }` | None                |
| Other props          | Input props except value, defaultValue, type and children          | Native              |

Native `onChange` observes draft edits; `onValueChange` requests committed arrays.

Exports `TagsInputProps`.
