## Usage

Use [Field](/docs/field/) for a label and errors. `autoComplete` defaults to `current-password`. Use `new-password` when the user chooses a password.

### Reveal with a hold or an icon

By default, the button toggles visibility. Set `revealMode="hold"` to reveal only while the button is held. Each icon replaces the corresponding button text and works in either mode.

```tsx
import { faEye, faEyeSlash } from '@fortawesome/free-solid-svg-icons'
import { FontAwesomeIcon } from '@fortawesome/react-fontawesome'
import { PasswordInput } from '@cognitap/radiant'

export function PasswordField() {
  return (
    <PasswordInput
      aria-label="Password"
      name="password"
      revealMode="hold"
      showIcon={<FontAwesomeIcon icon={faEye} />}
      hideIcon={<FontAwesomeIcon icon={faEyeSlash} />}
    />
  )
}
```

## State

Use `defaultValue` or `value` with `onChange`. The value starts hidden. It hides again when the form is submitted or reset, or when the field is disabled.

## Accessibility

Give the input a visible label, `aria-label` or `aria-labelledby`. Use Enter or Space on the reveal button. In hold mode, release the key or move focus away to hide the password. `showLabel` and `hideLabel` still name the icon button for assistive technology. Hold mode keeps `showLabel` throughout the press.

## Styling

Use `parts.wrapper` and `parts.toggle` to style the frame and reveal button. Set `--rad-password-input-gap` on the wrapper to change the space between the input and button. See [focus outlines](/docs/foundations/theming/#focus-outlines) for focus and error colors.

## API

PasswordInput accepts [native input props](/docs/input/#api) except `type` and `children`.

| Prop                        | Purpose                                                    |
| --------------------------- | ---------------------------------------------------------- |
| `revealMode`                | `toggle` (default) or `hold`.                              |
| `showIcon`, `hideIcon`      | React nodes for the hidden and visible states.             |
| `showLabel`, `hideLabel`    | Override the button labels.                                |
| `controlSize`               | `small`, `medium` (default), or `large`.                   |
| `className`, `style`, `ref` | Target the native input with `data-slot="password-input"`. |
