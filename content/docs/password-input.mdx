## Usage

Use PasswordInput for a password the user may want to check before submitting. Showing it never changes the value, the autofill attributes or what the form submits. Use [Input](/docs/input/) for ordinary text or email, [OTPField](/docs/otp-field/) for one-time codes and [InputGroup](/docs/input-group/) for other addons.

```tsx
<Field
  label="Password"
  required
>
  <PasswordInput name="password" />
</Field>
```

`autoComplete` defaults to `current-password`. Use `new-password` when the user chooses one, and `username` on the account input.

## State

Pass `value` with `onChange` or pass `defaultValue`, not both. Switching between them throws, and so does a value that isn't a string. Native form reset restores `defaultValue`.

Visibility is internal and starts hidden. The password hides again on form submit, before your submit handler runs, on form reset and when the input is disabled, including through Field. It stays hidden when re-enabled. To start a different record hidden, change the `key`.

Only the input submits, under its `name`. The reveal button is `type="button"` and never submits.

## Accessibility

Name the input with a Field label, `aria-label` or `aria-labelledby`. The reveal button renames itself to its next action: `showLabel` while hidden, `hideLabel` while shown. Both must be non-empty. A button that renames itself is an action, not a [toggle](/docs/button/#accessibility), so it sets no `aria-pressed`. Its visible label stays its accessible name, which voice-control users speak, and a pressed state would contradict it. `aria-controls` points it at the input. Some screen readers don't announce a focused button's new name.

| Key                     | Behavior                                               |
| ----------------------- | ------------------------------------------------------ |
| Tab / Shift+Tab         | Visit the input, then the reveal button                |
| Enter / Space on reveal | Show or hide; focus and the input's selection stay put |
| Enter in input          | Submit the form natively                               |

## Motion

Nothing animates. The reveal button uses `motion="off"`.

## Styling

`className`, `style` and `ref` reach the input. `parts.wrapper` and `parts.toggle` take a class and style for the wrapper and the reveal button.

| Part          | `data-slot`                              |
| ------------- | ---------------------------------------- |
| Wrapper       | `input-group password-input-wrapper`     |
| Input         | `input input-group-input password-input` |
| Reveal button | `button password-input-toggle`           |

The wrapper also has `data-control-size`. `components.passwordInput.gap` or `--rad-password-input-gap` sets the space between the input and the reveal button.

## API

### PasswordInput

| Prop                                                        | Type                                          | Default            |
| ----------------------------------------------------------- | --------------------------------------------- | ------------------ |
| value                                                       | string; controlled                            | None               |
| defaultValue                                                | string; uncontrolled                          | None               |
| onChange                                                    | Native input change handler                   | None               |
| showLabel                                                   | string; reveal button name while hidden       | `'Show password'`  |
| hideLabel                                                   | string; reveal button name while shown        | `'Hide password'`  |
| autoComplete                                                | string                                        | `current-password` |
| controlSize                                                 | small / medium / large                        | medium             |
| parts                                                       | `{ wrapper?: PartStyle; toggle?: PartStyle }` | None               |
| name / form / required / disabled / readOnly / aria-invalid | Native; Field supplies them when wrapped      | None               |
| className / style                                           | string / ThemeStyle; the input                | None               |
| ref                                                         | `Ref<HTMLInputElement>`                       | None               |
| Native input attributes                                     | Except `type` and `children`                  | Native             |

Exports: `PasswordInput`, `PasswordInputProps`.
