## Usage

Use Drawer for a task beside the current page, such as settings or an outline. Use [Dialog](/docs/dialog/) for a centered task that blocks the page and [Popover](/docs/popover/) for small content anchored to a trigger. Persistent navigation belongs in the layout.

```tsx
<Drawer>
  <DrawerTrigger>Settings</DrawerTrigger>
  <DrawerContent side="end">
    <DrawerHandle aria-label="Resize settings" />
    <DrawerTitle>Project settings</DrawerTitle>
    <DrawerDescription>Change your preferences.</DrawerDescription>
    <DrawerClose>Done</DrawerClose>
  </DrawerContent>
</Drawer>
```

## State

Open state follows [Dialog](/docs/dialog/#state): `open` or `defaultOpen`, with `onOpenChange(open)`. Size is a separate owner: `snapPoint` or `defaultSnapPoint`, with `onSnapPointChange(snapPoint)`. Uncontrolled size starts at the largest point. A controlled owner may refuse either request. Mixing controlled and default props for one state is a type error.

`snapPoints` are distinct fractions in `(0, 1]`. A `snapPoint` outside the set throws. Dragging below the smallest point requests dismissal and keeps the last size for reopening.

Drawer has no form value. Forms inside the content submit and reset natively; reset does not change open or size.

## Accessibility

Content is a native `<dialog>` named by DrawerTitle and described by DrawerDescription. Modal content traps focus and returns it to the trigger on close; non-modal content leaves the page usable. Keep a visible Close action.

DrawerHandle is a real button. It requires `aria-label` or `aria-labelledby` and throws without one. A polite live region announces the size as a percentage.

| Key                        | Behavior                                         |
| -------------------------- | ------------------------------------------------ |
| Enter / Space on trigger   | Open                                             |
| Escape                     | Close, unless `closeOnEscape={false}` or refused |
| Tab / Shift+Tab            | Stay inside a modal drawer                       |
| Enter / Space on handle    | Next larger size, wrapping to the smallest       |
| Arrow toward the open side | Next larger size                                 |
| Arrow toward the edge      | Next smaller size; below the smallest closes     |
| Home / End on handle       | Smallest / largest size                          |

Arrows ignore modifier keys and disabled or pending handles.

## Motion

Under `MotionProvider`, the drawer slides in and out and settles on a spring after a snap or drag. Set `motion="off"` on DrawerContent, or rely on reduced motion, to remove it. Dragging still works. The handle has no press motion.

## Styling

| Part     | Slot and attributes                                                                         |
| -------- | ------------------------------------------------------------------------------------------- |
| Content  | `dialog drawer`; `data-side`, `data-physical-side` (top/right/bottom/left), `data-dragging` |
| Viewport | `drawer-viewport`; style with `parts.viewport`                                              |
| Handle   | contains `drawer-handle` and `button`                                                       |

Set `--rad-drawer-size` (default `24rem`) for the maximum extent. Surface spacing uses `--rad-dialog-gap` and `--rad-dialog-padding`.

## API

### Drawer

| Prop                            | Type / default                   |
| ------------------------------- | -------------------------------- |
| open / defaultOpen              | boolean; one owner; closed       |
| onOpenChange                    | (open: boolean) → void           |
| modal                           | boolean; true                    |
| closeOnBackdrop / closeOnEscape | boolean; true                    |
| snapPoints                      | readonly number[]; [0.5, 1]      |
| snapPoint / defaultSnapPoint    | number; one owner; largest point |
| onSnapPointChange               | (snapPoint: number) → void       |

### DrawerTrigger / DrawerClose

| Prop        | Type / default                              |
| ----------- | ------------------------------------------- |
| render      | Custom element for the action               |
| Other props | Button props without `pressed`; type button |

### DrawerContent

| Prop              | Type / default                                 |
| ----------------- | ---------------------------------------------- |
| side              | top / right / bottom / left / start / end; end |
| motion            | inherit / off; inherit                         |
| parts             | `{ viewport?: PartStyle }`                     |
| className / style | string / ThemeStyle; the dialog                |
| ref               | HTMLDialogElement                              |

### DrawerHandle

| Prop                         | Type / default                                       |
| ---------------------------- | ---------------------------------------------------- |
| aria-label / aria-labelledby | Requires `aria-label` or `aria-labelledby`           |
| variant                      | Button variant; ghost                                |
| tone                         | Button tone; neutral                                 |
| Other props                  | Button props without children, pressed, type, motion |

### DrawerTitle / DrawerDescription

| Prop        | Type / default                                  |
| ----------- | ----------------------------------------------- |
| Other props | Same as DialogTitle / DialogDescription; h2 / p |

### useDrawer()

Returns DrawerState (`snapPoint`, `snapPoints`, `setSnapPoint`, `snapControlled` and Dialog state), or `null` outside Drawer.

Exports each part's `Drawer…Props` type, `DrawerSide`, `DrawerState` and `DrawerRenderProps`.
