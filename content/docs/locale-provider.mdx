## Usage

Wrap a region to set the locale for components such as [NumberField](/docs/number-field/) and [Select](/docs/select/).

```tsx
import { LocaleProvider, NumberFormatter } from '@cognitap/radiant'

;<LocaleProvider locale="fr-FR">
  <NumberFormatter value={1234.5} />
</LocaleProvider>
```

## State

The app supplies `locale`. Omit it to inherit from the nearest provider. Use the same initial locale on the server and client. Formatting and matching fall back to en-US when the locale is unconfigured or unsupported.

## Accessibility

The subtree wrapper sets native `lang` and script-derived `dir` for an explicit locale. Omitted locale leaves those attributes to surrounding HTML. An inner French scope can read left to right inside Arabic content. Controls, disclosures, overlays, and navigation follow computed CSS direction, including direct `dir` overrides. The app supplies translations for its content, labels, and errors. Built-in component messages default to English.

## API

| Prop       | Type and default                                                             |
| ---------- | ---------------------------------------------------------------------------- |
| `locale`   | Optional BCP 47 tag. Inherits when omitted.                                  |
| `scope`    | `subtree` (default) renders a div. `document` renders the children directly. |
| `children` | React content.                                                               |

Exports LocaleProvider and LocaleProviderProps. The `getLocaleAttributes(locale?)` helper returns native `lang` and `dir`. The language omits formatting extensions.
