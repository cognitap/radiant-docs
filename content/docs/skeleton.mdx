## Usage

Use Skeleton when you know the layout of the content that is loading. Use [Spinner](/docs/spinner/) for a compact activity indicator beside text or in a pending [Button](/docs/button/), and [Progress](/docs/progress/) when completion is measurable. When there is no layout to preserve, show plain text in a status region.

```tsx
<section aria-busy={loading}>
  {loading ? (
    <>
      <Skeleton style={{ width: '40%' }} />
      <Skeleton />
    </>
  ) : (
    <AccountDetails />
  )}
</section>
<output>{loading ? 'Loading account…' : 'Account loaded.'}</output>
```

## State

Skeleton has no state and contributes no form value. The application decides when loading starts and ends, and replaces the shapes with real content.

## Accessibility

Every shape is `aria-hidden="true"` and empty. Children, `role`, ARIA naming, `aria-busy`, `aria-live` and `tabIndex` are rejected by the type and stripped at runtime.

The consumer owns the loading state. Put `aria-busy={loading}` on the region that will hold the content. Put the loading and completion text in a status region, such as `<output>` or [Alert](/docs/alert/), outside the busy region, since some screen readers skip a busy region's content. Replacing shapes with content does not move focus. Don't fill placeholders with plausible fake data.

| Key             | Behavior                              |
| --------------- | ------------------------------------- |
| Tab / Shift+Tab | Skip the shape; it is never focusable |

## Motion

Shapes pulse in opacity once per `--rad-skeleton-duration`, `2s` by default. System reduced motion, a theme with motion off, `motion="off"` and forced colors all stop the pulse and leave a static, visible shape. `data-motion` is `off` for the prop or theme setting; it does not reflect system reduced motion. The pulse is CSS only, so no MotionProvider is needed.

## Styling

Skeleton renders a block `span` capped at the container width, with `data-slot="skeleton"` and `data-motion`. A caller `data-slot` is appended, so select with `[data-slot~="skeleton"]`. `className` is merged last, and `style` takes native width, height and border radius. Forced colors draw a `CanvasText` border on `Canvas`.

`components.skeleton` or local variables set `--rad-skeleton-width` (`100%`), `-height` (`1rem`), `-radius` (the surface radius), `-color` (the neutral color) and `-duration`.

## API

### Skeleton

| Prop        | Type                                                                         | Default         |
| ----------- | ---------------------------------------------------------------------------- | --------------- |
| motion      | inherit / off                                                                | inherit         |
| className   | string; merged after the built-in classes                                    | None            |
| style       | ThemeStyle, including `--rad-skeleton-*`                                     | None            |
| data-slot   | Extra tokens after `skeleton`                                                | skeleton        |
| ref         | `Ref<HTMLSpanElement>`                                                       | None            |
| Other props | Native span props except children, `role`, ARIA naming and state, `tabIndex` | Native defaults |

Exports: `Skeleton`, `SkeletonProps`.
