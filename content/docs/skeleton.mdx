## Explain the loading state

Skeleton draws an empty visual placeholder. Every shape is hidden from
assistive technology and cannot contain text, links or controls. Shapes do not
represent real content or describe whether a request succeeded.

Provide useful loading text separately. The application owns fetching,
cancellation, errors and completion. Use [Alert](/docs/alert/) for concise
status feedback when an announcement is useful. Avoid announcing every shape
or repeating an unchanged loading message.

Set `aria-busy` on the content region being updated. Keep the status outside
that busy region so useful updates are not held back. Replace placeholders
with real content and clear busy state when the work finishes. On failure,
show meaningful error feedback and an appropriate retry or cancellation action.
Preserve the user's focus while replacing content; Skeleton never moves it.

Use shapes that resemble the expected layout to reduce movement when content
arrives. Do not present plausible fake account details as placeholders. Use
[Progress](/docs/progress/) for measurable task completion, or
[Spinner](/docs/spinner/) for compact activity feedback.

## Customize the shapes

Skeleton renders a native `span` with the `skeleton` slot. Native attributes,
`className`, `style` and an `HTMLSpanElement` ref reach that host. It owns
`aria-hidden`, role, focusability and its empty content. Loading-region busy
state and accessible status belong on separate application elements.
`SkeletonProps` is exported.

Use `components.skeleton` or local `--rad-skeleton-*` variables for `width`,
`height`, `radius`, `color` and `duration`. Defaults fill the available width,
use a one-rem height, inherit the shared surface radius and use the neutral
color. Set dimensions and radius through `style` for circles or custom blocks.
Keep shapes bounded in narrow layouts.

## Motion and visibility

The default treatment uses a CSS opacity pulse. System reduced motion,
`motion="off"` and theme motion off retain static visible shapes. Forced colors
use a static system-color outline. No MotionProvider, timers or animation
engine are required; removing the element removes its CSS animation.

Preserve visible placeholders and useful loading text when replacing styles.
No provider is required; [themes](/docs/foundations/theming/) apply normally.
