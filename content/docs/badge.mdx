## Usage

Use text that conveys the status on its own, such as “Needs review”. Put counts next to a label that says what they count. Use [Tag](/docs/tag/) for removable items, [Button](/docs/button/) for actions, and [Link](/docs/link/) for navigation.

## Accessibility

Badge is plain text and stays out of the tab order. Set `decorative` only when nearby text already says the same thing. Use an [Alert](/docs/alert/) to announce an update.

## Styling

Use `components.badge` or `--rad-badge-*` variables to style the badge. Target it with `[data-slot~="badge"]`.

## API

| Prop              | Type                                     | Default |
| ----------------- | ---------------------------------------- | ------- |
| children          | ReactNode                                | None    |
| tone              | neutral / accent / warning / danger      | neutral |
| decorative        | boolean                                  | false   |
| Native span props | Includes `className`, `style`, and `ref` | Native  |

Exports `Badge`, `BadgeProps`, and `BadgeTone`.
