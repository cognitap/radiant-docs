## Usage

Use Badge for short text that labels a status, a count or a category. Use [Tag](/docs/tag/) when people can remove the item, [Kbd](/docs/kbd/) for keyboard keys, [Button](/docs/button/) or [Link](/docs/link/) for anything clickable, and [Alert](/docs/alert/) for updates that must be announced.

```tsx
<Badge tone="warning">Needs review</Badge>
```

`tone` only sets color: `neutral` (default) for information, `accent` for success or confirmation, `warning` for a problem the user can still avoid, and `danger` for a failure. Say the status in the text; color only reinforces it.

## State

Badge holds no state, has no controlled or uncontrolled props and contributes no form value.

## Accessibility

Badge renders a plain `span` with no role, so its visible text is its accessible content. Its types reject `role`, `tabIndex`, `contentEditable`, `aria-label`, `aria-labelledby`, `aria-live` and `aria-hidden`, and the component strips them at runtime. Badge adds no live region; applications announce status changes themselves.

| Key             | Behavior                              |
| --------------- | ------------------------------------- |
| Tab / Shift+Tab | Skip the badge; it is never focusable |

## Motion

Badge has no motion. Forced colors use `CanvasText` for text and border and `Canvas` for the background.

## Styling

| Part  | Element | data-slot | Data attributes                |
| ----- | ------- | --------- | ------------------------------ |
| Badge | `span`  | `badge`   | `data-tone`, `data-decorative` |

`className`, `style` and the ref reach the span. Caller classes merge after the defaults, caller `style` wins, and a caller `data-slot` is appended to `badge`. `components.badge` or `--rad-badge-*` variables set radius, background, color, borderColor, borderWidth, borderStyle, paddingInline, paddingBlock and fontSize. Long text wraps within the available width.

## API

| Badge prop        | Type                                                                   | Default         |
| ----------------- | ---------------------------------------------------------------------- | --------------- |
| children          | ReactNode                                                              | None            |
| tone              | neutral / accent / warning / danger                                    | neutral         |
| decorative        | boolean                                                                | false           |
| className / style | string / ThemeStyle                                                    | None            |
| data-slot         | Additional identity tokens                                             | badge           |
| ref               | `Ref<HTMLSpanElement>`                                                 | None            |
| Native span props | Except role, tabIndex, contentEditable and naming, live or hidden ARIA | Native defaults |

Exports: `Badge`; types `BadgeProps`, `BadgeTone`.
