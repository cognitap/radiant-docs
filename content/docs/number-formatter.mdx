## Usage

Use NumberFormatter for display and [NumberField](/docs/number-field/) for editable numbers.

```tsx
import { NumberFormatter } from '@cognitap/radiant'

;<NumberFormatter
  value={1299.95}
  options={{ style: 'currency', currency: 'EUR' }}
/>
```

## State

Pass a value and formatting options. Locale comes from the nearest LocaleProvider unless `locale` is provided. Radiant falls back to en-US for unsupported locales. Use the same locale on server and client. The server text stays in place during hydration when engine data differs. Changed values use the browser’s locale data.

## Accessibility

The native bidi isolation element keeps the number together in surrounding text. Group labels and descriptions belong to the surrounding content.

## Styling

`className`, `style`, and `ref` target the inline element. It inherits text color and typography.

## API

| Prop                          | Type and default                                      |
| ----------------------------- | ----------------------------------------------------- |
| `value`                       | Number or bigint.                                     |
| `options`                     | Intl.NumberFormatOptions. Default decimal formatting. |
| `locale`                      | Optional BCP 47 locale.                               |
| `lang`                        | Override the formatted language on the element.       |
| `className` / `style` / `ref` | Native inline host.                                   |

Exports NumberFormatter and NumberFormatterProps.
