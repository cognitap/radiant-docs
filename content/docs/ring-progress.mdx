## Usage

Use RingProgress for a compact circular display. Use [Progress](/docs/progress/) or [Meter](/docs/meter/) for a horizontal display.

```tsx
import { RingProgress } from '@cognitap/radiant'

;<RingProgress
  aria-label="Export progress"
  value={60}
  label="60%"
/>
```

## State

Pass a value or segments. Each segment contributes its value above the minimum. The native element reports the combined total. Omit the value for indeterminate progress. Meter mode requires a reading.

## Accessibility

Provide a native accessible name for the progressbar or meter. The SVG and center label are decorative. If segments convey categories, explain them in adjacent text.

## Motion

With `MotionProvider`, changes follow the theme’s [follow spring](/docs/foundations/motion/). The native value updates immediately. Reduced motion or `motion="off"` applies the visual value immediately.

## Styling

`className`, `style`, and `ref` target the wrapper. Set `--rad-ring-progress-size` to change the diameter. Use `parts.track`, `parts.segment`, and `parts.label` for local styling.

## API

| Prop          | Type and default                                               |
| ------------- | -------------------------------------------------------------- |
| `kind`        | progress (default) or meter.                                   |
| `value`       | Reading. Null or omitted means indeterminate in progress mode. |
| `segments`    | Array of nonnegative contributions with optional tones.        |
| `min` / `max` | Minimum 0. Meter can override min. Maximum defaults to 100.    |
| `label`       | Optional visual center text.                                   |
| `tone`        | Default arc tone. Defaults to accent.                          |
| `motion`      | inherit (default) or off.                                      |
| `parts`       | track, segment, and label.                                     |

Exports RingProgress, RingProgressProps, and RingProgressSegment.
