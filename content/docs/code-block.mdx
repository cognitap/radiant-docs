## Usage

Pass the original snippet as `code`. For syntax colors, pass highlighted nodes to `CodeBlockContent`. The copy button copies the original string and briefly shows a checkmark and “Copied”.

## Accessibility

Tab reaches the copy button and viewport. Arrow keys scroll the focused viewport. Copy feedback is announced, and line numbers are hidden from assistive technology.

## Styling

Use `components.codeBlock` in your theme to set the surface, border, spacing, and code typography.

## API

| Part                | Props                                                                                                                                                                                |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `CodeBlock`         | `code` is required. `language` sets metadata. `lineNumbers` shows a gutter and defaults to `false`. `loadingText`, `copiedText`, `errorText`, and `parts.status` customize feedback. |
| `CodeBlockHeader`   | Holds the title and actions. Accepts native div props.                                                                                                                               |
| `CodeBlockViewport` | Supply `aria-label` or `aria-labelledby`. Defaults to `dir="ltr"`, `orientation="both"`, and `<CodeBlockContent />`. Accepts [ScrollArea](/docs/scroll-area/) props.                 |
| `CodeBlockContent`  | Accepts highlighted `children` and native pre props.                                                                                                                                 |
| `CodeBlockCopy`     | Accepts action [Button](/docs/button/) props. The default label is “Copy code”.                                                                                                      |
