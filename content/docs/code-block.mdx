## Usage

Use CodeBlock for a complete snippet a reader may copy. Use InlineCode for a command, path or identifier inside a sentence, and [Kbd](/docs/kbd/) for keys.

```tsx
<p>
  Install <InlineCode>@cognitap/radiant</InlineCode> first.
</p>
<CodeBlock code="pnpm add @cognitap/radiant" language="shell">
  <CodeBlockHeader>
    <span>Install command</span>
    <CodeBlockCopy>Copy install command</CodeBlockCopy>
  </CodeBlockHeader>
  <CodeBlockViewport aria-label="Install command" />
</CodeBlock>
```

CodeBlock includes no highlighting engine. Pass highlighted React nodes as CodeBlockContent children; copying still uses the raw code string.

## State

The application owns code and language; there is no editable value. Replacing code clears copy feedback and never copies automatically.

CodeBlockCopy is an action, not a toggle. It rejects pressed, defaultPressed and onPressedChange, never sets aria-pressed, and always renders `type="button"`, so it cannot submit a surrounding form.

Copying starts only on activation. The button stays focused and pending while one clipboard write runs; a second press waits. Feedback reports success, or asks the reader to copy manually when the clipboard is unavailable or refused. A result for replaced code is not announced.

## Accessibility

Name the viewport with aria-label or aria-labelledby. It is a focusable [ScrollArea](/docs/scroll-area/), so long lines stay keyboard reachable. Line numbers are hidden from assistive technology and excluded from copying.

| Key                   | Behavior                                 |
| --------------------- | ---------------------------------------- |
| Tab / Shift+Tab       | Reach the copy button, then the viewport |
| Enter / Space on copy | Copy the raw code                        |
| Arrow and paging keys | Scroll the focused viewport              |

A polite status output announces and displays feedback, and the copy button references it. Do not add a second live region for the same result.

The viewport defaults to left-to-right inside right-to-left pages. Set its dir for right-to-left source.

## Motion

CodeBlock adds no animation. CodeBlockCopy keeps Button's press motion and reduced-motion behavior.

## Styling

className, style and ref reach each part's host. The root carries data-language, data-line-numbers and data-copy-state (idle, pending, success or error). Inner slots are code-block-status, code-block-line-numbers and code-block-code.

`components.codeBlock` sets radius, border, surface, padding, header spacing, maxHeight, font size, line height, number gap and colors, and status color through `--rad-code-block-*`. `components.inlineCode` sets radius, padding, background, color and fontSize through `--rad-inline-code-*`.

## API

### CodeBlock

| Prop              | Type                  | Default                                                      |
| ----------------- | --------------------- | ------------------------------------------------------------ |
| code              | string                | Required                                                     |
| language          | string                | None; sets data-language only                                |
| lineNumbers       | boolean               | false                                                        |
| loadingText       | string                | 'Copying code…'                                              |
| copiedText        | string                | 'Code copied.'                                               |
| errorText         | string                | 'Could not copy code. Select the code and copy it manually.' |
| parts             | status style hook     | None                                                         |
| className / style | string / ThemeStyle   | None                                                         |
| ref               | `Ref<HTMLDivElement>` | None                                                         |
| Other props       | Native div props      | Native defaults                                              |

### CodeBlockHeader

| Prop        | Type                  | Default         |
| ----------- | --------------------- | --------------- |
| ref         | `Ref<HTMLDivElement>` | None            |
| Other props | Native div props      | Native defaults |

### CodeBlockViewport

| Prop                         | Type                                   | Default                |
| ---------------------------- | -------------------------------------- | ---------------------- |
| aria-label / aria-labelledby | string                                 | One required           |
| dir                          | ltr / rtl                              | ltr                    |
| orientation                  | vertical / horizontal / both           | both                   |
| children                     | ReactNode                              | `<CodeBlockContent />` |
| Other props                  | [ScrollArea](/docs/scroll-area/) props | ScrollArea defaults    |

### CodeBlockContent

| Prop        | Type                  | Default         |
| ----------- | --------------------- | --------------- |
| children    | Highlighted ReactNode | The code string |
| ref         | `Ref<HTMLPreElement>` | None            |
| Other props | Native pre props      | Native defaults |

### CodeBlockCopy

| Prop        | Type                                                        | Default                   |
| ----------- | ----------------------------------------------------------- | ------------------------- |
| children    | ReactNode                                                   | 'Copy code'               |
| pending     | boolean                                                     | false; true while copying |
| render      | (resolved: CodeBlockRenderProps) => ReactElement            | Native button             |
| Other props | [Button](/docs/button/) props except type and pressed state | Button defaults           |

### InlineCode

| Prop              | Type                | Default         |
| ----------------- | ------------------- | --------------- |
| children          | ReactNode           | None            |
| className / style | string / ThemeStyle | None            |
| ref               | `Ref<HTMLElement>`  | None            |
| Other props       | Native code props   | Native defaults |

Exports `InlineCodeProps`, each part's Props type and `CodeBlockRenderProps`.
