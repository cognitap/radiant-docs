## Usage

Use Separator to split related content into groups, such as settings sections or sets of actions. Inside menus, use the menu's own separator from [Menu](/docs/menu/), [Context Menu](/docs/context-menu/) or [Menubar](/docs/menubar/). Between crumbs, use `BreadcrumbSeparator` from [Breadcrumb](/docs/breadcrumb/). Separator never takes focus, so it can't be a resizable splitter.

```tsx
<section>…</section>
<Separator />
<section>…</section>
```

## Accessibility

Separator renders a native `<hr>`, whose implicit role is `separator`. It needs no accessible name.

By default the separator is semantic. Screen readers report a break between groups, and `aria-orientation` matches `orientation`. Keep it semantic when the line marks a real boundary that nothing else announces, such as two groups of actions in one row.

Set `decorative` when the line only repeats structure that is already there, such as a rule under a heading. It gets `aria-hidden="true"` and no `aria-orientation`, so screen readers skip it.

Separator owns `role`, `tabIndex`, `aria-hidden` and `aria-orientation`, and drops them if you pass them.

| Key             | Behavior                                  |
| --------------- | ----------------------------------------- |
| Tab / Shift+Tab | Skip the separator; it is never focusable |

## Styling

Separator is one part, with `data-slot="separator"`, `data-orientation` and, when decorative, `data-decorative`. `className`, `style` and `ref` reach the `<hr>`. Menu separators carry `data-slot="menu-separator separator"`.

`components.separator` sets `thickness`, `style` and `spacing`. Locally, set `--rad-separator-color` (the shared border color), `--rad-separator-thickness` (`1px`), `--rad-separator-style` (`solid`) and `--rad-separator-spacing` (`0`, a margin on the cross axis). Forced colors draw the line with `CanvasText`.

A vertical separator stretches to the height of a flex row. Anywhere else, give it a height.

## API

### Separator

| Prop        | Type                                                                                          | Default         |
| ----------- | --------------------------------------------------------------------------------------------- | --------------- |
| orientation | `Orientation`; horizontal / vertical                                                          | horizontal      |
| decorative  | boolean; hides the line from assistive technology                                             | false           |
| className   | string                                                                                        | None            |
| style       | ThemeStyle, including `--rad-separator-*`                                                     | None            |
| data-slot   | Extra tokens after `separator`                                                                | separator       |
| ref         | `Ref<HTMLHRElement>`                                                                          | None            |
| Other props | Native `<hr>` props except `role`, `tabIndex`, `aria-hidden`, `aria-orientation` and children | Native defaults |

Exports: `Separator`, `SeparatorProps`, `Orientation`.
