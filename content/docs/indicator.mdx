## Usage

Use Indicator for status attached to a specific target. Use [Badge](/docs/badge/) for status text that stands on its own.

```tsx
import { Button, Indicator } from '@cognitap/radiant'

;<Indicator
  label="Inbox"
  statusText="12 unread messages"
  count={12}
>
  {target => <Button {...target}>Inbox</Button>}
</Indicator>
```

## Accessibility

Use the target’s visible label as `label` and the full status as `statusText`. Apply the supplied accessible name directly to the Button, Link, or image. The visual marker is hidden from assistive technology. The target owns focus and keyboard behavior.

## Styling

`className`, `style`, and `ref` target the wrapper, which fits its target in a grid. Override the wrapper width for a full-width target. `parts.marker` styles the marker. Logical corners mirror with text direction.

## API

| Prop         | Type and default                                           |
| ------------ | ---------------------------------------------------------- |
| `label`      | Required base name.                                        |
| `statusText` | Required full status.                                      |
| `children`   | Render function receiving the target’s `aria-label`.       |
| `count`      | Nonnegative integer. Omit for a dot.                       |
| `maxCount`   | Maximum displayed count. Defaults to 99.                   |
| `position`   | top-end (default), top-start, bottom-end, or bottom-start. |
| `offset`     | CSS pixels outward from the corner. Defaults to 0.         |
| `tone`       | Badge palette. Defaults to accent.                         |
| `parts`      | marker.                                                    |

Exports Indicator, IndicatorProps, IndicatorPosition, and IndicatorTargetProps.
