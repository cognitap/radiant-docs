## Usage

Each item is a native `details` element, and the root decides which items are open. Give every item a stable, distinct string `value`. Use [Collapsible](/docs/collapsible/) for one independent section, [Tabs](/docs/tabs/) to switch between views where one is always shown, and [NavLinkGroup](/docs/nav-link/) for sidebar navigation.

```tsx
<Accordion defaultValue="start">
  <AccordionItem value="start">
    <AccordionTrigger>Where should I begin?</AccordionTrigger>
    <AccordionContent>Start with one clear next step.</AccordionContent>
  </AccordionItem>
  <AccordionItem value="next">
    <AccordionTrigger>What comes next?</AccordionTrigger>
    <AccordionContent>Make a little room to explore.</AccordionContent>
  </AccordionItem>
</Accordion>
```

## State

`type` sets the value shape and is fixed for the mount; remount with a new `key` to change it.

| `type`               | Value            | Initial |
| -------------------- | ---------------- | ------- |
| `'single'` (default) | `string \| null` | `null`  |
| `'multiple'`         | `string[]`       | `[]`    |

A single accordion opens one item at a time, and activating the open item closes it, leaving `null`. A multiple value lists items in the order they opened.

Use `defaultValue`, or `value` with `onValueChange`. Passing both, or switching owners after mount, throws. A controlled owner can refuse a request by keeping `value`.

```tsx
const [open, setOpen] = useState<string | null>('arrival')

<Accordion value={open} onValueChange={setOpen}>…</Accordion>
```

Accordion submits nothing. Closed content stays mounted, so its fields keep their values and submit with the form. Form reset restores those fields and leaves the open items alone.

`useAccordion()` returns `{ type, value, disabled, setItemOpen(value, open) }`, or `null` outside an Accordion. When content closes its own item, move focus back to its trigger, as the guide above does.

## Accessibility

Each trigger is a native `summary`, which the browser exposes as an expandable button named by its text. It wraps its children in an `h3`; set `level` to fit your page outline, or `null` when you supply your own heading. Keep buttons and links in the content, not the trigger. Disabled triggers get `aria-disabled="true"` and leave the Tab order.

| Key             | Behavior                                                      |
| --------------- | ------------------------------------------------------------- |
| Tab / Shift+Tab | Moves between triggers and into open content                  |
| Enter / Space   | Toggles the focused item; in single mode, closes the open one |

Arrow keys, Home and End do nothing special.

## Motion

Content height animates through `::details-content`, with a spring under `MotionProvider`, and the chevron rotates 90 degrees. Open state changes immediately. Turn motion off per item with `motion="off"`, with a theme whose `motion.mode` is `'off'`, or through the system reduced-motion setting. `--rad-collapsible-duration` sets the duration.

## Styling

`className`, `style` and `ref` target each part's host. A caller's `data-slot` is added to the built-in tokens, so select with `[data-slot~=accordion-item]`.

| Part             | Host      | `data-slot`                             | Data attributes                             |
| ---------------- | --------- | --------------------------------------- | ------------------------------------------- |
| Accordion        | `div`     | `accordion`                             | `data-type`, `data-disabled`                |
| AccordionItem    | `details` | `collapsible accordion-item`            | `data-state`, `data-disabled`, `data-value` |
| AccordionTrigger | `summary` | `collapsible-trigger accordion-trigger` | `data-state`, `data-disabled`               |
| AccordionContent | `div`     | `collapsible-content accordion-content` | `data-state`                                |

`--rad-accordion-gap` spaces the items. Items take every `--rad-collapsible-*` token.

## API

### Accordion

| Prop              | Type                                              | Default       |
| ----------------- | ------------------------------------------------- | ------------- |
| type              | `'single' \| 'multiple'`; fixed for the mount     | `'single'`    |
| value             | `string \| null` or `string[]`; controlled        | None          |
| defaultValue      | `string \| null` or `string[]`; uncontrolled      | `null` / `[]` |
| onValueChange     | `(value) => void`, with the value shape of `type` | None          |
| disabled          | boolean; blocks opening and closing every item    | false         |
| className / style | string / ThemeStyle                               | None          |
| Other props       | Native div props except defaultValue and onChange | Native        |

### AccordionItem

| Prop              | Type                                                         | Default   |
| ----------------- | ------------------------------------------------------------ | --------- |
| value             | string; stable and distinct within the accordion             | Required  |
| disabled          | boolean; also set by the root                                | false     |
| motion            | `'inherit' \| 'off'`                                         | `inherit` |
| onToggle          | `(event: ToggleEvent<HTMLDetailsElement>) => void`; observes | None      |
| className / style | string / ThemeStyle                                          | None      |
| Other props       | Native details props except open and name                    | Native    |

### AccordionTrigger

| Prop              | Type                                       | Default |
| ----------------- | ------------------------------------------ | ------- |
| level             | `1`–`6` or `null`; heading around children | `3`     |
| className / style | string / ThemeStyle                        | None    |
| Other props       | Native summary props                       | Native  |

### AccordionContent

| Prop              | Type                | Default |
| ----------------- | ------------------- | ------- |
| className / style | string / ThemeStyle | None    |
| Other props       | Native div props    | Native  |

Exports: `Accordion`, `AccordionItem`, `AccordionTrigger`, `AccordionContent`, `useAccordion`, `AccordionProps`, `AccordionItemProps`, `AccordionTriggerProps`, `AccordionContentProps`, `AccordionHeadingLevel`, `AccordionValue`, `AccordionState`.
