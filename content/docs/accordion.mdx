## Group related answers

```tsx
<Accordion defaultValue="start">
  <AccordionItem value="start">
    <AccordionTrigger>Where should I begin?</AccordionTrigger>
    <AccordionContent>Start with one clear next step.</AccordionContent>
  </AccordionItem>
  <AccordionItem value="next">
    <AccordionTrigger>What comes next?</AccordionTrigger>
    <AccordionContent>Make a little room to explore.</AccordionContent>
  </AccordionItem>
</Accordion>
```

Accordion owns selection. Items reuse [Collapsible](/docs/collapsible/): native
`details`, a direct-child `summary`, and a normal-flow Content wrapper. Give
each item a stable, distinct string value and React key; an empty string is valid.
Single selection opens at most one item; activating it again closes all.

Tab reaches enabled summaries and open content. Enter and Space toggle the
focused summary; arrow keys have no special behavior. Trigger places a heading
inside summary, defaulting to h3. Choose its `level` for your page outline, or
`null` to supply your own heading. Keep links and buttons in Content.

## Own selection once

```tsx
const [value, setValue] = useState<string[]>(['start'])

<Accordion type="multiple" value={value} onValueChange={setValue}>
  {items}
</Accordion>
```

Multiple selection uses `string[]`; single uses `string | null`. Clear with
`[]` or `null`. Choose controlled `value` or initial `defaultValue`, never both.
Remount with a new key to change type or ownership. Control the root, not each
item's open state. `onValueChange` requests updates; an owner may decline.
No-op requests and prop synchronization do not notify. Item `onToggle` remains
a native observation.

Root and item disabled states add up. Disabled summaries guard activation and
leave the Tab sequence; application changes to controlled selection still work.
Closing keeps fields mounted, retains their values and includes them in
FormData. Native reset restores uncontrolled fields without resetting selection.
Nested disclosures keep their own state.

## Add motion

```tsx
import { MotionProvider } from '@cognitap/radiant/motion/react'

;<MotionProvider>
  <Accordion defaultValue="start">
    <AccordionItem
      value="start"
      motion="inherit"
    >
      <AccordionTrigger>Details</AccordionTrigger>
      <AccordionContent>{details}</AccordionContent>
    </AccordionItem>
  </Accordion>
</MotionProvider>
```

The shared disclosure engine springs natural height without scaling content.
Rapid switches retarget moving items; dynamic content is measured as it grows.
Item `motion="off"`, theme off and live reduced motion settle presentation;
selection stays immediate. See [Collapsible](/docs/collapsible/#add-motion-and-dynamic-content)
for measurement and browser fallback, and [motion setup](/docs/foundations/motion/).
Native disclosures work before hydration; coordinated selection and disabled
guards need JavaScript.

## Parts and customization

| Component        | Native style/ref target | Identity tokens                       |
| ---------------- | ----------------------- | ------------------------------------- |
| Accordion        | div                     | accordion                             |
| AccordionItem    | details                 | collapsible accordion-item            |
| AccordionTrigger | summary                 | collapsible-trigger accordion-trigger |
| AccordionContent | div                     | collapsible-content accordion-content |

Parts accept native props, className, typed theme style and DOM refs. Match
additive identities with `[data-slot~="accordion-item"]`. Items expose
`data-value`, `data-state` and optional `data-disabled`; root exposes `data-type`.

Set `--rad-accordion-gap` on the root for spacing; Collapsible tokens style its
items. Preserve focus and hidden-content behavior. `useAccordion()` returns
nearest owner state and `setItemOpen(value, open)`, or null outside one.
When an action closes its own answer, return focus to its summary.

## Public props

All part prop types, AccordionValue, AccordionState and AccordionHeadingLevel
are exported.

| Root prop            | Purpose / default                                    |
| -------------------- | ---------------------------------------------------- |
| type                 | single (default) or multiple; fixed per mount        |
| value / defaultValue | Controlled or initial selection; initially null / [] |
| onValueChange        | Matching string-or-null / string-array request       |
| disabled             | Guard user selection; false                          |
| Native div props     | Attributes, events, children, className, style, ref  |

| Part prop                      | Purpose                                                       |
| ------------------------------ | ------------------------------------------------------------- |
| Item value                     | Required stable, distinct string                              |
| Item disabled                  | Add to root disabled state                                    |
| Item motion                    | inherit (default) or off                                      |
| Item native props              | Details props except owned open/defaultOpen/onOpenChange/name |
| Trigger level                  | Inner heading 1–6, default 3; null omits heading              |
| Trigger / Content native props | Summary/div attributes, styles, refs                          |
| data-slot                      | Additional identities on all hosts                            |
