## Choose a selection model

Accordion coordinates [Collapsible](/docs/collapsible/) items. Each remains
native `details` with a direct-child `summary`. The root owns selection; each
item has a distinct `value`.

Single selection opens at most one item; opening another closes the first, and
activating the open summary again leaves all items closed. Multiple selection
lets several stay open. Accordion's type and ownership stay fixed during a mount.
A nested disclosure inside an item does not change the Accordion's selection.

## Keyboard, disabled state and content

Tab reaches enabled summaries and links in open content. Enter and Space toggle
the focused summary. There is no arrow-key navigation. Closed content stays
mounted and is hidden from keyboard navigation.

A disabled item's summary has `aria-disabled`, is removed from the tab sequence
and guards pointer/Enter/Space activation. Disabled state blocks user changes, not
your application's control of selection.

Native details expand without JavaScript. Coordinated selection, disabled
guards and controlled state require it. The stylesheet provides closed-content
and focus behavior.

## Controlled or local selection

In single mode the value is a string or `null`; in multiple mode it is a string
array. Use `null` or `[]` to clear a controlled selection, not `undefined`,
which changes ownership. Summaries request updates through `onValueChange`.
Give the Accordion a new `key` to change its `type` or ownership. Do not
control each item's `open` yourself.

## Named parts and targets

| Component        | Native style/ref target | `data-slot` tokens                      |
| ---------------- | ----------------------- | --------------------------------------- |
| Accordion        | `div`                   | `accordion`                             |
| AccordionItem    | `details`               | `collapsible accordion-item`            |
| AccordionTrigger | `summary`               | `collapsible-trigger accordion-trigger` |
| AccordionContent | `div`                   | `collapsible-content accordion-content` |

Match identities as tokens, such as `[data-slot~="accordion-item"]`. The root exposes `data-type` and optional
`data-disabled`. Items expose `data-value`, optional `data-disabled` and
`data-state`; trigger/content also expose `data-state`.

AccordionTrigger places a heading **inside** the direct-child summary.
Its native attributes, styles and ref target the summary. Never put a button
or link inside AccordionTrigger.

`components.accordion.gap` spaces the items. Items inherit
`components.collapsible` values, so a Collapsible token such as padding on the
Accordion root reaches every item. `useAccordion()` returns the nearest
owner state, or `null` outside an Accordion.

## Public props

Each component's prop type, `AccordionValue`, `AccordionHeadingLevel` and
`AccordionState` are exported.

| Accordion prop           | Purpose / default                                                |
| ------------------------ | ---------------------------------------------------------------- |
| `type`                   | `single` (default) or `multiple`; fixed per mount                |
| `value` / `defaultValue` | Controlled or initial local selection; defaults to `null` / `[]` |
| `onValueChange`          | Receives the matching string-or-null / string-array selection    |
| `disabled`               | Disable user interaction for all items; defaults to `false`      |
| Native div props         | Root attributes, events, children, styling and ref               |

| Part prop                      | Purpose                                                                      |
| ------------------------------ | ---------------------------------------------------------------------------- |
| Item `value`                   | Required distinct string identifying this item                               |
| Item `disabled`                | Disable this item; root disabled state also applies                          |
| Item native props              | Details props/styles/ref, excluding owned open/defaultOpen/onOpenChange/name |
| Trigger `level`                | Inner heading level `1`–`6`, default `3`; `null` omits the heading           |
| Trigger / Content native props | Summary/div props, styles and refs                                           |
| `data-slot`                    | Additive identities on root and named parts                                  |

## Use the example

Keep the `compositions/` paths when copying. It needs only React and Radiant.
For an independent disclosure, use [Collapsible](/docs/collapsible/); for
passive grouping of content and actions, use [Card](/docs/card/).
