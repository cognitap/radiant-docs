## Usage

Use Pagination when results are split into numbered pages a reader can return to. Use [Breadcrumb](/docs/breadcrumb/) for a place in a hierarchy, [Tabs](/docs/tabs/) for switching panels in place and [NavLink](/docs/nav-link/) for site navigation. For a feed read top to bottom, load more on scroll or with a "Load more" [Button](/docs/button/) instead.

```tsx
<Pagination aria-label="Search result pages">
  <PaginationList>
    <PaginationItem>
      <PaginationUnavailable>Previous</PaginationUnavailable>
    </PaginationItem>
    <PaginationItem>
      <PaginationLink
        href="?page=1"
        current
        aria-label="Page 1"
      >
        1
      </PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="?page=2" />
    </PaginationItem>
  </PaginationList>
</Pagination>
```

Pages are `medium` by default, like Button and Link. Set `controlSize="small"` for a compact pager.

## State

Pagination keeps no state and submits nothing. Set `current` on exactly one link or button. The application owns page counts, routing, fetching and focus after content changes. With `PaginationButton`, disable Previous and Next at the ends and move focus to the reached page, as the record demo above does.

## Accessibility

Pagination is a `nav` landmark named "Pagination". Give each pager on a page a distinct `aria-label`, or `aria-labelledby` for a visible heading. A blank name throws. Pages sit in an ordered list. The current page gets `aria-current="page"`. Label number-only pages, such as "Page 2".

`PaginationUnavailable` renders text with `aria-disabled="true"` and no focus stop, since a link cannot be disabled. Disabled `PaginationButton` boundaries use native `disabled`. The ellipsis is hidden from assistive technology.

| Key                     | Behavior                                              |
| ----------------------- | ----------------------------------------------------- |
| Tab / Shift+Tab         | Move between links and enabled buttons                |
| Enter on a link         | Follow the URL                                        |
| Enter / Space on button | Run `onClick`; disabled and pending buttons ignore it |

## Motion

Links and buttons use Button's press motion. It stops under reduced motion and with `motion="off"` inside a `MotionProvider`. Forced colors keep the current page visible.

## Styling

| Part                      | `data-slot`                                    |
| ------------------------- | ---------------------------------------------- |
| Pagination                | `pagination`                                   |
| PaginationList / Item     | `pagination-list` / `pagination-item`          |
| PaginationLink            | `link pagination-link`                         |
| PaginationPrevious / Next | adds `pagination-previous` / `pagination-next` |
| PaginationButton          | `button pagination-button`                     |
| PaginationUnavailable     | `pagination-unavailable`                       |
| PaginationEllipsis        | `pagination-ellipsis`                          |

Links and buttons also set `data-variant`, `data-tone` and `data-control-size`. `className` and `style` reach each part's host.

| Variable                          | Default                        |
| --------------------------------- | ------------------------------ |
| `--rad-pagination-gap`            | 0.25rem                        |
| `--rad-pagination-radius`         | `--rad-control-radius`, 0.5rem |
| `--rad-pagination-item-min-width` | 2rem                           |

Theme keys are `components.pagination.gap`, `radius` and `itemMinWidth`.

## API

### Pagination

| Prop            | Type / default                    |
| --------------- | --------------------------------- |
| aria-label      | string; "Pagination"              |
| aria-labelledby | string; replaces the default name |
| Other props     | Native `nav` props                |

`PaginationList` (`ol`) and `PaginationItem` (`li`) take native props.

### PaginationLink

| Prop        | Type / default                               |
| ----------- | -------------------------------------------- |
| href        | Required string                              |
| current     | boolean; false; sets `aria-current="page"`   |
| variant     | Link variant; solid when current, else ghost |
| tone        | accent when current, else neutral            |
| controlSize | small / medium / large; medium               |
| external    | boolean; false                               |
| render      | (props: PaginationLinkRenderProps) => anchor |

### PaginationPrevious / PaginationNext

| Prop        | Type / default                                                    |
| ----------- | ----------------------------------------------------------------- |
| children    | ReactNode; "Previous" / "Next"                                    |
| rel         | string; `prev` / `next`, plus `noopener noreferrer` when external |
| Other props | PaginationLink props except `current`                             |

### PaginationButton

| Prop               | Type / default                                |
| ------------------ | --------------------------------------------- |
| current            | boolean; false; sets `aria-current="page"`    |
| variant / tone     | As PaginationLink                             |
| controlSize        | small / medium / large; medium                |
| disabled / pending | boolean; false                                |
| type               | "button"                                      |
| Other props        | Button props except `aria-current` and `role` |

### PaginationUnavailable / PaginationEllipsis

| Prop        | Type / default                                                            |
| ----------- | ------------------------------------------------------------------------- |
| children    | ReactNode; ellipsis defaults to "…"                                       |
| Other props | Native `span` props except `aria-disabled` / `aria-hidden` and `tabIndex` |

Every part strips `role`. Exports `PaginationProps`, `PaginationListProps`, `PaginationItemProps`, `PaginationLinkProps`, `PaginationLinkRenderProps`, `PaginationPreviousProps`, `PaginationNextProps`, `PaginationButtonProps`, `PaginationUnavailableProps` and `PaginationEllipsisProps`.
