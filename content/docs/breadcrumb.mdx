## Usage

Breadcrumb is a named navigation landmark: an ordered list of ancestor links ending in the current page. Your application owns the hierarchy. Use [NavLink](/docs/nav-link/) for site navigation between sections, [Pagination](/docs/pagination/) for moving through pages of one list, and a plain [Link](/docs/link/) for a single "Back to" link.

```tsx
<Breadcrumb aria-label="Breadcrumb">
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/projects">Projects</BreadcrumbLink>
      <BreadcrumbSeparator />
    </BreadcrumbItem>
    <BreadcrumbItem>
      <BreadcrumbPage>Reader study</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

`BreadcrumbLink` defaults to the `subtle` variant and `neutral` tone. A trail repeats on every page, so it stays muted and underlines only on hover rather than competing with the page's own links. Both can be overridden.

## Accessibility

Breadcrumb renders a `nav` and requires `aria-label` or `aria-labelledby`; it throws without a name. Give each nav on a page a distinct one.

Mark exactly one current page. `BreadcrumbPage` renders an unfocusable span with `aria-current="page"`. Set `current` on a BreadcrumbLink when the current page should stay a link. Both set `data-selected` on the current item. Neither part accepts `aria-current` directly.

Separators are `aria-hidden="true"` and never focusable, so screen readers hear only destinations. Put each inside a BreadcrumbItem, not directly under the list.

| Key             | Behavior                                                        |
| --------------- | --------------------------------------------------------------- |
| Tab / Shift+Tab | Move between the trail's links; skip the page and separators    |
| Enter           | Follow the focused link; a router adapter can handle plain ones |

## Motion

Only BreadcrumbLink's color fades on hover, as in Link. Set `--rad-link-color-duration` to change it; reduced motion turns it off.

## Styling

`className`, `style` and `ref` reach each part's host: `nav`, `ol`, `li`, `a`, `span` and `span`. Each part sets a `data-slot`, followed by a caller's; BreadcrumbLink keeps Link's `link` slot, `data-variant`, `data-tone` and `data-control-size`.

| Part                | `data-slot`            |
| ------------------- | ---------------------- |
| Breadcrumb          | `breadcrumb`           |
| BreadcrumbList      | `breadcrumb-list`      |
| BreadcrumbItem      | `breadcrumb-item`      |
| BreadcrumbLink      | `link breadcrumb-link` |
| BreadcrumbPage      | `breadcrumb-page`      |
| BreadcrumbSeparator | `breadcrumb-separator` |

Theme keys live under `components.breadcrumb`.

| Variable                            | Default                |
| ----------------------------------- | ---------------------- |
| `--rad-breadcrumb-gap`              | 0.5rem                 |
| `--rad-breadcrumb-font-size`        | UI body size, 0.875rem |
| `--rad-breadcrumb-color`            | Muted foreground       |
| `--rad-breadcrumb-link-color`       | Muted foreground       |
| `--rad-breadcrumb-link-hover-color` | Foreground             |
| `--rad-breadcrumb-current-color`    | Foreground             |
| `--rad-breadcrumb-separator-color`  | Muted foreground       |

## API

Every part also takes its host's native props and `style?: ThemeStyle`. `role` is not accepted.

### Breadcrumb

| Prop            | Type   | Default                                     |
| --------------- | ------ | ------------------------------------------- |
| aria-label      | string | None; this or `aria-labelledby` is required |
| aria-labelledby | string | None                                        |

### BreadcrumbList and BreadcrumbItem

Native `ol` and `li` props.

### BreadcrumbLink

| Prop        | Type                                               | Default       |
| ----------- | -------------------------------------------------- | ------------- |
| href        | string                                             | Required      |
| current     | boolean; sets `aria-current="page"`                | false         |
| variant     | LinkVariant                                        | subtle        |
| tone        | Tone                                               | neutral       |
| controlSize | small / medium / large; action variants only       | medium        |
| external    | boolean; sets target `_blank` and rel              | false         |
| render      | (props: BreadcrumbLinkRenderProps) => ReactElement | Native anchor |

Takes every other [Link](/docs/link/) prop except `aria-current`.

### BreadcrumbPage

Native `span` props, without `aria-current`. Always sets `aria-current="page"`.

### BreadcrumbSeparator

| Prop     | Type      | Default |
| -------- | --------- | ------- |
| children | ReactNode | "/"     |

Native `span` props, without `aria-hidden` or `tabIndex`.

Exports: `BreadcrumbProps`, `BreadcrumbListProps`, `BreadcrumbItemProps`, `BreadcrumbLinkProps`, `BreadcrumbLinkRenderProps`, `BreadcrumbPageProps` and `BreadcrumbSeparatorProps`. `BreadcrumbLinkRenderProps` is Link's render props with `href: string` and a `data-slot` that includes `link breadcrumb-link`.
