## Usage

Button defaults to `type="button"`. Use `type="submit"` to submit a form. Use [Link](/docs/link/) for navigation or [ButtonGroup](/docs/button-group/) for adjacent actions.

## State

Set `pending` while work runs. The button keeps focus and its label and blocks activation.

Use `defaultPressed` for an uncontrolled toggle or `pressed` with `onPressedChange` for a controlled toggle. Use [ToggleGroup](/docs/toggle-group/) for related choices.

## Accessibility

Name icon-only buttons with `aria-label` or `aria-labelledby`. Keep a toggle's label the same when its pressed state changes.

## Motion

Use [MotionProvider](/docs/foundations/motion/) for spring motion on press. Set `motion="off"` to turn off spatial motion. The pending spinner gives way to the label when the user prefers reduced motion.

## Styling

Use `components.button` to theme Button. See [focus outlines](/docs/foundations/theming/#focus-outlines) for keyboard focus styles.

## API

Button accepts native button props and events.

| Prop                                           | Purpose                                                    |
| ---------------------------------------------- | ---------------------------------------------------------- |
| `variant`                                      | `solid` (default), `soft`, `outline`, or `ghost`.          |
| `tone`                                         | `accent` (default), `neutral`, `warning`, or `danger`.     |
| `controlSize`                                  | `small`, `medium` (default), or `large`.                   |
| `iconOnly`, `fullWidth`                        | Square icon button or fill the available width.            |
| `pending`                                      | Blocks activation and sets `aria-busy`.                    |
| `pressed`, `defaultPressed`, `onPressedChange` | Control or initialize a toggle and receive its changes.    |
| `motion`                                       | `inherit` (default) or `off`.                              |
| `render`                                       | Return a button that forwards the props, ref and children. |
| `className`, `style`, `ref`                    | Target the native button with `data-slot="button"`.        |
