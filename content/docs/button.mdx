## Usage

Use Button for an action, a form submission or, with a pressed prop, a two-state toggle. Choose something else when:

- [Link](/docs/link/): navigation. Button cannot render an anchor.
- [ToggleGroup](/docs/toggle-group/): several related pressed buttons.
- [ButtonGroup](/docs/button-group/): adjacent actions joined visually.
- [Toolbar](/docs/toolbar/): a set of controls reached with arrow keys.

Dialogs, menus and popovers open from their own Trigger.

```tsx
<Button
  type="submit"
  pending={saving}
>
  Save changes
</Button>
<Button
  iconOnly
  aria-label="Bold"
  pressed={bold}
  onPressedChange={setBold}
>
  <BoldIcon />
</Button>
```

## State

Any pressed prop turns on toggle mode. Use `pressed` with `onPressedChange` to control it, or `defaultPressed`; switching owner throws. Call `preventDefault` in `onClick` to refuse a change. Form reset leaves pressed state unchanged.

`type` defaults to `"button"`, not the native `"submit"`. With `type="submit"`, native `name`, `value`, `form` and `formAction` reach the submitter. `pending` cancels the click before your `onClick`, so a pending submit does not submit and a pending toggle does not flip.

## Accessibility

Button renders a native `<button>`. A toggle (`pressed`) keeps one stable label. A button that renames itself to name its next action, such as "Show password", is an action and must not set `pressed`.

Give `iconOnly` buttons an `aria-label`. `pending` sets `aria-busy="true"`, keeps focus and keeps the name.

| Key             | Behavior                                    |
| --------------- | ------------------------------------------- |
| Tab / Shift+Tab | Reach enabled buttons; pending ones stay in |
| Enter           | Activate; a toggle flips                    |
| Space           | Activate on release; a toggle flips         |

## Motion

Inside a [`MotionProvider`](/docs/foundations/motion/), a spring scales, moves and reshapes the pressed button. Turn it off with `motion="off"`, theme `motion.mode: 'off'` or the reduced-motion preference. A caller `scale` style or `scale-*` class replaces the press scale. Under reduced motion the pending spinner hides.

## Styling

`className`, `style`, `ref` and native props reach the button. Select it with `[data-slot~="button"]`; your `data-slot` tokens are appended. Style state with `data-variant`, `data-tone`, `data-control-size`, `aria-pressed`, `aria-busy` and `:disabled`. Keep the focus ring and the pressed cue, an inset ring that becomes a double underline in forced colors.

Theme keys live under `components.button`, such as `radius`, `radiusPressed`, `cornerShape`, `shadowPressed`, `pressScale` and `selectedLayer`. Override one in `style`, as in `--rad-button-radius`.

A pressed button, and a ToggleGroup item, mixes `selectedLayer` (20% by default) of its text color into its fill, so the state stays visible on every variant.

## API

| Prop              | Type                                          | Default              |
| ----------------- | --------------------------------------------- | -------------------- |
| variant           | solid / soft / outline / ghost                | solid                |
| tone              | accent / neutral / warning / danger           | accent               |
| controlSize       | small / medium / large                        | medium               |
| iconOnly          | boolean; square, needs `aria-label`           | false                |
| fullWidth         | boolean                                       | false                |
| pending           | boolean; blocks activation, sets `aria-busy`  | false                |
| disabled          | boolean; native                               | false                |
| pressed           | boolean; controlled toggle                    | None                 |
| defaultPressed    | boolean; uncontrolled toggle                  | false in toggle mode |
| onPressedChange   | `(pressed: boolean) => void`                  | None                 |
| aria-pressed      | boolean / 'mixed'; only without pressed props | None                 |
| type              | button / submit / reset                       | button               |
| motion            | inherit / off                                 | inherit              |
| render            | `(props: ButtonRenderProps) => ReactElement`  | Native button        |
| data-slot         | string; extra identity tokens                 | button               |
| className / style | string / ThemeStyle                           | None                 |
| ref               | `Ref<HTMLButtonElement>`                      | None                 |
| Native attributes | Button attributes and events                  | Native               |

`render` must return one button, or a component that forwards every prop, the ref and children to one. `ButtonProps` is a union, so extend it with `ButtonProps & { hint?: string }`, not an interface.

Exports `Button`, `ButtonProps`, `ButtonRenderProps` and `ButtonVariant`.
