## State

Opt into toggling with `pressed`, `defaultPressed` or `onPressedChange`. Use one owner: controlled callbacks request changes; prop sync fires none. Ordinary actions omit `aria-pressed`. Raw `aria-pressed` supports application-owned mixed state. Form reset leaves pressed state unchanged.

`disabled` uses native behavior. `pending` blocks activation before the consumer handler, preserves focus and the name, and shows decorative progress. The application owns async work and duplicate-submit guards. Prevent default in `onClick` to cancel a pressed-state request.

## Accessibility

Keep toggle labels stable. Give icon-only actions an accessible name and hide decorative icons. Native `type="submit"` and `type="reset"` retain form behavior.

| Key             | Behavior                                       |
| --------------- | ---------------------------------------------- |
| Tab / Shift+Tab | Reach enabled actions; pending stays focusable |
| Enter           | Native activation                              |
| Space           | Native activation on release                   |

## Motion

`MotionProvider` from `@cognitap/radiant/motion/react` enables theme press springs. Local off and system reduced motion win. Physical feedback is independent from pressed state.

## Styling

Props, ref, classes and typed styles target the button. `data-slot` retains `button`; `data-variant`, `data-tone` and `data-control-size` describe presentation. Style `aria-pressed`, `aria-busy` and `:disabled`; retain focus and selected cues.

Use `components.button` or `--rad-button-*` overrides. A custom `render` forwards all resolved props, ref and children to one compatible button; children include pending presentation.

## API

| Button prop                  | Type                                          | Default             |
| ---------------------------- | --------------------------------------------- | ------------------- |
| variant                      | solid / soft / outline / ghost                | solid               |
| tone                         | accent / neutral / warning / danger           | accent              |
| controlSize                  | small / medium / large                        | medium              |
| pressed / defaultPressed     | boolean; exclusive owner                      | false when opted in |
| onPressedChange              | (pressed: boolean) => void                    | None                |
| pending / disabled           | boolean                                       | false               |
| iconOnly / fullWidth         | boolean                                       | false               |
| motion                       | inherit / off                                 | inherit             |
| type                         | button / submit / reset                       | button              |
| render                       | (resolved: ButtonRenderProps) => ReactElement | Native button       |
| className / style            | string / ThemeStyle                           | None                |
| data-slot                    | Additional identity tokens                    | button              |
| children                     | ReactNode                                     | None                |
| ref                          | `Ref<HTMLButtonElement>`                      | None                |
| Native attributes and events | Includes form, name, value and onClick        | Native defaults     |

Exports: `Button`, `ButtonProps`, `ButtonRenderProps`, `ButtonVariant`.
