## Usage

Use AlertDialog when the user must confirm or cancel before continuing, such as discarding work or deleting data. Use [Dialog](/docs/dialog/) when the user isn't being asked to confirm or cancel, [Toast](/docs/toast/) or [Alert](/docs/alert/) for feedback that needs no decision, and [Popover](/docs/popover/) for a choice that shouldn't block the page.

```tsx
<AlertDialog>
  <AlertDialogTrigger>Discard draft</AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogTitle>Discard unsaved changes?</AlertDialogTitle>
    <AlertDialogDescription>Your latest edits will be lost.</AlertDialogDescription>
    <AlertDialogCancel
      variant="outline"
      tone="neutral"
    >
      Keep editing
    </AlertDialogCancel>
    <AlertDialogAction
      tone="danger"
      onClick={discard}
    >
      Discard changes
    </AlertDialogAction>
  </AlertDialogContent>
</AlertDialog>
```

## State

Open state follows [Dialog](/docs/dialog/#state): controlled `open` with `onOpenChange`, or `defaultOpen`. A controlled owner may refuse a request.

AlertDialog is always modal. Backdrop clicks never close it; `modal` and `closeOnBackdrop` are type errors.

Action and Cancel run `onClick`, then request close. Call `event.preventDefault()` to keep it open while async work runs. `pending` or `disabled` blocks both the handler and the request. Both are `type="button"` and never submit an ancestor form.

`useAlertDialog()` returns Dialog state inside AlertDialog, or `null` elsewhere.

## Accessibility

Content is a native `dialog` with protected `role="alertdialog"` and `aria-modal="true"`. Title names it and Description is always in `aria-describedby`. Use one of each, or `aria-label` with a Description.

Cancel takes focus on every open, even after Action in DOM order. Set `autoFocus={false}` on Cancel to focus something else. Focus returns to the opener; if it's gone, move focus yourself.

| Key                      | Behavior                                                                     |
| ------------------------ | ---------------------------------------------------------------------------- |
| Enter / Space on Trigger | Opens; focus moves to Cancel                                                 |
| Tab / Shift+Tab          | Moves between controls; the page behind is inert                             |
| Enter / Space on Cancel  | Closes; focus returns to the opener                                          |
| Enter / Space on Action  | Runs `onClick`, then closes unless prevented                                 |
| Escape                   | Closes like Cancel, unless `closeOnEscape={false}` or `onCancel` prevents it |

## Motion

Inside a `MotionProvider`, Content springs open and Trigger, Action and Cancel compress on press. Native close never waits. Set `motion="off"` on Content or each button part. Reduced motion removes transitions.

## Styling

`className`, `style` and `ref` reach each host. Parts keep Dialog's `data-slot` tokens and add their own; match them with `~=`.

| Part                   | Host     | data-slot                                                    |
| ---------------------- | -------- | ------------------------------------------------------------ |
| AlertDialog            | None     | None                                                         |
| AlertDialogTrigger     | `button` | `button dialog-trigger alert-dialog-trigger`                 |
| AlertDialogContent     | `dialog` | `dialog alert-dialog`; `data-state="open" \| "closed"`       |
| AlertDialogTitle       | `h2`     | `dialog-title alert-dialog-title`                            |
| AlertDialogDescription | `p`      | `dialog-description alert-dialog-description`                |
| AlertDialogAction      | `button` | `button dialog-close alert-dialog-close alert-dialog-action` |
| AlertDialogCancel      | `button` | `button dialog-close alert-dialog-close alert-dialog-cancel` |

Content uses `--rad-dialog-*` variables, such as `--rad-dialog-width` and `--rad-dialog-backdrop`. Title and Description use `--rad-dialog-title-*` and `--rad-dialog-description-*`.

## API

### AlertDialog

| Prop               | Type / default                       |
| ------------------ | ------------------------------------ |
| open / defaultOpen | boolean; one owner; initially closed |
| onOpenChange       | (open: boolean) => void              |
| closeOnEscape      | boolean; true                        |
| children           | Trigger and Content                  |

### AlertDialogTrigger, AlertDialogAction, AlertDialogCancel

| Prop                 | Type / default                                     |
| -------------------- | -------------------------------------------------- |
| variant              | solid / soft / outline / ghost; solid              |
| tone                 | accent / neutral / warning / danger; accent        |
| controlSize          | small / medium / large; medium                     |
| pending / disabled   | boolean; false; blocks the handler and request     |
| iconOnly / fullWidth | boolean; false                                     |
| motion               | inherit / off; inherit                             |
| type                 | button / submit / reset; button                    |
| onClick              | Runs first; `preventDefault()` cancels the request |
| render               | (props: AlertDialogRenderProps) => ReactElement    |
| autoFocus            | boolean; true on Cancel                            |
| ref                  | HTMLButtonElement                                  |

### AlertDialogContent

| Prop        | Type / default                                        |
| ----------- | ----------------------------------------------------- |
| motion      | inherit / off; inherit                                |
| onCancel    | Native Escape event; `preventDefault()` keeps it open |
| onClose     | Native close event                                    |
| aria-label  | string; names it without a Title                      |
| ref         | HTMLDialogElement                                     |
| Other props | Native dialog props except open, role and aria-modal  |

### AlertDialogTitle, AlertDialogDescription

| Prop        | Type / default                            |
| ----------- | ----------------------------------------- |
| ref         | HTMLHeadingElement / HTMLParagraphElement |
| Other props | Native h2 / p props                       |

All parts accept `className` and ThemeStyle. Exports each part's `AlertDialog…Props` type, `AlertDialogState`, `AlertDialogRenderProps` and `useAlertDialog`.
