## Usage

Use AppShell to frame a whole application. Use [NavigationMenu](/docs/navigation-menu/) for site dropdowns, [Drawer](/docs/drawer/) for a side task and [Resizable](/docs/resizable/) for panes people resize.

```tsx
<AppShell>
  <AppShellSkipLink>Skip to content</AppShellSkipLink>
  <AppShellHeader>
    <SidebarTrigger>Toggle navigation</SidebarTrigger>
  </AppShellHeader>
  <Sidebar label="Projects">
    <NavLink
      href="/atlas"
      icon={<FolderIcon />}
    >
      <SidebarLabel>Atlas</SidebarLabel>
    </NavLink>
  </Sidebar>
  <AppShellMain>…</AppShellMain>
</AppShell>
```

Render AppShell once per page. Wrap link text in SidebarLabel so it hides when the Sidebar collapses, and put controls that need the full width in `SidebarContent expandedOnly`.

## State

AppShell owns two booleans. `collapsed` narrows the desktop Sidebar; `open` shows the mobile drawer. Pass `defaultCollapsed` or `collapsed` with `onCollapsedChange`, and `defaultOpen` or `open` with `onOpenChange`. A controlled owner may refuse a request.

Below 40rem of shell width, not viewport width, the Sidebar moves into the drawer. A content-sized shell is 64rem wide, up to the viewport. Returning to desktop requests `open` false. Links stay mounted across the move, so field values survive.

`useAppShell()` returns `null` outside AppShell, otherwise the state and request methods. The Sidebar does not close on navigation; call `setOpen(false)` when a link routes. AppShell has no form value; save `collapsed` to restore a layout.

## Accessibility

The header is a banner, the main a focusable main landmark and the Sidebar a `nav` named by its visible `label`. AppShellSkipLink moves to the main; set `mainId` for a stable target. SidebarTrigger sets `aria-expanded` and `aria-controls` for the Sidebar or the drawer, plus `aria-haspopup` on mobile. Give an icon-only trigger an `aria-label`.

The mobile drawer is a modal [Drawer](/docs/drawer/) titled by `label`, with a close button named by `closeLabel`. With a `close` icon from [IconProvider](/docs/icon-provider/), that button is icon-only. Collapsing while focus sits in expanded-only content moves focus to the trigger.

| Key           | Behavior                                                           |
| ------------- | ------------------------------------------------------------------ |
| Tab           | Normal order; inside the drawer, focus stays there                 |
| Enter / Space | On the trigger, collapse or expand the Sidebar, or open the drawer |
| Arrow keys    | Scroll the focused Sidebar                                         |
| Escape        | Close the mobile drawer and restore focus                          |

## Motion

Under `MotionProvider`, the Sidebar and main spring to their new widths on collapse, and the drawer slides. `motion="off"` on AppShell or reduced motion removes both.

## Styling

| Part           | Slot and attributes                                                                                                                                                                                         |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Root           | `app-shell` div; `data-collapsed`, `data-mobile`, `data-state` (open/closed), `data-motion`                                                                                                                 |
| Header         | `app-shell-header` header                                                                                                                                                                                   |
| Main           | `app-shell-main` main                                                                                                                                                                                       |
| Skip link      | `link app-shell-skip-link` a                                                                                                                                                                                |
| Sidebar        | `sidebar` nav; `data-collapsed`, `data-state`; label `sidebar-label` h2                                                                                                                                     |
| Trigger        | `button sidebar-trigger`; `data-state` (open while expanded or while the drawer is open)                                                                                                                    |
| Label          | `sidebar-item-label` span                                                                                                                                                                                   |
| Content        | `sidebar-content` div; `data-expanded-only`                                                                                                                                                                 |
| Theme: shell   | `components.appShell`: `background`, `color`, `headerBackground`, `headerColor`, `headerPadding` (`1rem`), `headerMinHeight` (`3.5rem`), `headerBorderColor`, `headerBorderWidth`, `mainPadding` (`1.5rem`) |
| Theme: sidebar | `components.sidebar`: `width` (`16rem`), `collapsedWidth` (`5rem`), `background`, `color`, `padding` (`0.5rem`), `gap` (`1rem`), `borderColor`, `borderWidth`, `labelSize` (`1rem`)                         |

`data-collapsed` and `data-mobile` are empty when present, so select `[data-collapsed]`. `className`, `style`, `ref` and native props reach each host. Sidebar `parts` styles its `label`, `drawer`, `viewport` and `close`.

## API

### AppShell

| Prop                         | Type                            | Default   |
| ---------------------------- | ------------------------------- | --------- |
| collapsed / defaultCollapsed | boolean; one owner              | false     |
| onCollapsedChange            | (collapsed: boolean) => void    | None      |
| open / defaultOpen           | boolean; one owner              | false     |
| onOpenChange                 | (open: boolean) => void         | None      |
| mainId                       | string; nonempty, no whitespace | Generated |
| motion                       | inherit / off                   | inherit   |
| className / style            | string / ThemeStyle             | None      |
| ref                          | `Ref<HTMLDivElement>`           | None      |
| Other props                  | Native div props                | Native    |

### AppShellHeader, AppShellMain

| Prop              | Type                                                                | Default |
| ----------------- | ------------------------------------------------------------------- | ------- |
| className / style | string / ThemeStyle                                                 | None    |
| ref               | `Ref<HTMLElement>`                                                  | None    |
| Other props       | Native header or main props, except role; main also id and tabIndex | Native  |

### AppShellSkipLink

| Prop        | Type                                                 | Default |
| ----------- | ---------------------------------------------------- | ------- |
| render      | (props: AppShellRenderProps) => ReactElement; router | None    |
| Other props | [Link](/docs/link/) props except href and role       | Native  |

### Sidebar

| Prop              | Type                                                     | Default          |
| ----------------- | -------------------------------------------------------- | ---------------- |
| label             | ReactNode; visible, nonempty name                        | Required         |
| closeLabel        | string; drawer close button text or icon label           | Close navigation |
| parts             | `{ label, drawer, viewport, close }` of PartStyle        | None             |
| className / style | string / ThemeStyle                                      | None             |
| ref               | `Ref<HTMLElement>`                                       | None             |
| Other props       | Native nav props except id, role, tabIndex and ARIA name | Native           |

### SidebarTrigger, SidebarLabel, SidebarContent

| Part           | Prop           | Type                                               | Default         |
| -------------- | -------------- | -------------------------------------------------- | --------------- |
| SidebarTrigger | variant / tone | [Button](/docs/button/) props                      | ghost / neutral |
| SidebarTrigger | Other props    | Button props except toggle, popover and ARIA state | Native          |
| SidebarLabel   | Other props    | Native span props                                  | Native          |
| SidebarContent | expandedOnly   | boolean; hidden and inert while collapsed          | false           |
| SidebarContent | Other props    | Native div props except hidden and inert           | Native          |

### useAppShell()

| Member       | Type                         |
| ------------ | ---------------------------- |
| collapsed    | boolean                      |
| open         | boolean                      |
| mobile       | boolean; shell below 40rem   |
| mainId       | string                       |
| setCollapsed | (collapsed: boolean) => void |
| setOpen      | (open: boolean) => void      |

Parts outside AppShell throw. Invalid labels, `mainId` or non-boolean states throw.
