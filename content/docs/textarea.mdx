## Usage

Use [Field](/docs/field/) for labels and errors, [Input](/docs/input/) for one line, or [InputGroup](/docs/input-group/) to add an action.

## State

Use `defaultValue` for initial text or `value` with `onChange` for controlled text. Keep that choice until remount.

## Accessibility

Give each textarea a visible label, `aria-label` or `aria-labelledby`.

## Styling

Textarea resizes vertically by default. Set `fieldSizing: 'content'` and `maxHeight` to grow with the text. See [focus outlines](/docs/foundations/theming/#focus-outlines) for focus and error colors.

## API

Textarea accepts native props and events.

| Prop                        | Purpose                                                 |
| --------------------------- | ------------------------------------------------------- |
| `rows`, `cols`              | Native size hints. `rows` defaults to `3`.              |
| `controlSize`               | `small`, `medium` (default), or `large`                 |
| `className`, `style`, `ref` | Target the native textarea with `data-slot="textarea"`. |
