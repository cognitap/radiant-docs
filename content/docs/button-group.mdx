## Usage

Group related [Button](/docs/button/) actions. Set `orientation="vertical"` to stack them. For a split action, pair a Button with a [Menu](/docs/menu/) trigger.

```tsx
<ButtonGroup aria-label="Browse weeks">
  <Button variant="outline">Previous</Button>
  <Button variant="outline">Next</Button>
</ButtonGroup>
```

## Accessibility

Each button has its own Tab stop. Name the group with `aria-label` or `aria-labelledby` when the actions need context. Use [Toolbar](/docs/toolbar/) for arrow-key navigation or [ToggleGroup](/docs/toggle-group/) for related choices.

## Styling

The gap is half the theme’s normal spacing. Set `components.buttonGroup.gap` or `--rad-button-group-gap` to adjust it. Each button keeps its own shape and [motion](/docs/button/#motion).

## API

| Prop                  | Type                                     | Default    |
| --------------------- | ---------------------------------------- | ---------- |
| orientation           | horizontal / vertical                    | horizontal |
| children              | ReactNode                                | None       |
| Native div attributes | Includes `className`, `style`, and `ref` | Native     |

Exports `ButtonGroup`, `ButtonGroupProps`, and `Orientation`.
