## Usage

Use Popover for details or a small form. Use [Tooltip](/docs/tooltip/) to describe a control, [HoverCard](/docs/hover-card/) for a link preview, [Menu](/docs/menu/) for actions and [Dialog](/docs/dialog/) for a modal task.

```tsx
<Popover>
  <PopoverTrigger>Delivery details</PopoverTrigger>
  <PopoverPortal>
    <PopoverContent>
      <p>Standard delivery takes three to five working days.</p>
      <PopoverClose variant="outline">Got it</PopoverClose>
    </PopoverContent>
  </PopoverPortal>
</Popover>
```

### Anchor to an SVG shape or a rect

`anchor` takes an element or a viewport rect; a getter is re-read on render, scroll and resize. Without a trigger, the anchor owns its role, `aria-expanded`, `aria-controls` and keyboard activation. Give a non-focusable anchor a `returnFocusRef`.

```tsx
function Region({ setRegion, open, setOpen }) {
  const { contentId } = usePopover()!
  return (
    <path
      ref={setRegion}
      d={north}
      role="button"
      tabIndex={0}
      aria-label="North depot"
      aria-expanded={open}
      aria-controls={contentId}
      onClick={() => setOpen(!open)}
      onKeyDown={event => event.key === 'Enter' && setOpen(!open)}
    />
  )
}

;<Popover
  open={open}
  onOpenChange={setOpen}
  anchor={region}
>
  <svg>
    <Region
      setRegion={setRegion}
      open={open}
      setOpen={setOpen}
    />
  </svg>
  <PopoverPortal>
    <PopoverContent
      role="dialog"
      aria-label="North depot"
    >
      …
    </PopoverContent>
  </PopoverPortal>
</Popover>
```

## State

Use `open` with `onOpenChange`, or `defaultOpen`, never both. `onOpenChange` fires once per request: trigger, Close, Escape, outside pointer or focus leaving. A controlled owner refuses a close by not updating `open`. Closing an ancestor Popover or Dialog hides descendants. `usePopover()` returns `{ open, setOpen, contentId }`, or `null` outside a Popover.

Popover adds no form value. `PopoverPortal` mounts content in the nearest block container of the trigger or anchor element, so a surrounding `<form>`, theme and modal ancestry apply; a rect anchor uses the portal's nearest HTML ancestor.

## Accessibility

The trigger is a native button with `aria-expanded` and `aria-controls`. Content is a plain `div`: give it a role and name, such as `role="dialog"` with `aria-label`.

Opening keeps focus on the trigger unless `initialFocusRef` names a descendant. Content follows the trigger in Tab order, without a focus trap. Escape and Close return inside focus to `returnFocusRef`, else the trigger, a focusable anchor or the prior focus; outside dismissal leaves focus where it landed.

| Key             | Where              | Behavior                              |
| --------------- | ------------------ | ------------------------------------- |
| Enter / Space   | Trigger            | Toggle the popover                    |
| Tab             | Open trigger       | Move into the content                 |
| Tab / Shift+Tab | Leaving content    | Move on and close                     |
| Escape          | Trigger or content | Close the topmost popover             |
| Enter / Space   | PopoverClose       | Close and return focus to the trigger |

## Motion

With a `MotionProvider` from `@cognitap/radiant/motion/react`, content fades in. Reduced motion and `motion="off"` on PopoverContent remove it. Closing is immediate.

## Styling

Content flips and shifts to stay inside the visual viewport. On top and bottom sides, `start` and `end` follow text direction.

Content exposes `data-slot="popover-content"`, `data-state`, `data-motion`, and the `data-side` and `data-align` used after flipping. The trigger and close add `popover-trigger` and `popover-close` to Button's `data-slot`, and the trigger exposes `data-state`. Caller `data-slot` values are appended; `className` merges over the defaults.

Use `components.popover` or `--rad-popover-*` variables, such as `--rad-popover-width` (default `20rem`), `padding`, `radius` and `shadow`.

## API

| Popover prop       | Type                                                            | Default |
| ------------------ | --------------------------------------------------------------- | ------- |
| open / defaultOpen | boolean; exclusive owner                                        | false   |
| onOpenChange       | (open: boolean) => void                                         | None    |
| anchor             | Element, `{ x, y, width, height }` viewport rect or rect getter | Trigger |
| children           | ReactNode                                                       | None    |

| PopoverTrigger prop          | Type                                                           | Default                 |
| ---------------------------- | -------------------------------------------------------------- | ----------------------- |
| variant / tone / controlSize | ButtonVariant / Tone / ControlSize                             | solid / accent / medium |
| pending / disabled           | boolean                                                        | false                   |
| render                       | (props: PopoverRenderProps) => ReactElement                    | Native button           |
| onClick                      | Runs first; `preventDefault()` cancels the toggle              | None                    |
| Native button props          | `aria-controls`, `aria-expanded` and `popoverTarget` are owned | Native defaults         |
| ref                          | `Ref<HTMLButtonElement>`                                       | None                    |

| PopoverContent prop           | Type                                           | Default           |
| ----------------------------- | ---------------------------------------------- | ----------------- |
| side                          | top / right / bottom / left                    | bottom            |
| align                         | start / center / end                           | start             |
| sideOffset / collisionPadding | Finite nonnegative pixels                      | 8 / 8             |
| initialFocusRef               | `RefObject<HTMLElement \| null>`               | Trigger focus     |
| returnFocusRef                | `RefObject<HTMLElement \| SVGElement \| null>` | See Accessibility |
| motion                        | inherit / off                                  | inherit           |
| className / style             | string / ThemeStyle                            | None              |
| Native div props              | Includes role and naming; not id or popover    | Native defaults   |
| ref                           | `Ref<HTMLDivElement>`                          | None              |

| PopoverClose prop            | Type                                             | Default                 |
| ---------------------------- | ------------------------------------------------ | ----------------------- |
| variant / tone / controlSize | ButtonVariant / Tone / ControlSize               | solid / accent / medium |
| render                       | (props: PopoverRenderProps) => ReactElement      | Native button           |
| onClick                      | Runs first; `preventDefault()` cancels the close | None                    |
| Button and native props, ref | `Ref<HTMLButtonElement>`                         | Button defaults         |

`PopoverPortal` has no host and renders nothing until it finds its container.
