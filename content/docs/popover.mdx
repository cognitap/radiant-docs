## Usage

Use Popover for details or a small form the reader opens on demand. Use [Tooltip](/docs/tooltip/) to describe a control, [HoverCard](/docs/hover-card/) for a link preview, [Menu](/docs/menu/) for a list of actions and [Dialog](/docs/dialog/) for a modal task.

```tsx
<Popover>
  <PopoverTrigger>Delivery details</PopoverTrigger>
  <PopoverPortal>
    <PopoverContent>
      <p>Standard delivery takes three to five working days.</p>
      <PopoverClose variant="outline">Got it</PopoverClose>
    </PopoverContent>
  </PopoverPortal>
</Popover>
```

## State

Use `open` with `onOpenChange`, or `defaultOpen`, never both. `onOpenChange` fires once per request: trigger, Close, Escape, outside pointer or focus leaving. A controlled owner refuses a close by not updating `open`. Closing an ancestor Popover or Dialog still hides descendants. `usePopover()` returns `{ open, setOpen, contentId }`, or `null` outside a Popover.

Popover adds no form value. `PopoverPortal` mounts content in the trigger's nearest block container, so a surrounding `<form>`, theme and modal ancestry still apply.

## Accessibility

The trigger is a native button with `aria-expanded` and `aria-controls`. Content is a plain `div`: give it the role and name it needs, such as `role="dialog"` with `aria-label` for a form. Popover adds no menu or listbox behavior.

Opening keeps focus on the trigger unless `initialFocusRef` names a descendant. Content follows the trigger in Tab order, without a focus trap. Escape and Close return focus to the trigger when focus was inside; outside dismissal leaves focus where it landed.

| Key             | Where              | Behavior                              |
| --------------- | ------------------ | ------------------------------------- |
| Enter / Space   | Trigger            | Toggle the popover                    |
| Tab             | Open trigger       | Move into the content                 |
| Tab / Shift+Tab | Leaving content    | Move on and close                     |
| Escape          | Trigger or content | Close the topmost popover             |
| Enter / Space   | PopoverClose       | Close and return focus to the trigger |

## Motion

With a `MotionProvider` from `@cognitap/radiant/motion/react`, content fades in. Reduced motion and `motion="off"` on PopoverContent remove it. Closing is immediate.

## Styling

Content flips and shifts to stay inside the visual viewport. On top and bottom sides, `start` and `end` follow text direction. `data-side` and `data-align` report the placement after flipping.

Content exposes `data-slot="popover-content"`, `data-state`, `data-side`, `data-align` and `data-motion`. The trigger and close add `popover-trigger` and `popover-close` to Button's `data-slot`. Caller `data-slot` values are appended; `className` merges over the defaults.

Use `components.popover` or `--rad-popover-*` variables, such as `--rad-popover-width` (default `20rem`), `padding`, `radius` and `shadow`.

## API

| Popover prop       | Type                     | Default |
| ------------------ | ------------------------ | ------- |
| open / defaultOpen | boolean; exclusive owner | false   |
| onOpenChange       | (open: boolean) => void  | None    |
| children           | ReactNode                | None    |

| PopoverTrigger prop          | Type                                                           | Default                 |
| ---------------------------- | -------------------------------------------------------------- | ----------------------- |
| variant / tone / controlSize | ButtonVariant / Tone / ControlSize                             | solid / accent / medium |
| pending / disabled           | boolean                                                        | false                   |
| render                       | (props: PopoverRenderProps) => ReactElement                    | Native button           |
| onClick                      | Runs first; `preventDefault()` cancels the toggle              | None                    |
| Native button props          | `aria-controls`, `aria-expanded` and `popoverTarget` are owned | Native defaults         |
| ref                          | `Ref<HTMLButtonElement>`                                       | None                    |

| PopoverContent prop           | Type                                        | Default         |
| ----------------------------- | ------------------------------------------- | --------------- |
| side                          | top / right / bottom / left                 | bottom          |
| align                         | start / center / end                        | start           |
| sideOffset / collisionPadding | Finite nonnegative pixels                   | 8 / 8           |
| initialFocusRef               | `RefObject<HTMLElement \| null>`            | Trigger focus   |
| motion                        | inherit / off                               | inherit         |
| className / style             | string / ThemeStyle                         | None            |
| Native div props              | Includes role and naming; not id or popover | Native defaults |
| ref                           | `Ref<HTMLDivElement>`                       | None            |

| PopoverClose prop            | Type                                             | Default                 |
| ---------------------------- | ------------------------------------------------ | ----------------------- |
| variant / tone / controlSize | ButtonVariant / Tone / ControlSize               | solid / accent / medium |
| render                       | (props: PopoverRenderProps) => ReactElement      | Native button           |
| onClick                      | Runs first; `preventDefault()` cancels the close | None                    |
| Button and native props, ref | `Ref<HTMLButtonElement>`                         | Button defaults         |

`PopoverPortal` accepts children, has no host and renders nothing until the trigger mounts.

Exports: `Popover`, `PopoverTrigger`, `PopoverPortal`, `PopoverContent`, `PopoverClose`, `usePopover`; types `PopoverProps`, `PopoverState`, `PopoverTriggerProps`, `PopoverContentProps`, `PopoverCloseProps`, `PopoverPortalProps`, `PopoverRenderProps`, `PopoverSide`, `PopoverAlign`.
