## Usage

Use Menu for a short list of commands behind a button. Items are commands, not toggles: MenuItem takes no `pressed` props. For a command that turns something on or off, use MenuCheckboxItem. Choose something else when:

- [Select](/docs/select/) or [NativeSelect](/docs/native-select/): people pick a value to submit.
- NavigationMenu or [Link](/docs/link/): items go to other pages.
- [Menubar](/docs/menubar/): an app needs a persistent bar of menus.
- [ContextMenu](/docs/context-menu/): commands open on right-click over a surface.
- [Command](/docs/command/): people search a long list of commands.

```tsx
<Menu>
  <MenuTrigger>File actions</MenuTrigger>
  <MenuPortal>
    <MenuContent>
      <MenuItem onSelect={duplicate}>Duplicate</MenuItem>
      <MenuCheckboxItem
        checked={pinned}
        onCheckedChange={setPinned}
      >
        Pinned
      </MenuCheckboxItem>
    </MenuContent>
  </MenuPortal>
</Menu>
```

## State

Menu takes `open` or `defaultOpen` with `onOpenChange`. MenuCheckboxItem takes `checked` or `defaultChecked` with `onCheckedChange`. MenuRadioGroup takes `value` or `defaultValue`, a string or `null`, with `onValueChange`. Pick one owner per mount; switching throws. A controlled owner may refuse a request, as "Submit report actions" does while "Keep commands open" is checked.

Items are real buttons. Set `type="submit"` with `form`, `name` and `value` to submit a form, or `type="reset"` to reset it. Checkbox and radio items are `type="button"` and never submit. Call `event.preventDefault()` in `onSelect` to keep the menu open and cancel the native action.

## Accessibility

The trigger is a `button` with `aria-haspopup="menu"`, `aria-expanded` and `aria-controls`; its text names the menu. The content is a vertical `menu`. Items are `menuitem`, `menuitemcheckbox` with `aria-checked` true, false or mixed, or `menuitemradio`. Name a MenuGroup with `aria-labelledby` pointing at a MenuLabel `id`, or with `aria-label`. Disabled items stay focusable with `aria-disabled`.

| Key                                   | Behavior                                      |
| ------------------------------------- | --------------------------------------------- |
| Enter / Space / Arrow Down on trigger | Open and focus the first item                 |
| Arrow Up on trigger                   | Open and focus the last item                  |
| Arrow Down / Up                       | Move to the next or previous item, wrapping   |
| Home / End                            | Move to the first or last item                |
| Typing                                | Focus the next item whose `textValue` matches |
| Enter / Space                         | Activate the focused item                     |
| Arrow Right on a MenuSubTrigger       | Open the submenu on its first item            |
| Arrow Left in a submenu               | Close it and focus its MenuSubTrigger         |
| Escape                                | Close the menu and refocus its opener         |
| Tab / Shift+Tab                       | Close every menu and move on from the trigger |

Arrow Right and Left swap in right-to-left layouts. Hovering an item focuses it, except on touch; hovering a MenuSubTrigger opens its submenu.

## Motion

Inside [MotionProvider](/docs/foundations/motion/), the content fades and scales in. Set `motion="off"` on MenuContent or MenuSubContent to turn it off for that surface. Reduced motion is honored.

## Styling

Every part except Menu, MenuSub and MenuPortal takes `className`, `style` and `ref`. The trigger and items keep Button's slot, and the content keeps Popover's state and placement attributes.

| Part             | Attributes                                             |
| ---------------- | ------------------------------------------------------ |
| MenuTrigger      | `data-slot` includes `menu-trigger`                    |
| MenuContent      | `menu-content`                                         |
| MenuItem         | `menu-item`, `data-text-value`                         |
| MenuCheckboxItem | `menu-checkbox-item`                                   |
| MenuRadioGroup   | `menu-radio-group`                                     |
| MenuRadioItem    | `menu-radio-item`                                      |
| Indicator        | `menu-item-indicator`; style it with `parts.indicator` |
| MenuGroup        | `menu-group`                                           |
| MenuLabel        | `menu-label`                                           |
| MenuSeparator    | `menu-separator`                                       |
| MenuSubTrigger   | `menu-sub-trigger`                                     |
| MenuSubContent   | `menu-sub-content`                                     |

Theme with `components.menu` or `--rad-menu-*` tokens, such as `--rad-menu-width`, `--rad-menu-radius` and `--rad-menu-item-focus-background`.

## API

### Menu

| Prop         | Type                      | Default |
| ------------ | ------------------------- | ------- |
| open         | boolean                   | None    |
| defaultOpen  | boolean                   | false   |
| onOpenChange | `(open: boolean) => void` | None    |
| children     | ReactNode                 | None    |

### MenuTrigger

| Prop                         | Type                                                                                                                        | Default         |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------- | --------------- |
| variant / tone / controlSize | Button's                                                                                                                    | Button defaults |
| disabled / pending           | boolean                                                                                                                     | false           |
| render                       | `(props: MenuRenderProps) => ReactElement`                                                                                  | None            |
| Other props                  | Button props except `id`, `aria-haspopup` and toggle props (`pressed`, `defaultPressed`, `onPressedChange`, `aria-pressed`) | Native          |

### MenuPortal

| Prop     | Type      | Default |
| -------- | --------- | ------- |
| children | ReactNode | None    |

Renders no host element.

### MenuContent

| Prop             | Type                                                                                          | Default |
| ---------------- | --------------------------------------------------------------------------------------------- | ------- |
| side             | top / right / bottom / left                                                                   | bottom  |
| align            | start / center / end                                                                          | start   |
| sideOffset       | number                                                                                        | 8       |
| collisionPadding | number                                                                                        | 8       |
| motion           | inherit / off                                                                                 | inherit |
| style            | ThemeStyle                                                                                    | None    |
| Other props      | div props except `role`, `aria-labelledby`, `aria-orientation`, `tabIndex`, `initialFocusRef` | Native  |

### MenuItem

| Prop                       | Type                                                                     | Default        |
| -------------------------- | ------------------------------------------------------------------------ | -------------- |
| onSelect                   | `(event: MouseEvent<HTMLButtonElement>) => void`                         | None           |
| closeOnSelect              | boolean                                                                  | true           |
| textValue                  | string; typeahead text                                                   | Text content   |
| disabled                   | boolean; stays focusable                                                 | false          |
| pending                    | boolean; blocks activation                                               | false          |
| type / form / name / value | Native button attributes                                                 | Button default |
| render                     | `(props: MenuRenderProps) => ReactElement`                               | None           |
| Other props                | Button props except `role`, `tabIndex`, `aria-disabled` and toggle props | Native         |

### MenuCheckboxItem

| Prop                     | Type                                                     | Default      |
| ------------------------ | -------------------------------------------------------- | ------------ |
| checked / defaultChecked | boolean                                                  | None / false |
| onCheckedChange          | `(checked: boolean) => void`                             | None         |
| indeterminate            | boolean; `aria-checked="mixed"`, selecting requests true | false        |
| closeOnSelect            | boolean                                                  | false        |
| parts.indicator          | PartStyle                                                | None         |
| Other props              | MenuItem props except `aria-checked` and `type`          | Native       |

### MenuRadioGroup

| Prop                 | Type                              | Default     |
| -------------------- | --------------------------------- | ----------- |
| value / defaultValue | string / null                     | None / null |
| onValueChange        | `(value: string \| null) => void` | None        |
| Other props          | MenuGroup props                   | Native      |

### MenuRadioItem

| Prop            | Type                                                     | Default  |
| --------------- | -------------------------------------------------------- | -------- |
| value           | string                                                   | Required |
| closeOnSelect   | boolean                                                  | false    |
| parts.indicator | PartStyle                                                | None     |
| Other props     | MenuItem props except `aria-checked`, `type` and `value` | Native   |

### MenuGroup

| Prop        | Type                    | Default |
| ----------- | ----------------------- | ------- |
| style       | ThemeStyle              | None    |
| Other props | div props except `role` | Native  |

### MenuLabel

| Prop        | Type                                | Default |
| ----------- | ----------------------------------- | ------- |
| style       | ThemeStyle                          | None    |
| Other props | div props except `role`, `tabIndex` | Native  |

### MenuSeparator

| Prop      | Type            | Default            |
| --------- | --------------- | ------------------ |
| All props | Separator props | Separator defaults |

### MenuSub

| Prop               | Type                      | Default      |
| ------------------ | ------------------------- | ------------ |
| open / defaultOpen | boolean                   | None / false |
| onOpenChange       | `(open: boolean) => void` | None         |
| children           | ReactNode                 | None         |

### MenuSubTrigger

| Prop            | Type                                                                                                   | Default |
| --------------- | ------------------------------------------------------------------------------------------------------ | ------- |
| parts.indicator | PartStyle                                                                                              | None    |
| Other props     | MenuItem props except `closeOnSelect`, `id`, `type`, `aria-haspopup`, `aria-expanded`, `aria-controls` | Native  |

### MenuSubContent

| Prop        | Type                | Default                      |
| ----------- | ------------------- | ---------------------------- |
| side        | Same as MenuContent | Inline end for the direction |
| sideOffset  | number              | 4                            |
| Other props | MenuContent props   | Same as MenuContent          |

`useMenu()` returns `{ open, setOpen, contentId }` inside a Menu, else `null`.

Exports each part's `Props` type, plus `MenuState` and `MenuRenderProps`.
