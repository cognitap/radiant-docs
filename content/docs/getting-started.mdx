Radiant is a collection of React components with native behavior and a shared
visual language.

## Install the package

```sh
pnpm add @cognitap/radiant
```

Use React and React DOM 19.3 or later within React 19. Radiant is experimental:
pin the package while evaluating it, and read the
[migration notes](/docs/releases/) before upgrading.

## Choose a styling route

Import the compiled stylesheet once in your application entry point:

```tsx
import '@cognitap/radiant/styles.css'
```

<Callout title="Start with the compiled CSS">
  The compiled stylesheet works without a Tailwind setup in your application. The optional
  `reset.css` export is a separate choice; only add a global reset when it fits your application.
</Callout>

The stylesheet includes component rules, utilities and a neutral light/dark
baseline. Components render without a provider. Use `ThemeScope` for a named
preset or a scoped mode.

### Optional global reset

Import Radiant's reset before the component stylesheet:

```tsx
import '@cognitap/radiant/reset.css'
import '@cognitap/radiant/styles.css'
```

The reset affects the whole document. Components do not require it.

### With Tailwind

If your app builds with **Tailwind 4.3.3 or later in 4.x**, use Radiant's source
entry instead of `styles.css`:

```css
@import 'tailwindcss';
@import '@cognitap/radiant/tailwind.css';
```

For Tailwind without Preflight, use:

```css
@layer theme, base, components, utilities;
@import 'tailwindcss/theme.css' layer(theme);
@import 'tailwindcss/utilities.css' layer(utilities);
@import '@cognitap/radiant/tailwind.css';
```

Keep source discovery enabled; with `source(none)`, register your application
sources explicitly. Tailwind then generates your utilities and merges matching
classes with component defaults. The compiled route ships only Radiant's
prebuilt utilities. Keep JavaScript and CSS on the same Radiant version, and
choose one component styling entry.

## Use public exports

Import components, types, `defineTheme`, `ThemeScope` and presets from
`@cognitap/radiant`. The styling entries are `styles.css`, `reset.css` and
`tailwind.css`. Imports from `src`, `dist` or other internal paths are not part
of the package contract. The website and Storybook are not installed with the
library.
