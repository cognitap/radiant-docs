## Usage

Use Form when a submission can fail and the user must fix it. Use a plain `<form>` with [Field](/docs/field/) when the browser can submit it unaided.

```tsx
<Form
  aria-label="Join workspace"
  onSubmitValues={async data => (await invite(data)).errors}
>
  {({ pending }) => (
    <>
      <FormField
        name="email"
        label="Email"
        required
      >
        <Input
          name="email"
          type="email"
        />
      </FormField>
      <FormError />
      <Button
        type="submit"
        pending={pending}
      >
        Join workspace
      </Button>
    </>
  )}
</Form>
```

## State

Form stores errors and pending status, never values.

Errors have one owner: `errors` with `onErrorsChange`, or `defaultErrors`. Mixing them is a type error.

  files={['form/FormStateExample.tsx']}
>
  <ReviewStudyNotes />
</Demo>

On submit, Form checks native constraints, then runs `validate(data)`. A native message wins over a custom one for the same field. Any error blocks submission. A submitter with `formNoValidate` skips the native check.

Without `onSubmitValues` the browser submits. With it, Form prevents navigation, sets `pending` and calls `onSubmitValues(data, { form, submitter, signal })`. Return errors, or nothing to clear them. If it throws or rejects, FormError shows `submitErrorText`. Further submits are ignored while pending.

Editing a control clears its error and the form error, and discards a pending result. Reset clears errors and aborts `signal`, as does unmount. Pass `signal` to `fetch` to cancel the request. Reset controlled values yourself.

Children may be a function of `FormState`: `errors`, `pending` and `focusInvalid`.

## Accessibility

Form requires `aria-label` or `aria-labelledby` and throws without one. FormField composes [Field](/docs/field/), for labels and error IDs. Match its `name` to the control's `name`. NumberField, TagsInput and Combobox report their errors on that FormField too.

After a failed submit, focus moves to the first invalid enabled control in document order. With only a form error, it moves to FormError, an assertive `role="alert"`. While pending, the form has `aria-busy`.

| Key                     | Behavior                               |
| ----------------------- | -------------------------------------- |
| Enter in a text field   | Submits the form (native)              |
| Enter / Space on submit | Submits the form                       |
| Enter / Space on reset  | Resets values and clears errors        |
| Tab / Shift+Tab         | Moves between controls; Form adds none |

## Motion

Form does not animate. Button and Alert keep their own motion.

## Styling

| Part      | Element            | `data-slot` and attributes                          |
| --------- | ------------------ | --------------------------------------------------- |
| Form      | `form`             | `form`; `data-pending`, `data-invalid`, `aria-busy` |
| FormField | `div` / `fieldset` | `field form-field`; Field's attributes              |
| FormError | `div role="alert"` | `alert form-error`; `data-tone`, `data-announce`    |

`className`, `style` and `ref` reach each part's element. Set `--rad-form-gap`, or `components.form.gap` in a theme, for the space between rows.

## API

### Form

| Prop                         | Type / default                                                        |
| ---------------------------- | --------------------------------------------------------------------- |
| aria-label / aria-labelledby | string; one is required                                               |
| errors / defaultErrors       | FormErrors; one owner; `{}`                                           |
| onErrorsChange               | (errors: FormErrors) → void                                           |
| validate                     | (data: FormData) → FormErrors \| void                                 |
| onSubmitValues               | (data, context: FormSubmitContext) → FormErrors \| void, or a promise |
| submitErrorText              | string; `'Unable to save. Try again.'`                                |
| children                     | ReactNode \| (state: FormState) → ReactNode                           |
| className / style            | string / ThemeStyle                                                   |
| ref                          | HTMLFormElement                                                       |
| onSubmit / onReset           | Run first; `preventDefault()` skips Form's handling                   |
| Other props                  | Native form props except `noValidate`, which Form always sets         |

### FormField

| Prop        | Type / default                                   |
| ----------- | ------------------------------------------------ |
| name        | Required string; the control's `name`            |
| error       | ReactNode; overrides the form's error for `name` |
| Other props | Field props                                      |

### FormError

| Prop        | Type / default                             |
| ----------- | ------------------------------------------ |
| tone        | Alert tone; danger                         |
| announce    | off / polite / assertive; assertive        |
| Other props | Alert props without children or `tabIndex` |

Renders nothing until there is a form error.

### useForm()

Returns the `FormState` of the enclosing Form, or `null` outside one.

### Types

| Type              | Shape                                                             |
| ----------------- | ----------------------------------------------------------------- |
| FormErrors        | `{ fields?: Record<string, string \| undefined>; form?: string }` |
| FormState         | `{ errors, pending, focusInvalid: () => void }`                   |
| FormSubmitContext | `{ form, submitter: HTMLElement \| null, signal: AbortSignal }`   |

Each part also exports its `Props` type.
