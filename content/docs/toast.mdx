## Usage

Use Toast to confirm or report something the user just did. Use [Alert](/docs/alert/) for a message that must stay in the page, and [AlertDialog](/docs/alert-dialog/) for a decision the user must make before continuing.

```tsx
<ToastProvider>
  <Button onClick={() => setOpen(true)}>Save draft</Button>
  <ToastViewport>
    <Toast
      open={open}
      onOpenChange={setOpen}
    >
      <ToastTitle>Draft saved</ToastTitle>
      <ToastDescription>Your latest edits are stored.</ToastDescription>
      <ToastClose>Dismiss</ToastClose>
    </Toast>
  </ToastViewport>
</ToastProvider>
```

There is no `toast()` function. Render a Toast for each message from your own state.

## State

Use `open` or `defaultOpen`, never both. ToastAction, ToastClose, Escape inside the toast and the timeout each call `onOpenChange(false)`. An action's `onClick` runs first; `event.preventDefault()` keeps the toast open.

Toast `duration` overrides the provider's, in milliseconds. The default `0` keeps the toast until it is dismissed. The timer starts when the toast is visible and pauses while it is hovered or focused, or the document is hidden.

A provider shows one toast at a time. The rest wait hidden and inert, in the order they opened, with `data-queued`. `useToast()` returns `{ open, visible, setOpen }` inside a Toast and `null` outside.

## Accessibility

Opening never moves focus. The provider announces the toast politely, or through `role="alert"` with `announce="assertive"`. It reads ToastTitle, ToastDescription and each ToastAction's `altText`, never ToastClose. `announcement` replaces that text.

`altText` is required because the user hears the toast from outside it, often after it has closed. Say where the action is: "Undo is available in Notifications, reached with F8." A blank value throws. The button's name stays its visible text. Keep `duration` at `0` when the user must reach an action.

| Key             | Behavior                                     |
| --------------- | -------------------------------------------- |
| F8              | Focus the visible toast from anywhere        |
| Tab / Shift+Tab | Move between actions inside the toast        |
| Enter / Space   | Activate an action or Close; close the toast |
| Escape          | Close the toast                              |

Closing returns focus to where it was. `hotkey={false}` on ToastViewport turns F8 off.

## Motion

With a `MotionProvider` from `@cognitap/radiant/motion/react`, the toast fades in. `motion="off"` and reduced motion remove the fade.

## Styling

Every part takes `className` and has a `toast-*` `data-slot`. Toast has `data-state`, `data-queued`, `data-urgency`, `data-tone` and `data-motion`.

Pass `--rad-toast-*` tokens through `style`. Toast takes padding, gap, radius, background, color, border and shadow tokens. The viewport takes `--rad-toast-inset`, `--rad-toast-width` and `--rad-toast-z-index`, and is fixed to the bottom right by default.

## API

| ToastProvider prop | Type      | Default |
| ------------------ | --------- | ------- |
| duration           | number    | 0       |
| children           | ReactNode | None    |

| ToastViewport prop   | Type                                        | Default         |
| -------------------- | ------------------------------------------- | --------------- |
| hotkey               | boolean                                     | true            |
| aria-label           | string                                      | "Notifications" |
| style                | ThemeStyle                                  | None            |
| Native section props | Except role, tabIndex and aria-keyshortcuts | Native defaults |

| Toast prop                 | Type                                                  | Default           |
| -------------------------- | ----------------------------------------------------- | ----------------- |
| open / defaultOpen         | boolean; exclusive owner                              | false             |
| onOpenChange               | (open: boolean) => void                               | None              |
| duration                   | number of milliseconds, 0 to 2147483647               | Provider duration |
| tone                       | neutral / accent / warning / danger                   | neutral           |
| announce                   | polite / assertive / off                              | polite            |
| announcement               | string                                                | Derived           |
| motion                     | inherit / off                                         | inherit           |
| Alert and native div props | Except hidden, inert, aria-hidden, tabIndex, onSelect | Native defaults   |

| ToastTitle prop | Type                  | Default         |
| --------------- | --------------------- | --------------- |
| level           | 1 / 2 / 3 / 4 / 5 / 6 | 2               |
| Native h2 props | Includes className    | Native defaults |

ToastDescription takes native `<p>` props.

| ToastAction prop             | Type                                   | Default         |
| ---------------------------- | -------------------------------------- | --------------- |
| altText                      | string; required, not blank            | None            |
| onClick                      | MouseEventHandler; runs before closing | None            |
| variant / tone / controlSize | As [Button](/docs/button/#api)         | Button's        |
| pending / disabled / render  | As Button                              | Button's        |
| Button props                 | Except pressed state and aria-pressed  | Native defaults |

ToastClose takes the same props as ToastAction without `altText`.
