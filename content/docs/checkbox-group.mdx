## Usage

Use CheckboxGroup for several related choices whose value is the array of checked options. It renders a [Field](/docs/field/) fieldset with the label as its legend; each option is a native checkbox. Use [Checkbox](/docs/checkbox/) for one setting, [RadioGroup](/docs/radio-group/) for exactly one choice, [MultiSelect](/docs/multi-select/) for long or searchable lists and [Fieldset](/docs/fieldset/) for a custom layout without a shared value.

```tsx
<CheckboxGroup
  label="Notifications"
  name="channels"
  defaultValue={['email']}
  items={[
    { value: 'email', label: 'Email' },
    { value: 'sms', label: 'SMS' }
  ]}
/>
```

## State

Use `defaultValue` for browser-owned selection, or `value` with `onValueChange`, not both. Both are `string[]`. Switching owners throws; remount with a `key`. Item values must be unique strings, and `''` is a real value. A controlled owner may refuse a change, and the checkboxes restore.

`name` has no default; without it nothing submits. Each checked, enabled option submits one `name=value` entry. Select all never submits.

`required` blocks submission until an enabled option is checked, with the browser message “Please select at least one option.” A fully disabled group is valid.

Form reset returns an uncontrolled group to `defaultValue`. A controlled group keeps its value, so reset your state in the form's `onReset`.

## Accessibility

`label` becomes the required `legend`. `description` and `error` are linked to the group, and `error` marks it invalid. Every option needs a `label`. Select all reports a mixed state, controls every option and leaves disabled selections unchanged.

| Key                 | Behavior                                           |
| ------------------- | -------------------------------------------------- |
| Tab / Shift+Tab     | Moves between enabled checkboxes, select all first |
| Space               | Toggles the focused checkbox                       |
| Space on select all | Checks or clears every enabled option              |

## Motion

Checks and the mixed state change instantly; CheckboxGroup adds no animation.

## Styling

The group's className, style, ref and native props reach the `fieldset` (`data-slot="field checkbox-group"`, `data-control-size`, `data-disabled`, `data-invalid`, `data-required`). `parts.options` styles the options grid (`checkbox-group-options`). `parts.label`, `parts.description`, `parts.error` and `parts.required` style the Field parts.

Options and select all render [Checkbox](/docs/checkbox/), so each configuration takes Checkbox's `parts`, className, style and ref. Set `components.checkboxGroup.gap` or `--rad-checkbox-group-gap` for option spacing.

## API

### CheckboxGroup

| Prop              | Type                                             | Default  |
| ----------------- | ------------------------------------------------ | -------- |
| label             | ReactNode; the legend                            | Required |
| items             | `readonly CheckboxGroupItem[]`                   | Required |
| name              | string; form data key for every option           | None     |
| value             | `string[]`; controlled checked values            | None     |
| defaultValue      | `string[]`; uncontrolled initial values          | `[]`     |
| onValueChange     | `(value: string[]) => void`                      | None     |
| selectAll         | CheckboxGroupSelectAll; never submitted          | None     |
| description       | ReactNode; linked help text                      | None     |
| error             | ReactNode; marks the group invalid               | None     |
| required          | boolean; one enabled option must be checked      | false    |
| requiredIndicator | ReactNode; replaces the required marker          | `*`      |
| disabled          | boolean; disables every option                   | false    |
| form              | string; associates every option with a form      | None     |
| controlSize       | small / medium / large; items may override       | medium   |
| parts             | label / description / error / required / options | None     |
| className / style | string / ThemeStyle                              | None     |
| ref               | `Ref<HTMLFieldSetElement>`                       | None     |
| Other props       | Native fieldset props except role                | Native   |

### Option configuration

| Type                   | Properties                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------- |
| CheckboxGroupItem      | `value: string` and `label: ReactNode`; Checkbox presentation, disabled, id and ref |
| CheckboxGroupSelectAll | `label: ReactNode`; Checkbox presentation, disabled, id and ref                     |

Configurations cannot set checked state, `name`, `form`, `required` or `onChange`.

Exports: `CheckboxGroup`, `CheckboxGroupProps`, `CheckboxGroupItem`, `CheckboxGroupSelectAll`.
