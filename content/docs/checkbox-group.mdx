## Usage

Use [Checkbox](/docs/checkbox/) for one option or [RadioGroup](/docs/radio-group/) for a single choice from a list.

The optional `selectAll` checkbox toggles enabled options and shows a mixed state when some are checked.

## State

Use `defaultValue` for the initial selection, or pass `value` with `onValueChange`. Both take an array of item values. Form reset restores `defaultValue` for uncontrolled groups.

With `name`, each checked, enabled option submits one value. Select all submits nothing. `required` needs at least one enabled selection.

## Accessibility

Give the group, each item, and select all a `label`. Tab moves between enabled checkboxes and Space toggles the focused option. Use `description` for help and `error` for a validation message.

## Styling

Options use [Checkbox styling](/docs/checkbox/#styling). Use `parts.options` or `--rad-checkbox-group-gap` for option spacing.

## API

| Prop                        | Purpose                                              |
| --------------------------- | ---------------------------------------------------- |
| `items`                     | Each item has a unique string `value` and a `label`. |
| `controlSize`               | `small`, `medium` (default), or `large`.             |
| `className`, `style`, `ref` | Target the group’s fieldset.                         |
