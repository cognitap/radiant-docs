## Usage

Use `Split` for main content with supporting content, such as results with their filters. Say which side the secondary area takes and how the width is shared; Split decides the geometry. Use [Grid](/docs/grid/) for equal items and [Compare](/docs/compare/) for options weighed against each other.

```tsx
<Split side="start">
  <SplitMain>
    <Results />
  </SplitMain>
  <SplitSecondary>
    <Filters />
  </SplitSecondary>
</Split>
```

## Accessibility

The divs add no role or focus stop. Below 40rem the parts stack in source order; wider, `side` places the secondary area. Write the parts in reading order and pick a `side` that keeps that order, so focus and reading order match what people see.

## Styling

Split is an inline-size container, so it follows its own width, not the viewport. Below 40rem each part takes the full width; from 40rem they share a row. In a box that sizes to its content, Split takes 20rem. `gap` reads `--rad-spacing-tight`, `--rad-spacing-normal` or `--rad-spacing-airy`.

| Part           | Element                                | data-slot         |
| -------------- | -------------------------------------- | ----------------- |
| Split          | `div`, wrapping row, container `split` | `split`           |
| SplitMain      | `div`                                  | `split-main`      |
| SplitSecondary | `div`                                  | `split-secondary` |

## API

Every part takes the native props of a div, `className`, `style` as ThemeStyle, additive `data-slot` and a ref.

| Split prop | Type                            | Default    |
| ---------- | ------------------------------- | ---------- |
| side       | `'start' \| 'end'`              | `'end'`    |
| ratio      | `'balanced' \| 'main'`          | `'main'`   |
| gap        | `'tight' \| 'normal' \| 'airy'` | `'normal'` |

`ratio="main"` gives the main area two thirds of the row; `balanced` halves it. Other values throw. Exports: `Split`, `SplitMain`, `SplitSecondary`, `SplitProps`, `SplitMainProps`, `SplitSecondaryProps`, `SplitSide`, `SplitRatio`.
