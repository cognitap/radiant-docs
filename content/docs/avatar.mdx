## Usage

Use Avatar to picture a person or entity. It shows the image once it loads and short text, usually initials, while it loads or when it fails. Use [Badge](/docs/badge/) for a status or count and [Tag](/docs/tag/) for a removable chip. For a profile control, put an Avatar with `alt=""` inside a [Button](/docs/button/) or [Link](/docs/link/) named by its text.

```tsx
<Avatar
  alt="Jordan Rivera"
  src={user.photoUrl}
  fallback="JR"
/>
```

`alt` is required. Write the full name for a standalone avatar. Use `alt=""` when the avatar is decorative or visible text beside it already names the person, so the name is read once. `fallback` is plain text, usually initials, and defaults to `?`. It is never inferred from `alt` and never supplies the name.

## State

Avatar has no controlled or uncontrolled value and submits nothing. Image load state is internal. It resets when `src`, `srcSet`, `sizes`, `crossOrigin` or `referrerPolicy` change, and the root element, its ref and its size stay the same. Images that finish loading before hydration are detected on mount. The application owns image URLs, privacy and revoking object URLs.

## Accessibility

The root span is the only named element, and its name holds through loading, failure and recovery. A non-empty `alt` gives it `role="img"` and `aria-label`. An empty `alt` gives it `aria-hidden="true"` and no role. Whitespace-only `alt` throws. The image and the fallback are always hidden from assistive technology.

Avatar rejects `aria-label`, `aria-labelledby`, `aria-hidden`, `aria-live`, `role`, `tabIndex`, `children` and `contentEditable`. A non-string `fallback` throws.

| Key             | Behavior                               |
| --------------- | -------------------------------------- |
| Tab / Shift+Tab | Skip the avatar; it is never focusable |

## Motion

None. A loaded image replaces the fallback without a transition.

## Styling

| Part     | Element | Data attributes                                                            | Target               |
| -------- | ------- | -------------------------------------------------------------------------- | -------------------- |
| Root     | `span`  | `data-slot="avatar"`, `data-control-size="small \| medium \| large"`       | `className`, `style` |
| Image    | `img`   | `data-slot="avatar-image"`, `data-state="loading \| loaded \| error"`      | `parts.image`        |
| Fallback | `span`  | `data-slot="avatar-fallback"`, `data-state="fallback \| loading \| error"` | `parts.fallback`     |

The fallback is `fallback` when there is no source and is removed once the image loads. `components.avatar` or local variables set `--rad-avatar-size` (with `-small` and `-large`), `-radius`, `-border-width`, `-border-color`, `-background`, `-color` and `-font-size`. Forced colors use `CanvasText` and `Canvas`.

## API

### Avatar

| Prop           | Type                                                                        | Default         |
| -------------- | --------------------------------------------------------------------------- | --------------- |
| alt            | string; the accessible name, `""` when decorative                           | Required        |
| fallback       | string; short visual text such as initials                                  | `?`             |
| src            | string                                                                      | None            |
| srcSet / sizes | string; native responsive sources                                           | None            |
| loading        | eager / lazy                                                                | None            |
| decoding       | sync / async / auto                                                         | None            |
| crossOrigin    | anonymous / use-credentials / `''`                                          | None            |
| referrerPolicy | `HTMLAttributeReferrerPolicy`                                               | None            |
| controlSize    | small / medium / large; 2rem, 2.5rem, 3rem                                  | medium          |
| parts          | `{ image?: PartStyle; fallback?: PartStyle }`                               | None            |
| className      | string                                                                      | None            |
| style          | ThemeStyle, including `--rad-avatar-*`                                      | None            |
| data-slot      | Extra tokens after `avatar`                                                 | avatar          |
| ref            | `Ref<HTMLSpanElement>`                                                      | None            |
| Other props    | Native span props except the rejected naming, role, focus and content props | Native defaults |

Exports: `Avatar`, `AvatarProps`.
