## Usage

Use ToggleGroup for related pressed actions. Use [RadioGroup](/docs/radio-group/) for native form choices, [Tabs](/docs/tabs/) to switch panels, or [Button](/docs/button/) for one toggle.

```tsx
<ToggleGroup
  aria-label="Formatting"
  type="multiple"
  defaultValue={['bold']}
>
  <ToggleGroupItem value="bold">Bold</ToggleGroupItem>
  <ToggleGroupItem value="italic">Italic</ToggleGroupItem>
</ToggleGroup>
```

## State

Single selection allows one string or `null`; multiple selection uses distinct strings. Use `value` or `defaultValue`, never both; ownership and type stay fixed per mount. Callbacks request changes and controlled owners may refuse. Form reset leaves selection unchanged. The application owns submission values.

`useToggleGroup()` reads state and requests item changes; it returns `null` outside a group. Item values must be distinct. Prevent default in an item's `onClick` to cancel activation.

## Accessibility

Name the group with `aria-label` or `aria-labelledby`. Items are real pressed Buttons. Focus navigation does not change selection. Inside [Toolbar](/docs/toolbar/), the toolbar owns focus navigation. Disabled items are skipped. Keep labels and selected/focus cues visible.

| Key               | Behavior                                |
| ----------------- | --------------------------------------- |
| Tab / Shift+Tab   | One group entry, then leave             |
| Horizontal arrows | Move focus, respecting native direction |
| Vertical arrows   | Move focus in vertical groups           |
| Home / End        | First / last enabled item               |
| Enter / Space     | Toggle the focused item                 |

## Motion

The single-selection `segmented` variant adds an indicator. `MotionProvider` from `@cognitap/radiant/motion/react` enables its theme `follow` spring. Without it, geometry updates directly. Reduced motion and local off stop spatial feedback; selection remains immediate.

## Styling

Root props, styles and ref reach the div; item props reach Button. Keep the root positioned for its indicator. `parts.indicator` styles the visual span without replacing geometry.

Identities: `toggle-group`, `button toggle-group-item`, `toggle-group-indicator`. Items expose `data-value`, `data-disabled` and `data-selected` on pressed items only, beside `aria-pressed`. The root exposes `data-type`, `data-variant`, `data-orientation`, `data-control-size` and `data-disabled`.

Theme hooks: `components.toggleGroup.gap`, `padding`, `radius`, `background`, `indicatorColor`, `indicatorRadius`, `indicatorShadow`, or `--rad-toggle-group-*` variables. Item presentation follows Button.

## API

### ToggleGroup

| Prop                         | Type                                           | Default    |
| ---------------------------- | ---------------------------------------------- | ---------- |
| aria-label / aria-labelledby | string; accessible name                        | Required   |
| type                         | single / multiple; fixed per mount             | single     |
| value                        | string or null (single) / string[] (multiple)  | None       |
| defaultValue                 | string or null / string[]                      | null / []  |
| onValueChange                | (value: ToggleGroupValue) => void              | None       |
| variant                      | buttons / segmented; segmented requires single | buttons    |
| orientation                  | `Orientation`: horizontal / vertical           | horizontal |
| loop                         | boolean; arrows wrap at the ends               | true       |
| disabled                     | boolean; disables every item                   | false      |
| controlSize                  | small / medium / large                         | medium     |
| motion                       | inherit / off; indicator and item presses      | inherit    |
| parts                        | `{ indicator?: PartStyle }`                    | None       |
| className / style            | string / ThemeStyle                            | None       |
| ref                          | `Ref<HTMLDivElement>`                          | None       |
| Other props                  | Native div props except role and tabIndex      | Native     |

### ToggleGroupItem

| Prop              | Type                                                                        | Default         |
| ----------------- | --------------------------------------------------------------------------- | --------------- |
| value             | string; distinct within the group                                           | Required        |
| disabled          | boolean; adds to the group's disabled                                       | false           |
| controlSize       | small / medium / large                                                      | From group      |
| variant           | Button variant; ghost under a segmented group                               | outline         |
| tone              | accent / neutral / warning / danger                                         | neutral         |
| render            | (props: ToggleGroupRenderProps) => ReactElement                             | Native button   |
| className / style | string / ThemeStyle                                                         | None            |
| ref               | `Ref<HTMLButtonElement>`                                                    | None            |
| Other props       | [Button](/docs/button/) props except pressed state, type, role and tabIndex | Button defaults |

The root `variant` picks the group treatment; the item `variant` is Button's.

Exports: `ToggleGroup`, `ToggleGroupItem`, `useToggleGroup`, `ToggleGroupProps`, `ToggleGroupItemProps`, `ToggleGroupState`, `ToggleGroupValue`, `ToggleGroupVariant`, `ToggleGroupRenderProps`. `orientation` uses the shared `Orientation` type.
