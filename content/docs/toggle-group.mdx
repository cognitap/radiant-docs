## Usage

Use ToggleGroup for choices such as text alignment or formatting. Use [RadioGroup](/docs/radio-group/) for form choices or [Tabs](/docs/tabs/) to switch panels.

## State

Single selection uses a string or `null`. Set `type="multiple"` for an array of selected strings. Use `defaultValue` for the initial selection or `value` with `onValueChange` to control it.

## Accessibility

Name the group with `aria-label` or `aria-labelledby`. Tab enters once. Arrow keys move focus and skip disabled items. Enter or Space toggles the focused item. Inside a [Toolbar](/docs/toolbar/), the toolbar manages focus.

## Styling

Use `variant="segmented"` for single selection with a shared track. Set `parts.indicator` to style the marker. With motion enabled, [MotionProvider](/docs/foundations/motion/) animates it as it follows selection.

## API

| ToggleGroup prop     | Type and default                           |
| -------------------- | ------------------------------------------ |
| type                 | single (default) / multiple                |
| value / defaultValue | string or null / string[] in multiple mode |
| onValueChange        | Receives the next selection                |
| variant              | buttons (default) / segmented              |
| orientation          | horizontal (default) / vertical            |
| loop                 | Wraps arrow navigation by default          |
| disabled             | Disables every item                        |
| controlSize          | small / medium (default) / large           |
| motion               | inherit (default) / off                    |
| parts.indicator      | `PartStyle`                                |

Each `ToggleGroupItem` needs a distinct `value` and takes [Button](/docs/button/) styling props. The group owns each item’s pressed state.

Use `useToggleGroup()` inside the group to read `value` or call `setItemPressed(value, pressed)`.
