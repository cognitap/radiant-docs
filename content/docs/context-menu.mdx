## Usage

Use ContextMenu for contextual commands on content. **Provide the same actions through visible controls**: right-click and long-press must never be the only way to complete a task. Use [Menu](/docs/menu/) for a visible menu button.

```tsx
<ContextMenu>
  <ContextMenuTrigger aria-label="Project file">
    <strong>Project brief</strong>
  </ContextMenuTrigger>
  <ContextMenuPortal>
    <ContextMenuContent>
      <ContextMenuItem onSelect={duplicate}>Duplicate</ContextMenuItem>
    </ContextMenuContent>
  </ContextMenuPortal>
</ContextMenu>
<Button onClick={duplicate}>Duplicate file</Button>
```

## State

Choose `open` or `defaultOpen`, never both. `onOpenChange` requests updates; controlled owners may refuse. Ownership stays fixed per mount. `useContextMenu()` returns open state, `setOpen` and the content ID, or `null` outside the family. Items, radio groups and submenus reuse [Menu's owners and cancellation rules](/docs/menu/#state).

## Accessibility

Trigger is a named native div grouping content. Supply `aria-label` or `aria-labelledby`, plus instructions when contextual commands would be hard to discover. It is focusable by default and keeps native child interactions.

| Input                            | Behavior                                                                                   |
| -------------------------------- | ------------------------------------------------------------------------------------------ |
| Right-click                      | Open at the pointer                                                                        |
| Touch hold                       | Open after 500ms; movement beyond 10px, release or cancellation aborts the pending gesture |
| Shift+F10 / Menu key             | Open below the focused descendant or target; inline start follows RTL                      |
| Menu arrows, Home/End, typeahead | [Navigate Menu items and submenus](/docs/menu/#accessibility)                              |
| Enter / Space                    | Activate the focused command                                                               |
| Escape                           | Close nearest surface; restore its opener                                                  |
| Tab / Shift+Tab                  | Close the tree and continue from the target                                                |

Opening moves focus into the menu. Outside interaction dismisses without stealing focus. The local portal preserves theme and modal ancestry. Long-press leaves native panning available and suppresses its trailing click; a later action remains usable.

## Motion

Optional `MotionProvider` supplies Menu's entry feedback. Reduced motion and local off win; dismissal stays immediate.

## Styling

Native props, refs, classes and styles reach Trigger's div or the real Menu part. Slot identities retain `menu-*`, Button and Popover identities, adding `context-menu-*`. Trigger exposes open/closed `data-state`; Content retains Menu state and placement attributes.

Use `components.contextMenu.width` or `--rad-context-menu-width`; remaining styling inherits [Menu](/docs/menu/#styling).

## API

| Part                                     | Props                                                                                                | Defaults                                       |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| ContextMenu                              | open / defaultOpen: boolean; onOpenChange; children                                                  | false; no callback                             |
| ContextMenuTrigger                       | Required aria-label or aria-labelledby; native div props/events/ref; tabIndex; className; ThemeStyle | tabIndex 0; named group                        |
| ContextMenuPortal                        | children                                                                                             | None; no host                                  |
| ContextMenuContent                       | MenuContent props: side, align, sideOffset, collisionPadding, motion, native div props/ref           | bottom; start; 0; 8; inherit                   |
| ContextMenuItem                          | MenuItem props: onSelect, textValue, closeOnSelect; Button props/ref                                 | closeOnSelect true                             |
| ContextMenuGroup / Label / Separator     | Corresponding Menu part props/ref                                                                    | Menu defaults                                  |
| ContextMenuCheckboxItem                  | checked/defaultChecked; onCheckedChange; indeterminate; indicator styling; Item props                | false; no callback; false; closeOnSelect false |
| ContextMenuRadioGroup / RadioItem        | value/defaultValue and onValueChange / required string value; Menu props                             | null / group-owned; closeOnSelect false        |
| ContextMenuSub / SubTrigger / SubContent | Corresponding Menu part props                                                                        | false / Menu defaults / logical end, offset 4  |
| useContextMenu()                         | open; setOpen(boolean); contentId                                                                    | null outside family                            |

Offsets and padding are finite nonnegative pixels. Every part exports its `ContextMenu…Props` type; `ContextMenuState` is also exported. Trigger/content/group/label refs are `Ref<HTMLDivElement>`; action refs are `Ref<HTMLButtonElement>`; separator refs are `Ref<HTMLHRElement>`. Root, Sub and Portal have no host.
