## Usage

Use ContextMenu for commands that act on one surface, such as a file card or a canvas. Context menus are hidden, so **offer every command through a visible control too**. Use [Menu](/docs/menu/) when a visible button opens the commands.

```tsx
<ContextMenu>
  <ContextMenuTrigger aria-label="Project file">
    <strong>Project brief</strong>
  </ContextMenuTrigger>
  <ContextMenuPortal>
    <ContextMenuContent>
      <ContextMenuItem onSelect={duplicate}>Duplicate</ContextMenuItem>
    </ContextMenuContent>
  </ContextMenuPortal>
</ContextMenu>
<Button onClick={duplicate}>Duplicate file</Button>
```

## State

ContextMenu takes `open` or `defaultOpen` with `onOpenChange`. Pick one owner per mount; switching throws. A controlled owner may refuse a request. `useContextMenu()` returns `{ open, setOpen, contentId }`, or `null` outside a ContextMenu.

Items are commands, not toggles: ContextMenuItem takes no `pressed` props. For a command that turns something on or off, use ContextMenuCheckboxItem. Checkbox items, radio groups, submenus and native form submission work as in [Menu](/docs/menu/#state).

## Accessibility

The trigger is a focusable `div` with a group role. Name it with `aria-label` or `aria-labelledby`; that name also labels the menu. Add visible instructions when the commands would be hard to discover.

| Input                       | Behavior                                                                   |
| --------------------------- | -------------------------------------------------------------------------- |
| Right-click                 | Open at the pointer; a second right-click moves the open menu there        |
| Touch hold                  | Open after 500 ms; moving more than 10 px or releasing first cancels       |
| Shift+F10 / ContextMenu key | Open at the focused trigger and focus the first item                       |
| Keys inside the menu        | [Menu keyboard](/docs/menu/#accessibility): arrows, typeahead, Escape, Tab |

The menu stays inside the viewport. Outside interaction closes it without moving focus.

## Motion

Inside [MotionProvider](/docs/foundations/motion/), the content fades and scales in. Set `motion="off"` on ContextMenuContent or ContextMenuSubContent to turn it off for that surface. Reduced motion is honored.

## Styling

Props, refs, classes and styles reach each part's native element. Every part adds a `context-menu-*` slot to its `menu-*` slot, such as `context-menu-trigger` and `context-menu-item`. The trigger exposes `data-state="open"` or `"closed"`.

Set the width with `components.contextMenu.width` or `--rad-context-menu-width`, which falls back to `--rad-menu-width`. Other tokens follow [Menu](/docs/menu/#styling).

## API

### ContextMenu

| Prop         | Type                      | Default |
| ------------ | ------------------------- | ------- |
| open         | boolean; controlled       | None    |
| defaultOpen  | boolean                   | false   |
| onOpenChange | `(open: boolean) => void` | None    |
| children     | ReactNode                 | None    |

### ContextMenuTrigger

| Prop                         | Type                                                                   | Default  |
| ---------------------------- | ---------------------------------------------------------------------- | -------- |
| aria-label / aria-labelledby | string; one is required                                                | Required |
| tabIndex                     | number                                                                 | 0        |
| style                        | ThemeStyle                                                             | None     |
| ref                          | `Ref<HTMLDivElement>`                                                  | None     |
| Other props                  | div props except id, role, aria-haspopup, aria-expanded, aria-controls | Native   |

### ContextMenuPortal

| Prop     | Type      | Default |
| -------- | --------- | ------- |
| children | ReactNode | None    |

### ContextMenuContent

| Prop             | Type                          | Default |
| ---------------- | ----------------------------- | ------- |
| side             | top / right / bottom / left   | bottom  |
| align            | start / center / end          | start   |
| sideOffset       | number; pixels from the point | 0       |
| collisionPadding | number                        | 8       |
| motion           | inherit / off                 | inherit |
| Other props      | MenuContent props; `div` ref  | Native  |

### Items, groups and submenus

These parts take the same props and defaults as their [Menu parts](/docs/menu/#api).

| Part                    | Same as                                          | Key defaults                        |
| ----------------------- | ------------------------------------------------ | ----------------------------------- |
| ContextMenuItem         | [MenuItem](/docs/menu/#menuitem)                 | closeOnSelect true; no toggle props |
| ContextMenuCheckboxItem | [MenuCheckboxItem](/docs/menu/#menucheckboxitem) | checked false; closeOnSelect false  |
| ContextMenuRadioGroup   | [MenuRadioGroup](/docs/menu/#menuradiogroup)     | value null                          |
| ContextMenuRadioItem    | [MenuRadioItem](/docs/menu/#menuradioitem)       | value required; closeOnSelect false |
| ContextMenuGroup        | [MenuGroup](/docs/menu/#menugroup)               | Native                              |
| ContextMenuLabel        | [MenuLabel](/docs/menu/#menulabel)               | Native                              |
| ContextMenuSeparator    | [MenuSeparator](/docs/menu/#menuseparator)       | Separator defaults                  |
| ContextMenuSub          | [MenuSub](/docs/menu/#menusub)                   | defaultOpen false                   |
| ContextMenuSubTrigger   | [MenuSubTrigger](/docs/menu/#menusubtrigger)     | No close on activation              |
| ContextMenuSubContent   | [MenuSubContent](/docs/menu/#menusubcontent)     | Inline end; sideOffset 4            |

Exports each part's `ContextMenu…Props` type, plus `ContextMenuState` and `ContextMenuRenderProps` for `render` adapters on items.
