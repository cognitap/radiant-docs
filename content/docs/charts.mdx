## Usage

Use a chart to show a trend or comparison. Use [Meter](/docs/meter/) for one value, [Table](/docs/table/) for records people act on, and ChartDataTable for exact numbers alone.

```tsx
import { LineChart } from '@cognitap/radiant/charts'

;<LineChart
  label="Completed sessions"
  data={[
    { key: 'one', label: 'Round 1', values: { sessions: 12 } },
    { key: 'two', label: 'Round 2', values: { sessions: 24 } }
  ]}
  series={[{ key: 'sessions', label: 'Sessions' }]}
/>
```

The separate entry keeps the renderer out of the root import.

## State

Your app owns the data. Charts keep no value, so there is nothing to reset or submit.

Keys must be unique and labels nonempty. A value is a finite number or `null`, which breaks a line and shows `—` in the table. Line, bar and area charts take one to six series. PieChart takes exactly one, with nonnegative values; colors repeat after six slices. Invalid data throws a TypeError.

Areas overlap rather than stack. `formatValue` formats ticks, tooltips and cells.

With no points to plot, the chart shows `emptyText` and keeps its legend and table.

## Accessibility

The chart is a native `figure`. Its required visible `label` names the figure, the scrolling plot and the data table; an empty label throws. `description` describes the figure.

Each point is a button named like "Round 1, Completed: 12", with a Tooltip showing that text. Points share one tab stop, ordered by row and then series. Series also differ by numbered legend entries and dash patterns, and stay visible in forced colors.

| Key             | Behavior                              |
| --------------- | ------------------------------------- |
| Tab             | Reach the last focused point          |
| Arrow Right     | Next point; previous in RTL           |
| Arrow Left      | Previous point; next in RTL           |
| Arrow Down / Up | Next / previous point                 |
| Home / End      | First / last point                    |
| Escape          | Dismiss the tooltip                   |
| Enter / Space   | Toggle the data table, on its summary |

## Motion

Charts redraw at once and points do not animate. The tooltip follows the motion provider and reduced motion.

## Styling

| Part        | Element and `data-slot`                                                                                                  | `parts` key   |
| ----------- | ------------------------------------------------------------------------------------------------------------------------ | ------------- |
| Root        | `figure`; `chart line-chart` (or bar, area, pie); `data-kind`                                                            | Root props    |
| Caption     | `figcaption`; `chart-caption`                                                                                            | `caption`     |
| Description | `div`; `chart-description`                                                                                               | `description` |
| Plot        | `div`; `chart-plot`, inside a horizontal ScrollArea                                                                      | `plot`        |
| Point       | `button`; `tooltip-trigger chart-point`                                                                                  | `point`       |
| Tooltip     | `span`; `tooltip-content chart-tooltip`                                                                                  | `tooltip`     |
| Empty       | `p`; `chart-empty`                                                                                                       | None          |
| Legend      | `ul`; `chart-legend`                                                                                                     | `legend`      |
| Disclosure  | `details`; `chart-disclosure`                                                                                            | None          |
| Table       | `table chart-data-table`                                                                                                 | `table`       |
| Theme       | `components.chart`: `gap`, `height` (`20rem`), `strokeWidth` (`2`), `gridColor`, `series1`–`series8`; or `--rad-chart-*` | None          |

`className`, `style`, `ref` and native props reach the figure. The plot is at least 480px wide, or 72px per row, and scrolls when narrower. Series colors come from the theme's `--rad-series-N-solid` tokens; `seriesPalette` from `@cognitap/radiant/color` derives them from a color palette.

## API

### LineChart, BarChart, AreaChart and PieChart

| Prop              | Type                                                                                | Default                       |
| ----------------- | ----------------------------------------------------------------------------------- | ----------------------------- |
| label             | ReactNode; visible caption and name                                                 | Required                      |
| description       | ReactNode                                                                           | None                          |
| data              | readonly ChartDatum[]                                                               | Required                      |
| series            | readonly ChartSeries[]; PieChart takes `[ChartSeries]`                              | Required                      |
| formatValue       | (value: number, series: ChartSeries) => string                                      | `String(value)`               |
| categoryLabel     | string; first table column header                                                   | `'Category'`                  |
| legendLabel       | string; legend list name                                                            | `'Chart legend'`              |
| tableLabel        | string; disclosure summary                                                          | `'View chart data'`           |
| emptyText         | string                                                                              | `'No chart data to display.'` |
| parts             | caption, description, plot, legend, point, tooltip, table: `{ className?, style? }` | None                          |
| className / style | string / ThemeStyle                                                                 | None                          |
| Other props       | Native figure props except `role`, `aria-label` and `aria-labelledby`               | Native                        |

### ChartDataTable

| Prop                       | Type                           | Default       |
| -------------------------- | ------------------------------ | ------------- |
| label                      | ReactNode; the table's caption | Required      |
| data / series              | As on a chart                  | Required      |
| formatValue, categoryLabel | As on a chart                  | As on a chart |
| Other props                | Table props                    | Native        |

### Types

| Type           | Shape                                                                              |
| -------------- | ---------------------------------------------------------------------------------- |
| ChartDatum     | `{ key: string; label: string; values: Readonly<Record<string, number \| null>> }` |
| ChartSeries    | `{ key: string; label: string }`                                                   |
| chartPalette() | Deprecated; use `tokens.series` from `seriesPalette`                               |

Exports: `LineChart`, `BarChart`, `AreaChart`, `PieChart`, `ChartDataTable`, `chartPalette`, `ChartProps`, `LineChartProps`, `BarChartProps`, `AreaChartProps`, `PieChartProps`, `ChartDataTableProps`, `ChartDatum`, `ChartSeries`.
