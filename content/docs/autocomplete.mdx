## Usage

Use Autocomplete when suggestions help but any text is allowed. Use [Combobox](/docs/combobox/) or [Select](/docs/select/) when the value must be one of the options, [MultiSelect](/docs/multi-select/) or [TagsInput](/docs/tags-input/) for several values, and [Command](/docs/command/) to run actions.

```tsx
<Field label="City">
  <Autocomplete
    name="city"
    items={[
      { value: 'Budapest', label: 'Budapest' },
      { value: 'Vienna', label: 'Vienna' }
    ]}
    defaultValue="Another city"
  />
</Field>
```

A suggestion's `value` is the text written into the input. A rich `label` needs a plain `textValue` for matching.

## State

Use `defaultValue`, or `value` with `onValueChange`, not both; mixing them or switching owner throws. The value is the input text, and empty text is `''`. The text is also the search query, so there is no separate `query`. `open`, `defaultOpen` and `onOpenChange` follow the same rule.

The input carries `name` and submits its text, including text that matches no suggestion. `required` uses native constraint validation. Form reset restores the uncontrolled text without calling `onValueChange`; a controlled Autocomplete keeps its value, so reset your state in `onReset`. `disabled` leaves the text out of form data. `readOnly` blocks edits and keeps it submitted. Pass `aria-invalid` to Autocomplete to mark it invalid outside Field.

For server results, set `filter={null}` and pass the current `items`. `loading` shows `loadingText` and `errorText` shows a load failure; neither changes the text. Your application owns requests, cancellation and validation.

## Accessibility

The input has `role="combobox"`, and suggestions are `option` items in a `listbox`. Name the input with [Field](/docs/field/) or `aria-label`. A polite `status` region announces loading, empty and error text. Focus stays in the input while `aria-activedescendant` marks the highlighted suggestion.

| Key                 | Behavior                                                      |
| ------------------- | ------------------------------------------------------------- |
| Typing              | Edit the text, filter suggestions and open the list           |
| Arrow Down / Up     | Open and highlight the next or previous enabled suggestion    |
| Alt+Arrow Down / Up | Open or close without moving the highlight                    |
| Enter               | Write the highlighted suggestion; with none, close and submit |
| Escape              | Close and keep the typed text                                 |
| Tab / Shift+Tab     | Close and move focus                                          |

Accepting a suggestion fires a native `input` event. AutocompleteTrigger ("Show suggestions") and AutocompleteClear ("Clear text") stay out of the Tab order; native editing clears the text from the keyboard.

## Motion

Inside [MotionProvider](/docs/foundations/motion/), the popup fades in; closing is immediate. Set `motion="off"` on AutocompleteContent to turn it off. Reduced motion shows it at full opacity.

## Styling

Autocomplete and AutocompletePortal have no host. Every other part takes `className`, `style` and `ref`. Each slot keeps its `combobox-*` name and adds an `autocomplete-*` one.

| Part                | Attributes                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------------- |
| Control wrapper     | `data-slot="combobox-control autocomplete-control"`; default composition only                     |
| AutocompleteInput   | `data-slot="combobox-input autocomplete-input"`, `data-control-size`, `data-invalid`              |
| AutocompleteTrigger | `data-slot="button combobox-trigger autocomplete-trigger"`                                        |
| AutocompleteClear   | `data-slot="button combobox-clear autocomplete-clear"`; renders only for nonempty text            |
| AutocompleteContent | `data-slot="combobox-content autocomplete-content"`, `data-state="open \| closed"`, `data-motion` |
| Listbox             | `data-slot="combobox-listbox autocomplete-listbox"` inside the content                            |
| AutocompleteItem    | `data-slot="combobox-item autocomplete-item"`, `data-value`, `data-highlighted`, `data-disabled`  |
| AutocompleteStatus  | `data-slot="combobox-status autocomplete-status"`                                                 |

Theme with the Combobox tokens, such as `--rad-combobox-height`, `--rad-combobox-radius` and `--rad-combobox-border-color`.

## API

### Autocomplete

| Prop                 | Type                                               | Default                                   |
| -------------------- | -------------------------------------------------- | ----------------------------------------- |
| items                | `readonly AutocompleteOption[]`; distinct values   | Required                                  |
| value / defaultValue | string                                             | None / `''`; one owner                    |
| onValueChange        | `(value: string) => void`                          | None                                      |
| open / defaultOpen   | boolean                                            | None / false                              |
| onOpenChange         | `(open: boolean) => void`                          | None                                      |
| filter               | `((item, query: string) => boolean) \| null`       | Matches value, textValue and string label |
| loading              | boolean; hides suggestions and shows `loadingText` | false                                     |
| loadingText          | string                                             | `'Loading results…'`                      |
| emptyText            | ReactNode                                          | `'No results found.'`                     |
| errorText            | ReactNode; load failure, hides suggestions         | None                                      |
| name / form          | string; reach the input                            | None                                      |
| disabled / required  | boolean                                            | Field's, else false                       |
| readOnly             | boolean                                            | false                                     |
| aria-invalid         | Native; forwarded to the input                     | Field's                                   |
| controlSize          | small / medium / large                             | medium                                    |
| children             | ReactNode                                          | Input, trigger and content                |

### AutocompleteInput

| Prop         | Type                                                                                              | Default |
| ------------ | ------------------------------------------------------------------------------------------------- | ------- |
| aria-invalid | Native; overrides the root's                                                                      | Root's  |
| autoComplete | string                                                                                            | `'off'` |
| Other props  | input props except value, defaultValue, name, form, type, role, disabled, required and popup ARIA | Native  |

### AutocompleteTrigger

| Prop        | Type                                                                                                                                         | Default              |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| render      | `(props: AutocompleteRenderProps) => ReactElement`                                                                                           | None                 |
| aria-label  | string                                                                                                                                       | `'Show suggestions'` |
| children    | ReactNode                                                                                                                                    | Chevron              |
| Other props | Button props except variant, tone, type, pending, disabled, controlSize, iconOnly, fullWidth, motion, tabIndex, popup ARIA and pressed props | Native               |

### AutocompleteClear

| Prop        | Type                                               | Default        |
| ----------- | -------------------------------------------------- | -------------- |
| render      | `(props: AutocompleteRenderProps) => ReactElement` | None           |
| aria-label  | string                                             | `'Clear text'` |
| children    | ReactNode                                          | Cross          |
| Other props | Same as AutocompleteTrigger                        | Native         |

### AutocompletePortal

| Prop     | Type      | Default |
| -------- | --------- | ------- |
| children | ReactNode | None    |

Renders beside the input without a wrapper; the popup uses the top layer.

### AutocompleteContent

| Prop             | Type                               | Default            |
| ---------------- | ---------------------------------- | ------------------ |
| sideOffset       | number                             | 4                  |
| collisionPadding | number                             | 8                  |
| motion           | inherit / off                      | inherit            |
| children         | ReactNode                          | One item per match |
| Other props      | div props except popover, role, id | Native             |

### AutocompleteItem

| Prop        | Type                                | Default    |
| ----------- | ----------------------------------- | ---------- |
| value       | string; must exist in `items`       | Required   |
| children    | ReactNode                           | Item label |
| Other props | div props except id, role, tabIndex | Native     |

### AutocompleteStatus

| Prop        | Type                  | Default     |
| ----------- | --------------------- | ----------- |
| children    | ReactNode             | Root status |
| Other props | div props except role | Native      |

Exports `AutocompleteProps`, `AutocompleteOption`, `AutocompleteRenderProps`, `AutocompleteInputProps`, `AutocompleteTriggerProps`, `AutocompleteClearProps`, `AutocompletePortalProps`, `AutocompleteContentProps`, `AutocompleteItemProps` and `AutocompleteStatusProps`.
