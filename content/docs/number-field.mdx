## Usage

Use [Field](/docs/field/) for a label and errors. Use [Slider](/docs/slider/) for approximate values or [Input](/docs/input/) for identifiers such as postal codes.

## State

Use `defaultValue` or `value` with `onValueChange`. Values are numbers or `null`. Form reset restores `defaultValue`.

Incomplete or out-of-range text blocks submission while editing. On blur, a parsed number is clamped to the range and formatted. The form submits the raw number under `name`, so `12,50 €` submits `12.5` and `25%` submits `0.25`.

## Accessibility

The input has the spinbutton role. Give it a visible label, `aria-label` or `aria-labelledby`. Up and Down arrows change the value by `step`. Page Up and Page Down use `largeStep`. The stepper buttons keep focus in the input.

## Styling

Use `parts.wrapper`, `parts.increment` and `parts.decrement` to style the field and buttons. See [focus outlines](/docs/foundations/theming/#focus-outlines) for focus and error colors.

## API

| Prop                               | Purpose                                                                 |
| ---------------------------------- | ----------------------------------------------------------------------- |
| `min`, `max`                       | Optional bounds.                                                        |
| `step`, `largeStep`                | Default to `1` and ten times `step`.                                    |
| `locale`, `formatOptions`          | Locale and decimal, currency, or percent formatting.                    |
| `steppers`                         | Set to `false` to hide the buttons. Keyboard stepping still works.      |
| `incrementLabel`, `decrementLabel` | Accessible button labels.                                               |
| `readOnly`, `disabled`             | Both prevent editing. Read-only values are included in form submission. |
| `controlSize`                      | `small`, `medium` (default), or `large`.                                |
| `className`, `style`, `ref`        | Target the native input with `data-slot="number-field"`.                |
