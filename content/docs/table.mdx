## Usage

Use Table for records that people compare across rows and columns. Each part renders its native element, and links and buttons in cells are ordinary [Link](/docs/link/) and [Button](/docs/button/) controls.

Use CSS grid or [Card](/docs/card/) for layout without row and column relationships, and [ScrollArea](/docs/scroll-area/) for a scroll surface that is not a table. Sorting, row selection and arrow-key cell navigation belong to a future DataTable; Table adds no grid behavior.

```tsx
<Table>
  <TableCaption>Team members</TableCaption>
  <TableHead>
    <TableRow>
      <TableHeader>Name</TableHeader>
      <TableHeader>Role</TableHeader>
    </TableRow>
  </TableHead>
  <TableBody>
    <TableRow>
      <TableHeader scope="row">Jordan Rivera</TableHeader>
      <TableCell>Designer</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

## Accessibility

Native table semantics stay intact: no part accepts `role`. `TableCaption` is the table's accessible name, so give every table one; hide it visually with a utility class if the design needs that.

`TableHeader` renders `th` with `scope="col"` by default. Pass `scope="row"` for the first cell of a body or footer row. For complex headers, give `TableHeader` an `id` and list those ids in `TableCell`'s `headers`.

`TableContainer` renders a focusable `section`, a region landmark, so it needs a name. Pass `aria-label`, `aria-labelledby` or both; it throws a `TypeError` when both are missing or blank.

| Key                                | Where                    | Action                                                    |
| ---------------------------------- | ------------------------ | --------------------------------------------------------- |
| Tab / Shift+Tab                    | Page                     | Visit TableContainer, then links and buttons in DOM order |
| Arrow keys, Page Up/Down, Home/End | Focused TableContainer   | Scroll the container                                      |
| Enter / Space                      | Link or button in a cell | Native activation                                         |

## Styling

Each part sets `data-slot` on its host: `table`, `table-caption`, `table-head`, `table-body`, `table-foot`, `table-row`, `table-header`, `table-cell` and `table-container`. A caller's `data-slot` is appended. `className` merges with the caller winning, and `ref` reaches the native element.

Cells align to the start and wrap long words; the caption sits on top. `components.table` in `defineTheme` sets background, color, headerBackground, headerColor, captionColor, borderColor, borderWidth, radius, paddingInline, paddingBlock and fontSize. Override one table with `--rad-table-*` properties on its `style`.

## API

Every part also takes its host's native props except `role`, plus `className`, `style` (ThemeStyle), `data-slot` and `ref`.

### Table

| Prop     | Type      | Default |
| -------- | --------- | ------- |
| children | ReactNode | None    |
| Host     | `table`   |         |

### TableCaption

| Prop     | Type                        | Default |
| -------- | --------------------------- | ------- |
| children | ReactNode; the table's name | None    |
| Host     | `caption`                   |         |

### TableHead, TableBody, TableFoot

| Prop     | Type                                      | Default |
| -------- | ----------------------------------------- | ------- |
| children | TableRow elements                         | None    |
| Host     | `thead` / `tbody` / `tfoot` (bold labels) |         |

### TableRow

| Prop     | Type                      | Default |
| -------- | ------------------------- | ------- |
| children | TableHeader and TableCell | None    |
| Host     | `tr`                      |         |

### TableHeader

| Prop              | Type                              | Default |
| ----------------- | --------------------------------- | ------- |
| scope             | col / row / colgroup / rowgroup   | col     |
| id                | string; target for cell `headers` | None    |
| colSpan / rowSpan | number                            | 1       |
| Host              | `th`                              |         |

### TableCell

| Prop              | Type                               | Default |
| ----------------- | ---------------------------------- | ------- |
| colSpan / rowSpan | number                             | 1       |
| headers           | string; space-separated header ids | None    |
| Host              | `td`                               |         |

### TableContainer

| Prop            | Type                                     | Default |
| --------------- | ---------------------------------------- | ------- |
| aria-label      | string; this or aria-labelledby required | None    |
| aria-labelledby | string; id of the naming element         | None    |
| tabIndex        | Not a prop; always 0                     | 0       |
| Host            | `section`                                |         |

Exports `TableProps`, `TableCaptionProps`, `TableHeadProps`, `TableBodyProps`, `TableFootProps`, `TableRowProps`, `TableHeaderProps`, `TableCellProps` and `TableContainerProps`.
