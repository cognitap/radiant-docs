## Usage

Pass the original string and a literal query. Matching ignores case by default. Set `ignoreDiacritics` to match “café” with “cafe” and keep the original spelling. An empty query shows plain text.

## Accessibility

Matches render as native `<mark>` elements. Keep the full accessible name when using Highlight inside a [Combobox](/docs/combobox/) or [Command](/docs/command/) option.

## Styling

Whole-word matches have even padding. Partial matches stay flush with the surrounding text. Use `parts.mark` to style the matches.

## API

| Prop             | Type      | Default  |
| ---------------- | --------- | -------- |
| text             | string    | Required |
| query            | string    | Required |
| caseSensitive    | boolean   | false    |
| ignoreDiacritics | boolean   | false    |
| parts.mark       | PartStyle | None     |

Exports `Highlight` and `HighlightProps`.
