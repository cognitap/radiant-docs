## Usage

Use RangeSlider for two endpoints of one interval. Use [Slider](/docs/slider/) for one value.

```tsx
import { Field, RangeSlider } from '@cognitap/radiant'

export function NightlyRate() {
  return (
    <Field label="Nightly rate">
      <RangeSlider
        name="price"
        lowerLabel="Minimum nightly rate"
        upperLabel="Maximum nightly rate"
        min={20}
        max={300}
        step={5}
        defaultValue={[60, 180]}
      />
    </Field>
  )
}
```

## State

Use `defaultValue` for local state or `value` and `onValueChange` for app state. The tuple is always lower then upper. Endpoints snap to the same step and may meet. Without a default, the selection spans the available positions.

Both values submit under `name` in lower–upper order. Read them with `FormData.getAll(name)`. Reset restores the uncontrolled initial tuple. Disabled controls omit both entries.

## Accessibility

Name the group with [Field](/docs/field/), `aria-label`, or `aria-labelledby` and supply a distinct label for each thumb. Tab reaches the lower thumb first. Use arrows to step and Home or End to reach each thumb’s current bounds. Horizontal arrows follow writing direction.

## Styling

Target `range-slider`, `range-slider-track`, `range-slider-range` and `range-slider-thumb` slots. Both thumbs inherit `--rad-slider-*` theme variables. `parts.track` and `parts.range` accept `className` and `style`.

## API

| Prop                       | Contract                                       |
| -------------------------- | ---------------------------------------------- |
| `value`, `defaultValue`    | `RangeSliderValue`, a readonly pair of numbers |
| `onValueChange`            | Receives a changed tuple                       |
| `min`, `max`, `step`       | Finite numbers. Defaults are 0, 100, and 1.    |
| `lowerLabel`, `upperLabel` | Required thumb labels                          |
| `name`, `form`, `disabled` | Native form behavior                           |
| `controlSize`, `parts`     | Presentation                                   |

The root ref targets a fieldset.
