## Choose one value

RadioGroup is a [Field](/docs/field/) fieldset and legend. Each Radio is a
native input. Give groups stable, unique names, for example from `useId()`,
and options distinct string values.

```tsx
<RadioGroup
  label="Plan"
  name="workspace-plan"
  defaultValue="pro"
  required
>
  <Radio
    label="Personal"
    value=""
  />
  <Radio
    label="Pro"
    value="pro"
  />
  <Radio
    label="Studio"
    value="studio"
    disabled
  />
</RadioGroup>
```

Tab enters the group; arrows select enabled options, and Space selects the
focused option. Disabled options are skipped. Only the selected, enabled
option contributes to FormData. A disabled group contributes nothing.

## Own selection once

Use `defaultValue` for browser-owned selection; native reset restores its
initial value. Use `value` for controlled selection. `null` clears it; `''`
is a real option value. Do not switch ownership or combine both props.

```tsx
const [plan, setPlan] = useState<string | null>(null)

<form onReset={() => setPlan(null)}>
  <RadioGroup label="Plan" name="account-plan" value={plan} onValueChange={setPlan}>
    <Radio label="Personal" value="" />
    <Radio label="Pro" value="pro" />
  </RadioGroup>
  <Button type="reset">Reset</Button>
</form>
```

Write state from `onValueChange` or native `onChange`, not both. Controlled
reset must restore application values and validation metadata. The group
owns option names and selection; omit conflicting `name`, `checked` and
`defaultChecked` on nested Radio.

Standalone Radio uses `name`, `checked`/`defaultChecked` and native `onChange`:

```tsx
<Radio
  name="standalone"
  value="daily"
  label="Daily digest"
  defaultChecked
/>
```

## Style options

Group styling/ref reach the fieldset. Radio styling/native props/ref reach its
input. Every option needs an accessible name; keep native focus visible.

| Part                                      | Target / identity                       |
| ----------------------------------------- | --------------------------------------- |
| Group label, description, error, required | Field parts; root `field radio-group`   |
| Group `options`                           | Option container; `radio-group-options` |
| Radio `wrapper`                           | Label/span; `radio-wrapper`             |
| Radio `label`                             | Label text; `radio-label`               |
| Radio `indicator`                         | Decorative dot; `radio-indicator`       |

```tsx
<RadioGroup
  label="Plan"
  name="styled-plan"
  disabled
  error="Plans are temporarily locked."
  parts={{ options: { style: { display: 'flex', flexWrap: 'wrap', gap: '1rem' } } }}
>
  <Radio
    label="Pro"
    value="pro"
    parts={{ label: { style: { fontWeight: 700 } } }}
  />
</RadioGroup>
```

Parts accept className/style. Required means one selected option; group
required/disabled state is additive. Group errors style the disks and belong
to the fieldset, without assigning invalid/required ARIA to every option.
Keep input `appearance-none` and the dot decorative.

## Selection feedback

The copyable local `RadioFeedback` adapter uses public
[motion hooks](/docs/foundations/motion/) on the dot. Its `selected` prop drives decoration;
RadioGroup owns selection. Root input styles pass through. Custom indicator
class/style takes ownership and opts out of that feedback.

## Public props

`RadioGroupProps` and `RadioProps` are exported.

| RadioGroup prop          | Purpose / default                                                         |
| ------------------------ | ------------------------------------------------------------------------- |
| `name`, `label`          | Required shared native name and group legend                              |
| `value` / `defaultValue` | Controlled selection or initial browser-owned selection; string or `null` |
| `onValueChange`          | Receives the newly selected string                                        |
| `onChange`               | Native change observation                                                 |
| `description`, `error`   | Field help/error content and relationships                                |
| `required`, `disabled`   | Group state; defaults to `false`                                          |
| `requiredIndicator`      | Field's decorative indicator; defaults to `*`                             |
| `controlSize`            | Inherited by options; `small`, `medium` (default), `large`                |
| `parts`                  | Field parts plus `options` styling                                        |
| Other native props       | Fieldset attributes, events, `form`, root styling and ref                 |

| Radio prop                           | Purpose / default                                                             |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| `value`                              | Required option string                                                        |
| `label`                              | Convenience label; otherwise provide an accessible name                       |
| `disabled`, `required`               | Native option state; group state also applies                                 |
| `controlSize`                        | Option override; otherwise group size or `medium`                             |
| `checked` / `defaultChecked`, `name` | Standalone ownership; group owns these when nested                            |
| `parts`                              | Wrapper, label and indicator styling                                          |
| Other native props                   | Input attributes/events, styling and `HTMLInputElement` ref; type stays radio |
