## Usage

Use RadioGroup to choose one of a few visible options. It renders a [Field](/docs/field/) fieldset with the label as its legend; each Radio is a native input. Use [Select](/docs/select/) for long lists, [ToggleGroup](/docs/toggle-group/) for toolbar-style choices, [CheckboxGroup](/docs/checkbox-group/) for several values and [Switch](/docs/switch/) for one setting.

```tsx
<RadioGroup
  label="Delivery speed"
  name="delivery"
  defaultValue="standard"
>
  <Radio
    value="standard"
    label="Standard"
  />
  <Radio
    value="express"
    label="Express"
  />
</RadioGroup>
```

## State

Use `defaultValue` for browser-owned selection, or `value` with `onValueChange`, not both. `null` means nothing is selected, and `''` is a real option value. People cannot clear a group; set `value` to `null` to clear it.

The group's `onChange` receives the native change event from the radio that was selected. Write state from `onValueChange` or from `onChange`, not both.

`name` is optional. Without it, the group generates one, so arrow keys, `required` and submission still work. Pass `name` when a form reads the value; the generated key is unpredictable. One entry is submitted for the selected radio, and nothing when no radio is selected or the group is disabled.

Form reset returns an uncontrolled group to `defaultValue`. A controlled group keeps its value, so reset your state in the form's `onReset`.

Inside a group, Radio throws if given its own `name`, `checked` or `defaultChecked`. A standalone Radio takes `name`, `checked` or `defaultChecked`, and native `onChange`. Radio has no `readOnly`, because native radios ignore it. Use `disabled`, or a controlled group that ignores changes.

## Accessibility

`label` becomes the required `legend`. `description` and `error` are linked to the group. Every Radio needs a name: `label`, `aria-label` or `aria-labelledby`. `error` marks the group invalid.

| Key                      | Behavior                                                          |
| ------------------------ | ----------------------------------------------------------------- |
| Tab                      | Moves into the group, to the selected radio or else the first one |
| Tab / Shift+Tab in group | Moves out of the group                                            |
| Arrow Down / Arrow Right | Selects the next enabled radio, wrapping                          |
| Arrow Up / Arrow Left    | Selects the previous enabled radio, wrapping                      |
| Space                    | Selects the focused radio                                         |

## Motion

The dot changes instantly. The plan example springs it with the public `useSpring` hook in a local `RadioFeedback` adapter, which follows reduced motion and theme `motion.mode: 'off'`.

## Styling

The group's className, style, ref and native props reach the `fieldset` (`data-slot="field radio-group"`, `data-control-size`, `data-invalid`). `parts.options` styles the options grid (`radio-group-options`); set `display: flex` for a row. `parts.label`, `parts.description`, `parts.error` and `parts.required` style the Field parts.

A Radio's className, style, ref and native props reach the `input` (`data-slot="radio"`, `data-control-size`). `parts.wrapper` styles the label row (`radio-wrapper`), `parts.label` the text (`radio-label`) and `parts.indicator` the decorative dot (`radio-indicator`).

Theme the control with `--rad-radio-*` tokens, such as `--rad-radio-group-gap`, `--rad-radio-size` and `--rad-radio-mark`.

## API

### RadioGroup

| Prop              | Type                                             | Default   |
| ----------------- | ------------------------------------------------ | --------- |
| label             | ReactNode; the legend                            | Required  |
| name              | string; native name and form data key            | Generated |
| value             | string / null; controlled selection              | None      |
| defaultValue      | string / null; uncontrolled initial selection    | null      |
| onValueChange     | (value: string) => void                          | None      |
| onChange          | `(event: ChangeEvent<HTMLInputElement>) => void` | None      |
| description       | ReactNode; linked help text                      | None      |
| error             | ReactNode; marks the group invalid               | None      |
| required          | boolean; marks every radio required              | false     |
| requiredIndicator | ReactNode; replaces the required marker          | `*`       |
| disabled          | boolean; disables every radio                    | false     |
| form              | string; associates the fieldset with a form      | None      |
| controlSize       | small / medium / large; shared by every Radio    | medium    |
| parts             | label / description / error / required / options | None      |
| className / style | string / ThemeStyle                              | None      |
| ref               | `Ref<HTMLFieldSetElement>`                       | None      |
| Other props       | Native fieldset props                            | Native    |

### Radio

| Prop                     | Type                                                | Default              |
| ------------------------ | --------------------------------------------------- | -------------------- |
| value                    | string; submitted value, `''` allowed               | Required             |
| label                    | ReactNode; otherwise name the input with aria-label | None                 |
| checked / defaultChecked | boolean; standalone only                            | false                |
| onChange                 | `(event: ChangeEvent<HTMLInputElement>) => void`    | None                 |
| name                     | string; standalone only                             | None                 |
| disabled / required      | boolean                                             | false                |
| controlSize              | small / medium / large                              | Group's, else medium |
| parts                    | wrapper / label / indicator                         | None                 |
| className / style        | string / ThemeStyle                                 | None                 |
| ref                      | `Ref<HTMLInputElement>`                             | None                 |
| Other props              | Native input props except type and readOnly         | Native               |

Exports: `RadioGroup`, `Radio`, `RadioGroupProps`, `RadioProps`.
