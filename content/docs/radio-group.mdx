## Choose one value

RadioGroup composes [Field](/docs/field/) in group layout: a native `fieldset`
and `legend`, help/error text and Radio options. Each Radio is a native
`input type="radio"` with its own label. The group owns the shared `name` and
the selection.

Tab reaches the selected radio, or an enabled option when none is selected.
Arrow keys move and select within the group; Space selects a focused option.
Disabled options are skipped. This is native radio behavior, not a custom
roving tabindex. A disabled group removes its values from form
submission.

## Name and selection ownership

Supply a stable `name` on RadioGroup, for example from `useId()`, and a distinct
`value` on each Radio. Only the selected, enabled option contributes a value.

With `defaultValue`, native form reset restores the initial choice. Use `null`
to clear a controlled selection; `''` is a real option value, and `undefined`
changes ownership. Do not pass both `value` and `defaultValue`, or switch
ownership during a mount.

Write state from `onValueChange` or `onChange`, not both. Inside a group, do
not give Radio a conflicting `name`, `checked` or `defaultChecked`.

Controlled form reset must reset application values and validation metadata.
It does not erase the current controlled selection.

## Anatomy and parts

| Hook                    | Target / identity                                         |
| ----------------------- | --------------------------------------------------------- |
| RadioGroup root         | `fieldset`; `data-slot` includes `field radio-group`      |
| Group label/help/error  | Field's `parts.label`, `description`, `error`, `required` |
| `parts.options`         | Option container; `radio-group-options`                   |
| Radio root              | Native input; `data-slot="radio"`, `data-control-size`    |
| Radio `parts.wrapper`   | Outer label/span; `radio-wrapper`                         |
| Radio `parts.label`     | Convenience label text; `radio-label`                     |
| Radio `parts.indicator` | Decorative dot; `radio-indicator`                         |

Parts accept `className` and `style`. Group `className`, `style` and `ref` target
the fieldset; Radio's native props, styling and ref target its input. Keep an
accessible name on every option and visible focus.

Required means one selected option, not every option. A required group sets
native `required` on every radio; an option's `required={false}` cannot remove
it. An invalid group styles the radio disks. The group never adds
`aria-invalid` or `aria-required` to individual radios. The dot ignores pointer
events. Keep the input's `appearance-none` class; removing it brings back the
browser's own radio glyph.

## Public props

`RadioGroupProps` and `RadioProps` are exported.

| RadioGroup prop          | Purpose / default                                                         |
| ------------------------ | ------------------------------------------------------------------------- |
| `name`, `label`          | Required shared native name and group legend                              |
| `value` / `defaultValue` | Controlled selection or initial browser-owned selection; string or `null` |
| `onValueChange`          | Receives the newly selected string                                        |
| `onChange`               | Native change observation                                                 |
| `description`, `error`   | Field help/error content and relationships                                |
| `required`, `disabled`   | Group state; defaults to `false`                                          |
| `requiredIndicator`      | Field's decorative indicator; defaults to `*`                             |
| `controlSize`            | Inherited by options; `small`, `medium` (default), `large`                |
| `parts`                  | Field parts plus `options` styling                                        |
| Other native props       | Fieldset attributes, events, `form`, root styling and ref                 |

| Radio prop                           | Purpose / default                                                             |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| `value`                              | Required option string                                                        |
| `label`                              | Convenience label; otherwise provide an accessible name                       |
| `disabled`, `required`               | Native option state; group state also applies                                 |
| `controlSize`                        | Option override; otherwise group size or `medium`                             |
| `checked` / `defaultChecked`, `name` | Standalone ownership; group owns these when nested                            |
| `parts`                              | Wrapper, label and indicator styling                                          |
| Other native props                   | Input attributes/events, styling and `HTMLInputElement` ref; type stays radio |
