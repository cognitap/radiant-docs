## Usage

Give each `Radio` a distinct string `value`. Use [Select](/docs/select/) for a long list or [CheckboxGroup](/docs/checkbox-group/) for multiple choices.

## State

Use `defaultValue` for the initial choice or pass `value` with `onValueChange`. Set a controlled value to `null` to clear it.

Set `name` to use the selected value in form data. Form reset restores `defaultValue` for uncontrolled groups. Reset controlled values in the form’s `onReset`.

## Accessibility

Label the group and each option. Tab enters and leaves the group. Arrow keys select the next or previous enabled option, and Space selects the focused option.

Use `description` for help and `error` for a validation message. RadioGroup uses [Field](/docs/field/) for both.

## Styling

Use `parts.options` or `--rad-radio-group-gap` for option spacing. On a Radio, use `parts.indicator` or `--rad-radio-mark` to style the dot.

## API

| Prop          | Purpose                                                                   |
| ------------- | ------------------------------------------------------------------------- |
| `controlSize` | `small`, `medium` (default), or `large`. Radios inherit the group’s size. |
| `required`    | Requires one choice before submitting.                                    |
| `disabled`    | Disables the whole group or a single option.                              |
| `form`        | Associates the group with a form elsewhere on the page.                   |

`className`, `style`, and `ref` target the fieldset on RadioGroup and the native input on Radio.
