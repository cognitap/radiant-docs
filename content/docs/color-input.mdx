## Usage

Use ColorInput for a color in a form. Use [ColorPicker](/docs/color-picker/) for an always-visible editor.

```tsx
import { ColorInput, Field } from '@cognitap/radiant'

export function AccentField() {
  return (
    <Field label="Accent color">
      <ColorInput name="accent" />
    </Field>
  )
}
```

## State

Uncontrolled input starts empty unless `defaultValue` is provided. `onValueChange` receives typed text during edits and a canonical value after blur or a picker selection. `name` submits the normalized `format`, even when Enter submits before blur. Native reset restores the uncontrolled initial text.

## Accessibility

Name the textbox with Field or native ARIA. `pickerLabel` names the trigger and popup. Invalid text sets native custom validity.

| Key                          | Action                                                     |
| ---------------------------- | ---------------------------------------------------------- |
| Tab / Shift + Tab            | Move between the field, trigger, and open picker controls. |
| Enter / Space on the trigger | Open the picker.                                           |
| Arrow keys on a slider       | Adjust its color channel.                                  |
| Escape in the popup          | Close and return focus to the trigger.                     |

## Motion

The popup uses [Popover motion](/docs/popover/#motion) and follows reduced motion.

## Styling

`className` and `style` target the grouped boundary, and `ref` targets the textbox. Use `parts.input`, `parts.trigger`, and `parts.popup`.

## API

### ColorInput

| Prop                                       | Type and default                                |
| ------------------------------------------ | ----------------------------------------------- |
| `value` / `defaultValue`                   | Editable string. Uncontrolled starts empty.     |
| `onValueChange`                            | Receives edits and normalized text.             |
| `format`                                   | hex (default), rgb, or oklch.                   |
| `name` / `form`                            | Optional native submission name and form owner. |
| `required` / `disabled` / `readOnly`       | Native input flags, default to false.           |
| `pickerLabel`                              | Defaults to “Choose color”.                     |
| `invalidText`                              | Defaults to “Enter a hex, RGB, or OKLCH color.” |
| `swatches` / `eyedropper` / `pickerLabels` | Optional ColorPicker options.                   |
| `controlSize`                              | small, medium (default), or large.              |
| `parts`                                    | input, trigger, and popup.                      |
| `className` / `style` / `ref`              | Group styles and textbox ref.                   |

Exports ColorInput and ColorInputProps.
