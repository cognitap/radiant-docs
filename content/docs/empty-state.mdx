## Usage

Use EmptyState where content would be: before the first record exists, when a search matches nothing, or when loading failed. Use [Skeleton](/docs/skeleton/) or [Spinner](/docs/spinner/) while content loads, [Alert](/docs/alert/) for a message beside content that is present, and [Toast](/docs/toast/) to confirm something the user just did.

```tsx
<EmptyState>
  <EmptyStateIcon>
    <FolderIcon />
  </EmptyStateIcon>
  <EmptyStateTitle level={3}>No projects yet</EmptyStateTitle>
  <EmptyStateDescription>
    Create a study project to organize participants and reports.
  </EmptyStateDescription>
  <EmptyStateActions>
    <Button onClick={create}>Create study project</Button>
  </EmptyStateActions>
</EmptyState>
```

`variant` sets the treatment: `first-use` (default) draws a dashed border, `no-results` drops the border and background, and `error` draws a solid border. `tone` only sets the border and icon color: `neutral` (default), `accent`, `warning` or `danger`. Say what happened in the text; color only reinforces it.

## State

EmptyState holds no state and contributes no form value. Your application decides when it shows and what each action does. When an action removes the placeholder, as creating the first project does in the demo above, move focus to the new content yourself.

## Accessibility

EmptyStateTitle renders a heading, `h2` by default; choose `level` to fit the page outline. EmptyStateIcon is always `aria-hidden`, and its types reject a role, name or tab stop. Use [Button](/docs/button/) for actions and [Link](/docs/link/) for navigation.

The root has no role and announces nothing. Combobox and Command already announce their empty and error content, so add no second live region inside them. Elsewhere, put the announcement in a status you own.

| Key             | Behavior                          |
| --------------- | --------------------------------- |
| Tab / Shift+Tab | Move through the actions in order |
| Enter / Space   | Activate the focused action       |

## Motion

EmptyState has no transitions or enter and exit animation. Buttons inside keep their own motion and reduced-motion behavior.

## Styling

| Part                  | Element              | data-slot                 | Data attributes             |
| --------------------- | -------------------- | ------------------------- | --------------------------- |
| EmptyState            | `div`, centered grid | `empty-state`             | `data-variant`, `data-tone` |
| EmptyStateIcon        | `span`               | `empty-state-icon`        | None                        |
| EmptyStateTitle       | `h1`–`h6` by `level` | `empty-state-title`       | None                        |
| EmptyStateDescription | `p`                  | `empty-state-description` | None                        |
| EmptyStateActions     | `div`, wrapping row  | `empty-state-actions`     | None                        |

Each part takes `className`, `style`, an additive `data-slot` and a native ref. An SVG inside EmptyStateIcon fills the icon box. `components.emptyState` or `--rad-empty-state-*` variables set padding, gap, radius, borderWidth, borderColor, background, color, iconSize, iconColor, titleSize, titleWeight, descriptionSize, descriptionColor and actionsGap. Forced colors use system text and canvas colors.

## API

Every part takes the native props of its element, `style` as ThemeStyle and `data-slot`.

| EmptyState prop | Type                                | Default   |
| --------------- | ----------------------------------- | --------- |
| variant         | first-use / no-results / error      | first-use |
| tone            | neutral / accent / warning / danger | neutral   |

| EmptyStateIcon prop | Type                                                                             | Default |
| ------------------- | -------------------------------------------------------------------------------- | ------- |
| Native span props   | Except aria-hidden, aria-label, aria-labelledby, role, tabIndex, contentEditable | None    |

| EmptyStateTitle prop | Type                  | Default |
| -------------------- | --------------------- | ------- |
| level                | 1 / 2 / 3 / 4 / 5 / 6 | 2       |

EmptyStateDescription takes native `<p>` props. EmptyStateActions takes native `<div>` props.

Exports: `EmptyState`, `EmptyStateIcon`, `EmptyStateTitle`, `EmptyStateDescription`, `EmptyStateActions`; types `EmptyStateProps`, `EmptyStateIconProps`, `EmptyStateTitleProps`, `EmptyStateDescriptionProps`, `EmptyStateActionsProps`, `EmptyStateVariant`, `EmptyStateTone`, `EmptyStateHeadingLevel`.
