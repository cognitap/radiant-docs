## One control, connected text

Field connects a label, optional description and optional error to one
control. The label targets the control's ID. Description and error IDs are joined in the
control's `aria-describedby`; an error also marks it invalid.

Field does not validate, track touched state or save data. You choose when to
pass `error` and where to focus after a failed submission. Required
adds the relationship and indicator; a disabled control is unavailable and
omitted from native form data. Use `noValidate` on the form to show your own
feedback instead of the browser's validation popup.

## Adapt a native control

For an ordinary HTML input, pass a children callback. It receives
`FieldControlProps`: `id`, `required`, `disabled`, `aria-invalid`,
`aria-required` and `aria-describedby`. Forward all of them to the input. If
the adapter sets its own `aria-describedby`, keep the callback's IDs too.
Radiant controls append external IDs once, without duplicates.

Radiant [Input](/docs/input/), [Checkbox](/docs/checkbox/) and Radio consume
Field relationships automatically. The Field's own `id` and `ref` target the
wrapper; put a control ref on the input.

## Group related controls

`layout="group"` renders a native `fieldset` with a `legend`, description and
error. It has no single label target, so it does not accept `controlId` or a
children callback. Give each child its own accessible label, as in
[mixed checkbox selection](/docs/checkbox/#mixed-selection). For one choice,
use [RadioGroup](/docs/radio-group/).

A required group does not make every checkbox required. Your form implements
rules such as “choose at least one”. A disabled group uses native fieldset
disabling and inherited Field state.

## Anatomy and parts

| Part                | Native target / identity                          |
| ------------------- | ------------------------------------------------- |
| Root                | `div` or `fieldset`; `data-slot` includes `field` |
| `parts.label`       | `label` or `legend`; `field-label`                |
| `parts.description` | Help `div`; `field-description`                   |
| `parts.error`       | Error `div` with `role="alert"`; `field-error`    |
| `parts.required`    | Decorative required indicator; `field-required`   |

Each part accepts `className` and `style`, not arbitrary DOM props. Root
`data-layout` identifies the layout; `data-required`, `data-disabled` and
`data-invalid` are presence-based state attributes.

## Public props

`FieldProps`, `FieldControlProps`, `FieldState` and `FieldLayout` are exported.

| Prop                        | Purpose / default                                                                      |
| --------------------------- | -------------------------------------------------------------------------------------- |
| `label`                     | Required accessible label or group legend                                              |
| `layout`                    | `control` (default) or `group`                                                         |
| `controlId`                 | Explicit input ID in control layout; otherwise generated                               |
| `description`, `error`      | Optional help and validation content; a nonempty error marks invalid                   |
| `required`, `disabled`      | Boolean state; both default to `false`                                                 |
| `requiredIndicator`         | Decorative content; defaults to `*`                                                    |
| `children`                  | Content; control layout also accepts `(control: FieldControlProps) => ReactNode`       |
| `parts`                     | Label, description, error and required-indicator styling                               |
| `className`, `style`, `ref` | Root customization and ref to `div` / `fieldset`                                       |
| Other native props          | Attributes and events for the selected root; group also accepts native `form` / `name` |

`useField()` returns the nearest Field state, or `null` outside a Field. In
group layout its `controlProps` is `null`.
