## Usage

Wrap an [Input](/docs/input/) or another Radiant control in Field to connect its label, help and errors.

```tsx
<Field
  label="Email"
  error={error}
  required
>
  <Input
    name="email"
    type="email"
  />
</Field>
```

## Examples

### Native input

Pass a function child and spread its props on the native input.

```tsx
<Field
  label="Address"
  error={error}
>
  {control => (
    <input
      {...control}
      name="address"
    />
  )}
</Field>
```

### Group

`layout="group"` gives related choices a shared legend. Label each option. Use [Fieldset](/docs/fieldset/) to group independently labeled fields.

```tsx
<Field
  layout="group"
  label="Channels"
>
  <Checkbox label="Email" />
  <Checkbox label="SMS" />
</Field>
```

## State

Set `error` when validation fails. Clear it when the value passes. Group `required` marks the legend. The form checks which options are selected.

## Accessibility

Field links help and errors with `aria-describedby` and announces inline errors as alerts. For an error rendered elsewhere, set `aria-invalid` and pass the message ID in `aria-describedby`. Group help and caller IDs stay on the fieldset.

## Motion

Errors appear immediately. The demo uses [layout motion](/docs/foundations/motion/#animate-layout) to move the surrounding fields.

## Styling

Use `parts` to style the label, description, error or required indicator. The control draws the [focus outline](/docs/foundations/theming/#focus-outlines).

## API

| Prop                        | Purpose                                                                |
| --------------------------- | ---------------------------------------------------------------------- |
| `label`                     | Required label or legend                                               |
| `layout`                    | `'control'` (default) or `'group'`                                     |
| `description`, `error`      | Help text and validation message                                       |
| `required`, `disabled`      | Both default to `false`                                                |
| `requiredIndicator`         | Defaults to `'*'`. Pass `null` to hide it                              |
| `controlId`                 | Input ID in control layout. Generated by default                       |
| `children`                  | Controls or a function receiving `FieldControlProps` in control layout |
| `parts`                     | Part style overrides                                                   |
| `className`, `style`, `ref` | Target the root `div` or `fieldset`                                    |
