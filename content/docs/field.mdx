## Usage

Field has two layouts. The default control layout wraps one control in a `div` and points a `label` at it. Radiant controls such as [Input](/docs/input/) connect automatically.

```tsx
<Field
  label="Email"
  description="Your work address"
  error={error}
  required
>
  <Input
    name="email"
    type="email"
  />
</Field>
```

The group layout wraps several controls in a native `fieldset` and names it with a `legend`. Each child keeps its own label.

```tsx
<Field
  layout="group"
  label="Channels"
  error={channelError}
  required
>
  <Checkbox
    label="Email"
    name="channels"
    value="email"
  />
  <Checkbox
    label="Team feed"
    name="channels"
    value="feed"
  />
</Field>
```

For a native control, pass a function child and spread every prop it receives. A plain element child stays unlabelled.

```tsx
<Field
  label="Address"
  error={error}
>
  {control => (
    <input
      {...control}
      name="address"
    />
  )}
</Field>
```

Use [Fieldset](/docs/fieldset/) for a bare form section, [RadioGroup](/docs/radio-group/) for one choice among options, and `aria-label` on the control when there is no visible label.

## State

Field holds no value. You own values, validation, focus and the error text. An `error` with content marks the Field invalid; `''`, `null` or `false` clears it.

When the message lives elsewhere, such as an error summary, set `aria-invalid` and `aria-describedby` on Field. In control layout both reach the labelled control, after Field's own description and error IDs. Group layout keeps them on the `fieldset`.

A child cannot undo its Field's `required` or `disabled`. Field submits nothing. Control layout rejects `name` and `form`; in group layout they are native fieldset attributes. A required group does not require every checkbox.

`useField()` returns the nearest `FieldState`, or `null` outside Field. Its `controlProps` is `null` in group layout.

## Accessibility

In control layout the `label` names the control, whose `aria-describedby` lists the description, then the error. In group layout the `legend` names the `fieldset`, which carries those descriptions and `aria-invalid`. The error has `role="alert"`. The required indicator is `aria-hidden`; `required` and `aria-required` carry the state.

| Key         | Behavior                                        |
| ----------- | ----------------------------------------------- |
| Click label | Focuses or toggles the control (native `label`) |
| Any other   | Handled by the control; Field adds no keys      |

## Motion

Field does not animate; errors appear immediately. To move surrounding layout, wrap the Field in an element animated with `useSpringLayout`, as the first example does. It follows the theme's `motion.mode` and reduced motion. See [layout motion](/docs/foundations/motion/#animate-layout).

## Styling

Root `className`, `style`, native props and `ref` reach the `div` or `fieldset`. Disabled dims all but the description and error.

| Part          | Element              | `data-slot`         |
| ------------- | -------------------- | ------------------- |
| Root          | `div` / `fieldset`   | `field`             |
| `label`       | `label` / `legend`   | `field-label`       |
| `description` | `div`                | `field-description` |
| `error`       | `div role="alert"`   | `field-error`       |
| `required`    | `span` (aria-hidden) | `field-required`    |

The root carries `data-layout="control|group"` and the presence attributes `data-invalid`, `data-disabled` and `data-required`. A caller `data-slot` is appended to `field`. Theme variables: `--rad-field-gap`, `--rad-field-label-color|size|weight`, `--rad-field-description-color|size`, `--rad-field-error-color|size`, `--rad-field-required-color` and `--rad-field-disabled-opacity`.

## API

### Field

| Prop                | Type / default                                                              |
| ------------------- | --------------------------------------------------------------------------- |
| label               | Required ReactNode; control label or group legend                           |
| layout              | `'control' \| 'group'`; `'control'`                                         |
| description / error | ReactNode; error content marks the Field invalid                            |
| required / disabled | boolean; false                                                              |
| requiredIndicator   | ReactNode; `'*'`; `null` hides it                                           |
| controlId           | string; generated; control layout only                                      |
| children            | ReactNode, or `(control: FieldControlProps) => ReactNode` in control layout |
| parts               | label / description / error / required `PartStyle`                          |
| aria-invalid        | Forwarded to the control in control layout                                  |
| aria-describedby    | Appended to the control's descriptions in control layout                    |
| className / style   | string / ThemeStyle; root                                                   |
| ref                 | HTMLDivElement, or HTMLFieldSetElement in group layout                      |

`FieldControlProps` holds `id`, `required`, `disabled`, `aria-invalid`, `aria-required` and `aria-describedby`. Exports `Field`, `useField`, `FieldProps`, `FieldControlProps`, `FieldState` and `FieldLayout`.
