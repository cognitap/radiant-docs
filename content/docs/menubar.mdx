## Usage

Use Menubar for an application's persistent command menus. Use [Menu](/docs/menu/) for a single command list, NavigationMenu for site navigation, or [Toolbar](/docs/toolbar/) for a row of tool buttons and toggles.

```tsx
<Menubar aria-label="Document commands">
  <MenubarMenu value="file">
    <MenubarTrigger>File</MenubarTrigger>
    <MenubarPortal>
      <MenubarContent>
        <MenubarItem onSelect={save}>Save</MenubarItem>
      </MenubarContent>
    </MenubarPortal>
  </MenubarMenu>
</Menubar>
```

## State

The bar owns which menu is open. Its `value` is the open MenubarMenu's `value`, or `null` when every menu is closed. Menubar takes `value` or `defaultValue` with `onValueChange`. Pick one owner per mount; switching throws. A controlled owner may refuse a request. Give each MenubarMenu a distinct `value`.

`useMenubar()` returns `{ value, controlled, loop, setValue }`, or `null` outside a Menubar.

Items are commands, not toggles: MenubarItem takes no `pressed` props. For a command that turns something on or off, use MenubarCheckboxItem. Checkbox items, radio groups, submenus and native form submission work as in [Menu](/docs/menu/#state).

## Accessibility

The bar is a `div` with `role="menubar"`; name it with `aria-label` or `aria-labelledby`. Titles are menu items with `aria-haspopup="menu"` and `aria-expanded`. Disabled and pending titles stay focusable but don't open.

| Key                           | Behavior                                                              |
| ----------------------------- | --------------------------------------------------------------------- |
| Tab / Shift+Tab               | Enter the bar once; leave and close any open menu                     |
| Arrow Left / Right on a title | Move between titles, wrapping when `loop`; reversed in RTL            |
| Home / End on a title         | Move to the first or last title                                       |
| Enter / Space / Arrow Down    | Open the title's menu at its first item                               |
| Arrow Up on a title           | Open the title's menu at its last item                                |
| Arrow Left / Right on an item | Switch to the previous or next menu; forward on a SubTrigger opens it |
| Other keys inside a menu      | [Menu keyboard](/docs/menu/#accessibility): arrows, typeahead, Escape |

Clicking a title toggles its menu. While a menu is open, hovering another title switches to it.

## Motion

Inside [MotionProvider](/docs/foundations/motion/), titles keep Button press feedback and the content fades and scales in. Set `motion="off"` on MenubarContent or MenubarSubContent to turn it off for that surface. Reduced motion is honored.

## Styling

Props, refs, classes and styles reach each part's native element. Every part adds a `menubar-*` slot to its `menu-*` slot, such as `menubar-trigger` and `menubar-item`. The bar exposes `data-state="open"` or `"closed"`; each title exposes `data-value`.

Use `components.menubar` or `--rad-menubar-gap`, `--rad-menubar-padding`, `--rad-menubar-radius` and `--rad-menubar-background` for the bar. Popups and items follow [Menu](/docs/menu/#styling).

## API

### Menubar

| Prop                         | Type                                                 | Default  |
| ---------------------------- | ---------------------------------------------------- | -------- |
| aria-label / aria-labelledby | string; one is required                              | Required |
| value                        | string / null; controlled                            | None     |
| defaultValue                 | string / null                                        | null     |
| onValueChange                | `(value: string \| null) => void`                    | None     |
| loop                         | boolean; arrow keys wrap between titles              | true     |
| style                        | ThemeStyle                                           | None     |
| ref                          | `Ref<HTMLDivElement>`                                | None     |
| Other props                  | div props except role, aria-orientation and tabIndex | Native   |

### MenubarMenu

| Prop     | Type                      | Default  |
| -------- | ------------------------- | -------- |
| value    | string; unique in the bar | Required |
| children | ReactNode                 | None     |

### MenubarTrigger

| Prop        | Type                                                      | Default |
| ----------- | --------------------------------------------------------- | ------- |
| variant     | solid / soft / outline / ghost                            | ghost   |
| tone        | accent / neutral / warning / danger                       | neutral |
| disabled    | boolean                                                   | false   |
| pending     | boolean                                                   | false   |
| ref         | `Ref<HTMLButtonElement>`                                  | None    |
| Other props | MenuTrigger props except role, tabIndex and aria-disabled | Native  |

### MenubarPortal

| Prop     | Type      | Default |
| -------- | --------- | ------- |
| children | ReactNode | None    |

### MenubarContent

| Prop             | Type                         | Default |
| ---------------- | ---------------------------- | ------- |
| side             | top / right / bottom / left  | bottom  |
| align            | start / center / end         | start   |
| sideOffset       | number                       | 8       |
| collisionPadding | number                       | 8       |
| motion           | inherit / off                | inherit |
| Other props      | MenuContent props; `div` ref | Native  |

### Items, groups and submenus

These parts take the same props and defaults as their [Menu parts](/docs/menu/#api).

| Part                | Same as                                          | Key defaults                        |
| ------------------- | ------------------------------------------------ | ----------------------------------- |
| MenubarItem         | [MenuItem](/docs/menu/#menuitem)                 | closeOnSelect true; no toggle props |
| MenubarCheckboxItem | [MenuCheckboxItem](/docs/menu/#menucheckboxitem) | checked false; closeOnSelect false  |
| MenubarRadioGroup   | [MenuRadioGroup](/docs/menu/#menuradiogroup)     | value null                          |
| MenubarRadioItem    | [MenuRadioItem](/docs/menu/#menuradioitem)       | value required; closeOnSelect false |
| MenubarGroup        | [MenuGroup](/docs/menu/#menugroup)               | Native                              |
| MenubarLabel        | [MenuLabel](/docs/menu/#menulabel)               | Native                              |
| MenubarSeparator    | [MenuSeparator](/docs/menu/#menuseparator)       | Separator defaults                  |
| MenubarSub          | [MenuSub](/docs/menu/#menusub)                   | defaultOpen false                   |
| MenubarSubTrigger   | [MenuSubTrigger](/docs/menu/#menusubtrigger)     | No close on activation              |
| MenubarSubContent   | [MenuSubContent](/docs/menu/#menusubcontent)     | Inline end; sideOffset 4            |

Exports each part's `Menubar…Props` type, plus `MenubarState` and `MenubarRenderProps` for `render` adapters on items.
