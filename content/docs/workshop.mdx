**[Open the theme workshop](/workshop/)**

## Where you start

The workshop opens on a start screen. Pick a ready-made theme from the gallery,
enter your brand color, or open a shared link or configuration file. That theme
becomes the one you started with: every changed marker and reset counts from
it, and undo history begins there. New theme returns to the start screen and
asks first when edits would be lost.

## What it makes

The workshop edits one Radiant theme. Color, Typography, Spacing & surfaces and
Motion each own a section of that document. The preview shows one scene at a
time: a page, the components, or a motion example. It sits beside the controls,
or on a narrow screen stays pinned above them, where Expand shows it full size
and Preview options holds the scene, mode and width. Inspect
shows which theme values style anything you click in the preview and jumps to
their controls. Mode, width, comparison and scene data never become theme
settings. Editing stays in your browser.

Every control that differs from the theme you started with shows a dot and a
Reset button, and each editor tab counts them. Undo and Redo, or Cmd/Ctrl+Z and
Shift+Cmd/Ctrl+Z, step through every theme change, imports included. Each
section reset puts that editor back and is itself undoable. Reset scene
restores one preview scene.

## Take your theme

Copy typed theme produces a portable document and compiled theme for
ThemeScope. Download configuration includes supported editor recipes. Selective
exports transfer only chosen sections. Merge keeps omitted values, while Replace
removes omitted values within the supplied sections.

Selective TypeScript applies Typography or Motion to an existing document.
Compile the returned document for ThemeScope. Runtime setup supplies exact
dependency versions and MotionProvider. System reduced motion stays live instead
of being saved into the theme.

Typography CSS uses `radiant-typography` with a light/dark/system mode attribute;
load it after Radiant’s compiled styles. Full scoped CSS emits timing tokens but
omits spring profiles, so use the typed route when motion needs interruption.
Local font files are never uploaded or exported. Applications supply the files.

Share links store compressed configuration in the URL fragment without a server
account. A configuration file handles themes too large for a link.

See [motion setup and ownership](/docs/foundations/motion/) for production usage.
The header identifies the installed package. JavaScript and CSS must use matching
versions.
