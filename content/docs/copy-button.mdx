## Usage

Keep the text visible so people can copy it manually. Use [CodeBlock](/docs/code-block/) to show and copy a code sample.

## State

The button keeps focus during the write. On success, it shows a checkmark and the confirmation until `resetDelay`. An error appears below the button until retry or a value change.

## Accessibility

Name icon-only buttons with `aria-label` or `aria-labelledby`. A live region announces the result.

## Styling

Set `copy` and `check` in [IconProvider](/docs/icon-provider/) to use your app’s icons. CopyButton uses [Button motion](/docs/button/#motion).

## API

| Prop           | Type and default                                                 |
| -------------- | ---------------------------------------------------------------- |
| `value`        | String to copy                                                   |
| `children`     | Button label, defaults to Copy                                   |
| `resetDelay`   | Positive milliseconds, defaults to 2000                          |
| `copiedText`   | Success label, defaults to “Copied”                              |
| `errorText`    | Message when copying fails                                       |
| `parts.status` | `PartStyle` for the status region                                |
| Button props   | See [Button](/docs/button/) for appearance and native attributes |

Exports `CopyButton`, `CopyButtonProps`, and `CopyButtonRenderProps`.
