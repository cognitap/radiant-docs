## Usage

MultiSelect is the convenience export for [Combobox in multiple mode](/docs/combobox/#state). Use the [selection controls recipe](/docs/recipes/selection-controls/) to compare an always-visible list, searchable options, and free entry.

```tsx
import { Field, MultiSelect } from '@cognitap/radiant'

export function Reviewers() {
  return (
    <Field label="Reviewers">
      <MultiSelect
        name="reviewers"
        items={[
          { value: 'ana', label: 'Ana Petrescu' },
          { value: 'sam', label: 'Sam Novak' }
        ]}
        defaultValue={['ana']}
      />
    </Field>
  )
}
```

## API

MultiSelect accepts the [Combobox multiple-mode props](/docs/combobox/#api) with the mode fixed. Its public parts and `multi-select-*` slots remain available. Use the Combobox guide for [form behavior](/docs/combobox/#state), [keyboard behavior](/docs/combobox/#accessibility), and [part styling](/docs/combobox/#styling).
