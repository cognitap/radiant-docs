## Usage

Use MultiSelect to search a known list and keep several keys. It composes [Combobox](/docs/combobox/) with `type="multiple"` and gives the parts their own names. Choose something else when:

- [Combobox](/docs/combobox/) or [Select](/docs/select/): people choose one value.
- [TagsInput](/docs/tags-input/): people type values that aren't in a list.
- [CheckboxGroup](/docs/checkbox-group/): a few options should stay visible.

```tsx
<Field label="Reviewers">
  <MultiSelect
    items={people}
    name="reviewers"
    defaultValue={['ana']}
  />
</Field>
```

Without children, MultiSelect renders the tags, the input with a trigger, and an item for every entry in `items`.

## State

Use `defaultValue`, or `value` with `onValueChange`, not both; mixing them throws. Values are distinct strings, and `[]` is empty. `query` and `open` follow the same rule with their own callbacks.

Choosing an item toggles it, clears the search and keeps the popup open. For server results, pass `filter={null}` and set `loading` or `errorText` yourself. `selectedItems` labels selected keys missing from the current `items`.

Each selected key submits under `name`; read them with `FormData.getAll`. Search text never submits. `required` needs at least one selection. Form reset restores an uncontrolled selection without calling `onValueChange`; reset controlled state in `onReset`. `disabled` leaves the values out of form data. `readOnly` blocks edits but keeps them submitted. Pass `aria-invalid` to MultiSelect to mark it invalid outside [Field](/docs/field/).

## Accessibility

Focus stays on the `combobox` input; the popup is a `listbox` with `aria-multiselectable`, and each option's `aria-selected` shows membership. Loading, empty and error text is a polite `status`. Name the input with Field or `aria-label` on MultiSelectInput. Each tag's remove button is named "Remove" plus the item text.

| Key                         | Behavior                                      |
| --------------------------- | --------------------------------------------- |
| Typing                      | Filter and open; never selects                |
| Arrow Down / Up             | Open and highlight enabled items              |
| Alt+Arrow Down / Up         | Open or close without moving the highlight    |
| Enter                       | Toggle the highlighted item; stay open        |
| Backspace with empty search | Remove the last selection                     |
| Escape                      | Close and discard the search; keep selections |
| Tab                         | Close; tag remove buttons and Clear are stops |

## Motion

Inside [MotionProvider](/docs/foundations/motion/), the popup fades in; closing is immediate. Set `motion="off"` on MultiSelectContent to turn it off. Reduced motion shows it at full opacity.

## Styling

MultiSelect and MultiSelectPortal render no element. Other parts take `className`, `style` and `ref`, and keep their `combobox-*` slot alongside the `multi-select-*` one.

| Part               | Attributes                                                                                          |
| ------------------ | --------------------------------------------------------------------------------------------------- |
| MultiSelectTags    | `data-slot="combobox-tags multi-select-tags"`; each tag is `multi-select-tag`                       |
| MultiSelectInput   | `multi-select-input`, `data-control-size`, `data-invalid`; wrapper `multi-select-control`           |
| MultiSelectTrigger | `data-slot="button combobox-trigger multi-select-trigger"`                                          |
| MultiSelectClear   | `data-slot="button combobox-clear multi-select-clear"`                                              |
| MultiSelectContent | `multi-select-content`, `data-state="open \| closed"`, `data-motion`; `multi-select-listbox` inside |
| MultiSelectItem    | `multi-select-item`, `data-value`, `data-highlighted`, `data-selected`, `data-disabled`             |
| MultiSelectStatus  | `multi-select-status`                                                                               |

Hidden form inputs are `multi-select-native` and `multi-select-value`. `--rad-multi-select-gap` spaces the tags; everything else uses the `--rad-combobox-*` tokens.

## API

### MultiSelect

| Prop                 | Type                                          | Default                       |
| -------------------- | --------------------------------------------- | ----------------------------- |
| items                | `readonly MultiSelectOption[]`; unique values | Required                      |
| value / defaultValue | `string[]`                                    | None / `[]`                   |
| onValueChange        | `(value: string[]) => void`                   | None                          |
| selectedItems        | `readonly MultiSelectOption[]`                | None                          |
| query / defaultQuery | string                                        | None / `''`                   |
| onQueryChange        | `(query: string) => void`                     | None                          |
| open / defaultOpen   | boolean                                       | None / false                  |
| onOpenChange         | `(open: boolean) => void`                     | None                          |
| filter               | `((item, query) => boolean) \| null`          | Case-insensitive text match   |
| loading              | boolean; hides results                        | false                         |
| loadingText          | string                                        | `'Loading results…'`          |
| emptyText            | ReactNode                                     | `'No results found.'`         |
| errorText            | ReactNode; hides results                      | None                          |
| name / form          | string                                        | None                          |
| disabled / required  | boolean                                       | Field's, else false           |
| readOnly             | boolean                                       | false                         |
| aria-invalid         | Native; forwarded to the input                | Field's                       |
| controlSize          | small / medium / large                        | medium                        |
| children             | ReactNode                                     | Tags, input, trigger, content |

MultiSelect takes neither `type` nor `multiple`.

### MultiSelectTags

| Prop        | Type                  | Default     |
| ----------- | --------------------- | ----------- |

| Other props | div props except role | Native      |

`useMultiSelect()` returns `{ value, query, open, disabled, setValue, setQuery, setOpen }` inside MultiSelect or a `type="multiple"` Combobox, else `null`.

Exports `MultiSelectProps`, `MultiSelectOption`, `MultiSelectState`, `MultiSelectRenderProps`, `MultiSelectTagsProps`, `MultiSelectInputProps`, `MultiSelectTriggerProps`, `MultiSelectClearProps`, `MultiSelectPortalProps`, `MultiSelectContentProps`, `MultiSelectItemProps` and `MultiSelectStatusProps`.
