## Usage

Put one `InputGroupInput` or `InputGroupTextarea` directly inside `InputGroup`. Use `InputGroupAddon` before or after the control. Wrap the group in [Field](/docs/field/) for a label and errors.

## State

The grouped control takes the same value and form props as [Input](/docs/input/) or [Textarea](/docs/textarea/).

## Accessibility

Clicking a passive addon focuses the field. Label each action and set its disabled state separately. Hide decorative addons with `aria-hidden`.

## Styling

The [focus outline](/docs/foundations/theming/#focus-outlines) wraps the group. Use `--rad-input-group-radius` to change the corners.

## API

`controlSize` sets the default size for the input or textarea. Put `className`, `style` and `ref` on the part you want to target.
