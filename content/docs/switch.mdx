## Usage

Use Switch for a setting that applies immediately. Use [Checkbox](/docs/checkbox/) for a checklist or consent.

## State

Use `defaultChecked` for the initial and reset state, or pass `checked` with `onChange`. Read `event.currentTarget.checked` for the new state.

An enabled switch that is on submits its `name` and `value`. The default value is `"on"`.

## Accessibility

Give the switch a `label` or use [Field](/docs/field/) for a label, help and errors. Use `aria-label` or `aria-labelledby` when the label lives elsewhere.

Tab focuses the switch and Space toggles it. Drag the thumb past the midpoint to toggle, or press Escape to cancel the drag. Mouse drags can continue outside the track. In right-to-left layouts, on is on the left.

## Styling

Use `parts.indicator` to style the thumb and `parts.wrapper` or `parts.label` to style the row or label. See [theming](/docs/foundations/theming/) for switch tokens.

## API

| Prop                        | Purpose                                              |
| --------------------------- | ---------------------------------------------------- |
| `controlSize`               | `small`, `medium` (default), or `large`.             |
| `disabled`                  | Skips focus and form submission.                     |
| `required`                  | Requires the switch to be on before form submission. |
| `className`, `style`, `ref` | Target the native input that draws the track.        |
