## Usage

Use Toolbar for commands that belong together. Add [Buttons](/docs/button/), [Links](/docs/link/), or a [ToggleGroup](/docs/toggle-group/). Use a decorative [Separator](/docs/separator/) between sets of actions.

## Accessibility

Name the toolbar with `aria-label` or `aria-labelledby`. Tab enters once. Left and Right move focus in a horizontal toolbar. Up and Down move focus in a vertical one. Home and End focus the first or last enabled action. Navigation skips disabled and hidden actions. Enter or Space activates the focused button.

A ToggleGroup inside the toolbar shares its keyboard navigation. Open [menus](/docs/menu/) and [dialogs](/docs/dialog/) handle their own keys.

## Styling

Set `components.toolbar` in your [theme](/docs/foundations/theming/) to adjust its gap, padding, corner radius, or background.

## API

| Prop                             | Default      | Use                                   |
| -------------------------------- | ------------ | ------------------------------------- |
| `aria-label` / `aria-labelledby` | Required     | Give the toolbar an accessible name.  |
| `orientation`                    | `horizontal` | Set to `vertical` for a column.       |
| `loop`                           | `true`       | Set to `false` to stop at either end. |

`className`, `style`, and `ref` target the root div.
