## Connect related panels

Give each trigger and its content the same distinct string `value` within one
Tabs owner. Label the tab list; Tabs supplies the tab/panel IDs and ARIA
relationships. Set an initial selection with `defaultValue` or `value`.

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from '@cognitap/radiant'

export function ProjectSections() {
  return (
    <Tabs defaultValue="overview">
      <TabsList aria-label="Project sections">
        <TabsTrigger value="overview">Overview</TabsTrigger>
        <TabsTrigger value="activity">Activity</TabsTrigger>
      </TabsList>
      <TabsContent value="overview">Project details</TabsContent>
      <TabsContent value="activity">Recent changes</TabsContent>
    </Tabs>
  )
}
```

## Choose activation and ownership

Automatic activation is the default: focusing a tab selects its panel. Use
`activationMode="manual"` for panels that load on demand; arrows move focus,
then click, Enter or Space selects.

For controlled selection, pass a string `value` and `onValueChange`:

```tsx
const [section, setSection] = useState('overview')

<Tabs value={section} onValueChange={setSection}>
  {/* list, triggers and matching content */}
</Tabs>
```

Keep one owner for the entire mount. Do not combine `value` and `defaultValue`
or switch ownership. Keep the selected value matched to an available tab.
`useTabs()` returns the current state and `setValue` request, or `null` outside
Tabs. A controlled owner can refuse requests.

## Navigate

Tab enters the selected tab and leaves the list for panel content. Arrows move
through enabled, visible tabs in DOM order; Home/End move to the ends. Horizontal
navigation follows RTL direction and leaves Up/Down available for scrolling.
`orientation="vertical"` uses Up/Down. Set `loop={false}` to stop at the ends.

Disable individual triggers or the whole Tabs owner. Panels default to
`tabIndex={0}`; choose `-1` when Tab should go directly to a focusable child.

## Keep panel state

Inactive panel hosts remain hidden and inert. Their children unmount by default.
Set `keepMounted` on a TabsContent to preserve its local state.

Mounted hidden form controls still submit and validate; the application owns
validation across panels. Tab selection is not form data. Native form reset
restores controls without changing the selected tab.

## Customize

`controlSize` selects shared `small`, `medium` or `large` metrics. Use independent
`components.tabs` overrides or typed local variables:

```tsx
<Tabs
  defaultValue="overview"
  style={{
    '--rad-tabs-list-radius': '999px',
    '--rad-tabs-trigger-radius': '999px',
    '--rad-tabs-content-padding': '1.5rem'
  }}
>
  {/* list, triggers and content */}
</Tabs>
```

Root/list/content props and refs reach their `div`; trigger props/ref reach a
native button. Trigger `render` follows the [Button contract](/docs/button/).
Keep selected, focus and disabled cues visible. See
[theming](/docs/foundations/theming/).
