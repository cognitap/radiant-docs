## Usage

Give each TabsTrigger and its TabsContent the same string `value`, and name the list. Use [Accordion](/docs/accordion/) for sections people read in sequence or open together, [ToggleGroup](/docs/toggle-group/) or [RadioGroup](/docs/radio-group/) to pick a value rather than switch panels, and [NavLink](/docs/nav-link/) for items that go to other pages.

```tsx
<Tabs defaultValue="overview">
  <TabsList aria-label="Project sections">
    <TabsTrigger value="overview">Overview</TabsTrigger>
    <TabsTrigger value="activity">Activity</TabsTrigger>
  </TabsList>
  <TabsContent value="overview">Project details</TabsContent>
  <TabsContent value="activity">Recent changes</TabsContent>
</Tabs>
```

## State

Use `defaultValue`, or `value` with `onValueChange`. One is required, and passing both throws. Values are strings, and Tabs always has a selected tab. `onValueChange` fires only for user requests; a controlled owner can refuse one by keeping `value`. Do not switch owners after mount.

```tsx
const [section, setSection] = useState('general')

<Tabs value={section} onValueChange={setSection}>…</Tabs>
```

Hidden panels unmount their children. Set `keepMounted` on a panel to keep its state and let its fields submit while hidden, as the workspace form does. Tabs submits no value itself, and form reset leaves the selected tab unchanged.

`useTabs()` returns the current `TabsState` inside Tabs and `null` outside.

## Accessibility

TabsList has `role="tablist"` and needs `aria-label` or `aria-labelledby`. Each trigger is a native `button` with `role="tab"`, named by its text. Panels have `role="tabpanel"` and are labelled by their tab. Tabs generates the IDs, and they match between server and client.

| Key                      | Behavior                                                            |
| ------------------------ | ------------------------------------------------------------------- |
| Tab                      | Enters the list on the selected tab; the next Tab goes to the panel |
| Arrow Right / Arrow Left | Next / previous enabled tab when horizontal; reversed in RTL        |
| Arrow Down / Arrow Up    | Next / previous enabled tab when vertical                           |
| Home / End               | First / last enabled tab                                            |
| Enter / Space            | Selects the focused tab; needed with manual activation              |

Arrows wrap unless `loop={false}`. In automatic mode, moving focus selects the tab. Disabled tabs are skipped. Panels take `tabIndex={0}`; use `-1` when the panel starts with a focusable control.

## Motion

Nothing animates. Triggers render Button with motion off, and panels switch instantly.

## Styling

Every part takes `className` and `style`, which accepts `--rad-tabs-*` variables. `components.tabs` holds theme keys; `triggerActiveBackground`, `triggerActiveColor` and `triggerActiveBorder` style the selected tab.

| Part        | `data-slot`           | Data attributes                                                                         |
| ----------- | --------------------- | --------------------------------------------------------------------------------------- |
| Tabs        | `tabs`                | `data-orientation`, `data-control-size`, `data-disabled`                                |
| TabsList    | `tabs-list`           | `data-orientation`                                                                      |
| TabsTrigger | `button tabs-trigger` | `data-selected`, `data-disabled`, `data-value`, `data-orientation`, `data-control-size` |
| TabsContent | `tabs-content`        | `data-value`, `data-orientation`                                                        |

The selected trigger has `data-selected`. Target the visible panel with `[role=tabpanel]:not([hidden])`.

## API

### Tabs

| Prop              | Type                                              | Default    |
| ----------------- | ------------------------------------------------- | ---------- |
| value             | string; controlled selection                      | None       |
| defaultValue      | string; uncontrolled initial selection            | None       |
| onValueChange     | (value: string) => void                           | None       |
| orientation       | horizontal / vertical                             | horizontal |
| activationMode    | automatic / manual                                | automatic  |
| loop              | boolean; arrows wrap at the ends                  | true       |
| disabled          | boolean; disables every tab                       | false      |
| controlSize       | small / medium / large                            | medium     |
| className / style | string / ThemeStyle                               | None       |
| Other props       | Native div props except defaultValue and onChange | Native     |

### TabsList

| Prop                         | Type                                                        | Default  |
| ---------------------------- | ----------------------------------------------------------- | -------- |
| aria-label / aria-labelledby | string; accessible name                                     | Required |
| className / style            | string / ThemeStyle                                         | None     |
| Other props                  | Native div props except role, aria-orientation and tabIndex | Native   |

### TabsTrigger

| Prop              | Type                                                                        | Default       |
| ----------------- | --------------------------------------------------------------------------- | ------------- |
| value             | string; matches a TabsContent                                               | Required      |
| disabled          | boolean                                                                     | false         |
| controlSize       | small / medium / large                                                      | From Tabs     |
| render            | (props: TabsRenderProps) => ReactElement                                    | Native button |
| className / style | string / ThemeStyle                                                         | None          |
| ref               | `Ref<HTMLButtonElement>`                                                    | None          |
| Other props       | [Button](/docs/button/) props except selection, ARIA and presentation props | Native        |

### TabsContent

| Prop              | Type                                                           | Default  |
| ----------------- | -------------------------------------------------------------- | -------- |
| value             | string; the tab this panel belongs to                          | Required |
| keepMounted       | boolean; keep children mounted while hidden                    | false    |
| tabIndex          | number                                                         | 0        |
| className / style | string / ThemeStyle                                            | None     |
| Other props       | Native div props except id, role, hidden, inert and ARIA links | Native   |

Exports: `Tabs`, `TabsList`, `TabsTrigger`, `TabsContent`, `useTabs`, `TabsProps`, `TabsListProps`, `TabsTriggerProps`, `TabsContentProps`, `TabsRenderProps`, `TabsState`.
