## Usage

Use SortableList when people set the order of a short list, such as priorities or a playlist. Use [DragAndDrop](/docs/drag-and-drop/) to move items between lists. Use [DataTable](/docs/data-table/) to sort records by a column and [ListBox](/docs/list-box/) to choose items without ordering them.

SortableList has no built-in text: pass `instructionsText` and the four announcement functions in the page's language.

```tsx
<SortableList
  aria-label="Priorities"
  defaultValue={['invoice', 'review']}
  instructionsText="Press Space to pick up, arrows to move, Space to drop, Escape to cancel."
  pickUpText={(item, index, count) => `Picked up ${item}, ${index + 1} of ${count}.`}
  moveText={(item, index, count) => `${item}, ${index + 1} of ${count}.`}
  dropText={(item, index, count) => `Dropped ${item} at ${index + 1} of ${count}.`}
  cancelText={(item, index, count) => `${item} is back at ${index + 1} of ${count}.`}
>
  <SortableListItem value="invoice">Send the invoice</SortableListItem>
  <SortableListItem value="review">Review the proposal</SortableListItem>
</SortableList>
```

## State

The value is the item values in order. Use `defaultValue`, or `value` with `onValueChange`, not both. `onValueChange` reports the new order after a drop; a controlled owner can decline it, and the item returns. Values without an item are dropped, and items missing from the value follow in source order. Item values must be unique nonempty strings, and children must be SortableListItems, or SortableList throws.

With `name`, each item submits one value in order; read them with `FormData.getAll`. Form reset restores an uncontrolled order. `disabled`, or a disabled [Field](/docs/field/), blocks moves and submits nothing.

## Accessibility

Name the list with `aria-label`, `aria-labelledby` or a group Field label. It is an ordered list; each handle is a pressed-state Button named by its item and described by `instructionsText`. Moves are announced politely; a drop in place says nothing.

| Key                       | Behavior                     |
| ------------------------- | ---------------------------- |
| Space / Enter on a handle | Pick the item up, or drop it |
| Up / Down arrows          | Move the picked-up item      |
| Home / End                | Move it to the start or end  |
| Escape                    | Cancel the move or drag      |
| Tab away                  | Drop the item where it is    |

A pointer drags from the handle, and the nearest scroller scrolls near its edges.

## Motion

Inside `MotionProvider`, items spring to their new places, and a released item glides into its slot. Reduced motion and themes with motion off snap them; `motion="off"` also skips the glide.

## Styling

| Host         | Attributes                                                        |
| ------------ | ----------------------------------------------------------------- |
| List         | `data-slot="sortable-list"`, `data-dragging`, `data-disabled`     |
| Slot         | `data-slot="sortable-list-slot"`, `li`                            |
| Item         | `data-slot="sortable-list-item"`, `data-grabbed`, `data-dragging` |
| Handle       | `data-slot="button sortable-list-handle"`, `aria-pressed`         |
| Item content | `data-slot="sortable-list-item-content"`                          |

`parts.handle` and `parts.content` style every handle and content box. A line marks the drop spot while dragging. Handles draw `grip` from [IconProvider](/docs/icon-provider/) when supplied. `--rad-sortable-list-*` variables set `item-radius`, `item-background`, `item-border-color`, `item-gap`, `marker-color`, `handle-color`, `dragging-shadow` and more.

## API

### SortableList

| Prop                                          | Type                                                                   | Default             |
| --------------------------------------------- | ---------------------------------------------------------------------- | ------------------- |
| value / defaultValue                          | `string[]`; one owner                                                  | None                |
| onValueChange                                 | `(value: string[]) => void`                                            | None                |
| instructionsText                              | string                                                                 | Required            |
| pickUpText / moveText / dropText / cancelText | `SortableListText`: `(item, index, count) => string`; zero-based index | Required            |
| handleLabel                                   | `(item: string) => string`                                             | Item content        |
| name / form                                   | string                                                                 | None                |
| disabled                                      | boolean                                                                | Field's, else false |
| gap                                           | tight / normal / airy                                                  | tight               |
| controlSize                                   | small / medium / large                                                 | medium              |
| motion                                        | inherit / off                                                          | inherit             |
| parts                                         | `{ handle?, content? }`, each `PartStyle`                              | None                |
| Other props                                   | Native `ol` props                                                      | Native              |

### SortableListItem

| Prop        | Type                          | Default   |
| ----------- | ----------------------------- | --------- |
| value       | string; unique, nonempty      | Required  |
| textValue   | string; name in announcements | Item text |
| Other props | Native div props              | Native    |

Exports `SortableList`, `SortableListItem`, `SortableListProps`, `SortableListItemProps` and `SortableListText`.
