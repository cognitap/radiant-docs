## Usage

Use [CodeBlock](/docs/code-block/) for a complete snippet and [Kbd](/docs/kbd/) for keyboard shortcuts.

## Styling

Set `components.inlineCode` in your theme to change the font size, colors, padding, or radius.

## API

`InlineCode` accepts native `<code>` props and exports `InlineCodeProps`.
