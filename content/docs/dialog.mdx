## Start with an accessible task

```tsx
<Dialog>
  <DialogTrigger>Edit profile</DialogTrigger>
  <DialogContent>
    <DialogTitle>Edit profile</DialogTitle>
    <DialogDescription>Update the details your team sees.</DialogDescription>
    <DialogClose>Done</DialogClose>
  </DialogContent>
</Dialog>
```

Dialog owns state without adding a DOM element. Content is a native `dialog`.
It opens modally by default: the page becomes inert, focus moves inside, and
closing returns focus to the opening control. `autoFocus` chooses initial focus.
Without a Title, supply `aria-label` on Content. Keep an explicit close action.

Escape and clicks outside the panel dismiss it. `closeOnEscape` and
`closeOnBackdrop` configure those policies; Content's `onCancel` can cancel
Escape. Nested modal dialogs stack; only the top layer handles Escape.

## Own state and forms

```tsx
const [open, setOpen] = useState(false)

<Dialog open={open} onOpenChange={setOpen}>
  {/* Compose trigger, content, title, description and close here. */}
</Dialog>
```

Choose controlled `open` or initial `defaultOpen`; never combine them or switch
ownership. `onOpenChange` requests a change; an owner may refuse it. Prop syncs
and no-op requests do not notify.

There is no portal or body scroll lock. An ancestor form owns fields inside
Content. A `form method="dialog"` closes natively and state follows. Ordinary
form submission does not close automatically. Validation, pending work and
persistence belong to your application.

Trigger and Close compose [Button](/docs/button/), including pending, disabled
and `render`. Forward resolved props, ref and children to one compatible button.

Content keeps a 1rem viewport margin and scrolls long content. Set
`--rad-dialog-width` in Content style for a local width.

## Add motion

```tsx
import { MotionProvider } from '@cognitap/radiant/motion/react'

;<MotionProvider>
  <Dialog>
    <DialogTrigger>Open</DialogTrigger>
    <DialogContent motion="inherit">
      <DialogTitle>Ready when you are.</DialogTitle>
      <DialogDescription>Native behavior stays immediate.</DialogDescription>
      <DialogClose>Close</DialogClose>
    </DialogContent>
  </Dialog>
</MotionProvider>
```

The provider springs entry and composed Button presses. Content `motion="off"`
disables its presentation; theme off and live reduced motion settle everything.
Native close, modal semantics and focus never wait for an animation.

A visual exit copy is inert, unnamed and hidden from assistive technology.
Nested dialogs, media, embeds, canvas, custom elements and trees over 500
descendants skip it. Copies expire within two seconds. Reopening removes the
copy and retargets the spring. See [motion setup](/docs/foundations/motion/).

## Named parts and targets

| Component         | Host, style/ref target and identity                                                            |
| ----------------- | ---------------------------------------------------------------------------------------------- |
| Dialog            | Logical state owner; no DOM host or root style/ref                                             |
| DialogTrigger     | Native button; `button dialog-trigger`; sets `aria-haspopup`, `aria-expanded`, `aria-controls` |
| DialogContent     | Native `dialog`; `dialog`; `data-state="open" \| "closed"`                                     |
| DialogTitle       | `h2`; `dialog-title`                                                                           |
| DialogDescription | `p`; `dialog-description`                                                                      |
| DialogClose       | Native button; `button dialog-close`                                                           |

Identities are `data-slot` tokens; match composed ones with `[data-slot~="dialog-trigger"]`.
Content connects generated title/description IDs. Keep one title/description pair per content,
and do not overwrite their IDs. `useDialog()` returns the owner state, or
`null` outside a Dialog.

## Public props

| Dialog prop            | Purpose / default                                                                 |
| ---------------------- | --------------------------------------------------------------------------------- |
| `open` / `defaultOpen` | Controlled state or initial local state; initially closed                         |
| `onOpenChange`         | Receives a requested next boolean state                                           |
| `modal`                | Native `showModal()` by default; `false` uses `show()` and leaves the page usable |
| `closeOnBackdrop`      | Modal backdrop dismissal; defaults to `true`                                      |
| `closeOnEscape`        | Modal Escape dismissal; defaults to `true`                                        |
| `children`             | Compose the named parts under this owner                                          |
| `DialogContent`        | Native dialog props, styles and ref, except owner-controlled `open`               |
| `onCancel`             | On DialogContent; `preventDefault` cancels native Escape dismissal                |
| `onClose`              | On DialogContent; observes the native close event                                 |
| `motion` on Content    | `inherit` (default) or `off`; matches the shared transition convention            |
| Title / Description    | Native host props, styles and refs                                                |
| Trigger / Close        | `ButtonProps`, including `render`                                                 |

Each part's prop type and `DialogRenderProps` are exported.
