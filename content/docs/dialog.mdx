## Open, review and dismiss

Dialog owns open state and the native dialog lifecycle. By default it opens modally: the rest of the page becomes inert
and focus moves inside. Closing returns focus to the opening control. An element
with `autoFocus` takes initial focus instead. Give every dialog a title,
description and explicit close action. Without DialogTitle, pass `aria-label`
on DialogContent.

Escape or a click outside the dialog's border box dismisses a modal dialog;
keep an explicit close action even when you turn those off. A nonmodal dialog
leaves the page usable. Changing `modal` while open switches between
`showModal()` and `show()` without requesting a new open state.

A `<form method="dialog">` inside the content closes the dialog, and React state
follows. Nested modal dialogs stack; Escape closes the top one. A parent ignores
close and cancel events that bubble up from a nested dialog.

There is no portal. The panel stays where it renders, so an ancestor `form` owns
fields inside it. Radiant does not lock body scrolling.

## Button composition and state ownership

DialogTrigger and DialogClose compose [Button](/docs/button/) and accept its
props, including `render`. Do not nest another Button around the resolved result or substitute
an anchor for an action.

Do not pass both `open` and `defaultOpen`, or switch ownership during a mount.

The open dialog keeps a 1rem viewport margin and a maximum height of
`min(40rem, 100dvh - 2rem)`; its contents scroll. Set `--rad-dialog-width` in
`DialogContent.style` for a local width. Use the `open:` variant for open-only
classes. The dialog inherits its ThemeScope's theme.

## Named parts and targets

| Component         | Host, style/ref target and identity                                                            |
| ----------------- | ---------------------------------------------------------------------------------------------- |
| Dialog            | Logical state owner; no DOM host or root style/ref                                             |
| DialogTrigger     | Native button; `button dialog-trigger`; sets `aria-haspopup`, `aria-expanded`, `aria-controls` |
| DialogContent     | Native `dialog`; `dialog`; `data-state="open" \| "closed"`                                     |
| DialogTitle       | `h2`; `dialog-title`                                                                           |
| DialogDescription | `p`; `dialog-description`                                                                      |
| DialogClose       | Native button; `button dialog-close`                                                           |

Identities are `data-slot` tokens; match composed ones with `[data-slot~="dialog-trigger"]`.
Content connects generated title/description IDs. Keep one title/description pair per content,
and do not overwrite their IDs. `useDialog()` returns the owner state, or
`null` outside a Dialog.

## Public props

| Dialog prop            | Purpose / default                                                   |
| ---------------------- | ------------------------------------------------------------------- |
| `open` / `defaultOpen` | Controlled state or initial local state; initially closed           |
| `onOpenChange`         | Receives a requested next boolean state                             |
| `modal`                | Uses native `showModal()` when true (default), `show()` when false  |
| `closeOnBackdrop`      | Modal backdrop dismissal; defaults to `true`                        |
| `closeOnEscape`        | Modal Escape dismissal; defaults to `true`                          |
| `children`             | Compose the named parts under this owner                            |
| `DialogContent`        | Native dialog props, styles and ref, except owner-controlled `open` |
| `onCancel`             | On DialogContent; `preventDefault` cancels native Escape dismissal  |
| `onClose`              | On DialogContent; observes the native close event                   |
| Title / Description    | Native host props, styles and refs                                  |
| Trigger / Close        | `ButtonProps`, including `render`                                   |

Each part's prop type and `DialogRenderProps` are exported.
