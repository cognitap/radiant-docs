## Usage

Use Dialog for a short task that needs the user's attention before they return to the page. Use [AlertDialog](/docs/alert-dialog/) to confirm or cancel a consequential action, [Drawer](/docs/drawer/) for a panel at a screen edge, [Command](/docs/command/) for a search-and-run palette and [Popover](/docs/popover/) for small content that leaves the page usable.

```tsx
<Dialog>
  <DialogTrigger>Edit profile</DialogTrigger>
  <DialogContent>
    <DialogTitle>Edit profile</DialogTitle>
    <DialogDescription>Update the details your team sees.</DialogDescription>
    <DialogClose>Done</DialogClose>
  </DialogContent>
</Dialog>
```

## State

Pass `open` with `onOpenChange` to own the state, or `defaultOpen` to let Dialog own it. Mixing them is a type error. `onOpenChange` is a request: a controlled owner can decline it, and the dialog stays open, even after native Escape.

DialogContent is a native `<dialog>`. A `<form method="dialog">` inside it closes the dialog, and Dialog reports `onOpenChange(false)`. Other forms submit normally and stay open; close them yourself after saving. A dialog inside an ancestor form keeps its fields in that form. DialogTrigger and DialogClose default to `type="button"`, so they never submit.

## Accessibility

DialogContent is named by DialogTitle through `aria-labelledby` and described by DialogDescription through `aria-describedby`. Always render a DialogTitle, or pass `aria-label` to DialogContent. DialogTrigger sets `aria-haspopup="dialog"`, `aria-expanded` and `aria-controls`.

A modal dialog uses `showModal()`. The browser makes the rest of the page inert and moves focus inside, respecting `autoFocus`. Focus returns to the opener on close.

| Key                            | Behavior                                                                         |
| ------------------------------ | -------------------------------------------------------------------------------- |
| Enter / Space on DialogTrigger | Opens the dialog                                                                 |
| Tab / Shift+Tab                | Moves focus within a modal dialog                                                |
| Escape                         | Closes the topmost modal dialog unless `closeOnEscape={false}`; never its parent |
| Enter / Space on DialogClose   | Closes the dialog                                                                |

## Motion

Inside a [`MotionProvider`](/docs/foundations/motion/), DialogContent springs open and closed. Closing and focus return never wait for the exit. Turn it off with `motion="off"` on DialogContent, globally with theme `motion.mode: 'off'`, or through the reduced-motion preference.

## Styling

`className` and `style` target each part's own element. DialogContent carries `data-state="open"` or `"closed"`. The panel's height is capped at `min(40rem, 100dvh - 2rem)`, and longer content scrolls.

| Part              | `data-slot`             |
| ----------------- | ----------------------- |
| DialogContent     | `dialog`                |
| DialogTitle       | `dialog-title`          |
| DialogDescription | `dialog-description`    |
| DialogTrigger     | `button dialog-trigger` |
| DialogClose       | `button dialog-close`   |

Set `--rad-dialog-width` (default `32rem`) on DialogContent for a local width. Other variables cover gap, padding, radius, corner shape, border, background, backdrop filter, color, shadow, backdrop, focus ring, title size and weight, and description color and size, each as `--rad-dialog-*`.

## API

### Dialog

| Prop            | Type                    | Default | Description                                      |
| --------------- | ----------------------- | ------- | ------------------------------------------------ |
| open            | boolean                 | None    | Controlled open state                            |
| defaultOpen     | boolean                 | false   | Initial state when uncontrolled                  |
| onOpenChange    | (open: boolean) => void | None    | Requested change; a controlled owner may decline |
| modal           | boolean                 | true    | `false` uses `show()` and leaves the page active |
| closeOnBackdrop | boolean                 | true    | Modal only; a click outside closes it            |
| closeOnEscape   | boolean                 | true    | Modal only; Escape closes it                     |
| children        | ReactNode               | None    | Parts                                            |

### DialogTrigger

| Prop                         | Type                                       | Default         |
| ---------------------------- | ------------------------------------------ | --------------- |
| variant / tone / controlSize | [Button](/docs/button/) presentation       | Button defaults |
| pending / disabled           | boolean                                    | false           |
| type                         | button / submit / reset                    | button          |
| render                       | (props: DialogRenderProps) => ReactElement | Native button   |
| ref                          | `Ref<HTMLButtonElement>`                   | None            |
| Other props                  | Native button props                        | Native          |

Triggers do not accept `pressed`, `defaultPressed`, `onPressedChange` or `aria-pressed`.

### DialogContent

| Prop        | Type                                                | Default |
| ----------- | --------------------------------------------------- | ------- |
| motion      | inherit / off                                       | inherit |
| style       | ThemeStyle; accepts `--rad-dialog-*`                | None    |
| onCancel    | Native cancel event; `preventDefault` keeps it open | None    |
| onClose     | Native close event                                  | None    |
| ref         | `Ref<HTMLDialogElement>`                            | None    |
| Other props | Native dialog props except `open`                   | Native  |

### DialogTitle

| Prop              | Type                                   | Default |
| ----------------- | -------------------------------------- | ------- |
| className / style | string / ThemeStyle                    | None    |
| Other props       | Native `h2` props; the id is generated | Native  |

### DialogDescription

| Prop              | Type                                  | Default |
| ----------------- | ------------------------------------- | ------- |
| className / style | string / ThemeStyle                   | None    |
| Other props       | Native `p` props; the id is generated | Native  |

### DialogClose

Same props as DialogTrigger, without pressed state. Closes the dialog on click.

### useDialog

Returns `DialogState` inside a Dialog, or `null` outside one. The state has `open`, `setOpen`, `contentId`, `titleId`, `descriptionId`, `modal`, `closeOnBackdrop`, `closeOnEscape` and `controlled`.

Exports each part's Props type, `DialogState` and `DialogRenderProps`.
