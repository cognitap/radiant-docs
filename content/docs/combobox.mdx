## Usage

Use Combobox for one searchable choice. Use [MultiSelect](/docs/multi-select/) for several known choices, [Select](/docs/select/) without text search, or [TagsInput](/docs/tags-input/) for free text.

```tsx
<Field
  label="Destination"
  required
>
  <Combobox
    items={cities}
    name="city"
    defaultValue="budapest"
  />
</Field>
```

Items need distinct string keys; rich labels require plain `textValue`. Local filtering ignores case. Supply a custom filter or null for application-filtered results.

## State

Selection, query and expansion independently choose controlled `value`, `query`, `open`, or their default counterparts. Callbacks request changes; owners may refuse. Ownership and multiple mode stay fixed per mount. Prop synchronization and no-op requests do not notify.

Single mode uses string or null. Multiple mode uses string arrays, toggles membership and retains the open popup. `selectedItem` or multiple `selectedItems` supplies absent labels. Chosen labels survive result replacement. Applications own fetching, cancellation and ordering; results never select themselves.

Committed keys submit under `name`, repeatedly in multiple mode. Query never submits. An empty string is a valid required key. Disabled fields submit nothing; root readOnly protects the whole field and retains values. Native reset silently restores uncontrolled selection/query; controlled owners reset themselves.

`useCombobox()` reads scalar state. `useCombobox({multiple:true})` reads array state. Both expose value/query/open/disabled and setValue/setQuery/setOpen requests, returning null outside their matching mode.

## Accessibility

[Field](/docs/field/) supplies naming and validation. Focus stays in the input with a highlighted listbox option. Loading/error hide unavailable options and supply polite status.

| Key                              | Behavior                                           |
| -------------------------------- | -------------------------------------------------- |
| Up / Down                        | Open and highlight enabled results                 |
| Enter                            | Commit or toggle highlighted value                 |
| Tab / blur / Escape              | Discard search and dismiss                         |
| Escape while closed              | Clear single selection; retain multiple selections |
| Empty Backspace in multiple mode | Remove last value                                  |
| Home / End                       | Native text editing                                |

## Motion

[MotionProvider](/docs/foundations/motion/) adds popup opacity; off and reduced motion remove it. Closing remains immediate.

## Styling

Root/Portal have no host. Input props/ref reach input; Content/Item/Status/Tags reach divs. Trigger/Clear are real Buttons. Parts retain `combobox-*`; multiple mode adds `multi-select-*`. Use component Combobox tokens and preserve owned ARIA, placement and focus.
