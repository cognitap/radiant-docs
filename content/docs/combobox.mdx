## Usage

Use Combobox when people type to find a choice. Search text filters the list but never becomes the value. Choose something else when:

- [Select](/docs/select/): the list is short and needs no typing.
- [Autocomplete](/docs/autocomplete/): any text is allowed and suggestions only help.
- [MultiSelect](/docs/multi-select/): people pick several values; it matches `type="multiple"` with its own part names.

```tsx
<Field label="Destination">
  <Combobox
    name="city"
    defaultValue="budapest"
    items={[
      { value: 'budapest', label: 'Budapest' },
      { value: 'vienna', label: 'Vienna' }
    ]}
  />
</Field>
```

Without children, Combobox renders an input, trigger, clear button and a listbox of `items`. Give rich labels a plain `textValue`.

## State

| State               | Controlled | Uncontrolled   | Callback                               | Empty   |
| ------------------- | ---------- | -------------- | -------------------------------------- | ------- |
| Selection, single   | `value`    | `defaultValue` | `onValueChange(value: string \| null)` | `null`  |
| Selection, multiple | `value`    | `defaultValue` | `onValueChange(value: string[])`       | `[]`    |
| Search              | `query`    | `defaultQuery` | `onQueryChange(query: string)`         | `''`    |
| Popup               | `open`     | `defaultOpen`  | `onOpenChange(open: boolean)`          | `false` |

Passing both props of a pair, or changing the owner or `type` during a mount, throws; remount with a new `key`. Prop changes fire no callback.

Single mode submits the selected key under `name`, or `''` when empty. Multiple mode submits one `name` entry per key. `required` needs a selection. Native reset restores uncontrolled selection and search silently. `disabled` leaves the value out of the form; `readOnly` keeps it submitted but blocks edits.

For server results, pass `filter={null}`, `loading`, `errorText` and `selectedItem` when the selection is outside the results.

## Accessibility

The input is a `combobox` that controls a `listbox` of `option` items, with `aria-multiselectable` in multiple mode. Loading, empty and error text sit in a `status` region outside the list. Name the input with [Field](/docs/field/) or `aria-label` on ComboboxInput. Pass `aria-invalid` to Combobox to mark it invalid outside Field.

| Key                       | Behavior                                                                  |
| ------------------------- | ------------------------------------------------------------------------- |
| Typing                    | Filter and open; never commits                                            |
| Arrow Down / Up           | Open and move the highlight past disabled items                           |
| Alt+Arrow Down / Up       | Open or close without moving the highlight                                |
| Enter                     | Commit the highlighted item; multiple mode toggles and stays open         |
| Escape                    | Close and discard the search; with the popup closed, clear a single value |
| Tab                       | Close and move on without committing                                      |
| Backspace on empty search | Remove the last value in multiple mode                                    |

Focus stays on the input. ComboboxTrigger is not a Tab stop; ComboboxClear is one only in multiple mode.

## Motion

Inside [MotionProvider](/docs/foundations/motion/), ComboboxContent fades in; closing is immediate. Set `motion="off"` on ComboboxContent to turn it off. Reduced motion shows it at full opacity.

## Styling

Every hosted part takes `className`, `style` and `ref`. Multiple mode adds `multi-select-*` to each slot.

| Part            | Attributes                                                                                      |
| --------------- | ----------------------------------------------------------------------------------------------- |
| ComboboxInput   | `data-slot="combobox-input"`, `data-control-size`, `data-invalid`                               |
| ComboboxTrigger | `data-slot="button combobox-trigger"`                                                           |
| ComboboxClear   | `data-slot="button combobox-clear"`                                                             |
| ComboboxContent | `data-slot="combobox-content"`, `data-state="open \| closed"`, `data-motion`                    |
| ComboboxItem    | `data-slot="combobox-item"`, `data-value`, `data-highlighted`, `data-selected`, `data-disabled` |
| ComboboxStatus  | `data-slot="combobox-status"`                                                                   |
| ComboboxTags    | `data-slot="combobox-tags"`                                                                     |

Theme with `--rad-combobox-*` tokens, such as `--rad-combobox-radius` on the input `style`.

## API

### Combobox

| Prop                           | Type                                                     | Default                     |
| ------------------------------ | -------------------------------------------------------- | --------------------------- |
| items                          | `readonly ComboboxOption[]`; distinct values             | Required                    |
| type                           | single / multiple; fixed for the mount                   | single                      |
| value / defaultValue           | `string \| null`, or `string[]` when multiple; one owner | None / `null` or `[]`       |
| onValueChange                  | `(value) => void`                                        | None                        |
| selectedItem / selectedItems   | `ComboboxOption` / `readonly ComboboxOption[]`           | None                        |
| query / defaultQuery           | string; one owner                                        | None / `''`                 |
| onQueryChange                  | `(query: string) => void`                                | None                        |
| open / defaultOpen             | boolean; one owner                                       | None / false                |
| onOpenChange                   | `(open: boolean) => void`                                | None                        |
| filter                         | `((item, query) => boolean) \| null`                     | Case-insensitive text match |
| loading                        | boolean; hides results                                   | false                       |
| loadingText                    | string                                                   | `'Loading results…'`        |
| emptyText                      | ReactNode                                                | `'No results found.'`       |
| errorText                      | ReactNode; hides results                                 | None                        |
| name / form                    | string                                                   | None                        |
| disabled / readOnly / required | boolean                                                  | Field's, else false         |
| aria-invalid                   | Native; forwarded to the input                           | Field's                     |
| controlSize                    | small / medium / large                                   | medium                      |
| children                       | ReactNode                                                | Default parts               |

### ComboboxInput

| Prop         | Type                                                                                            | Default |
| ------------ | ----------------------------------------------------------------------------------------------- | ------- |
| aria-invalid | Native; overrides the root                                                                      | Root's  |
| style        | ThemeStyle                                                                                      | None    |
| Other props  | Input props except value, defaultValue, name, form, type, role, disabled, required, ARIA wiring | Native  |

### ComboboxTrigger and ComboboxClear

| Prop        | Type                                                                                                                                          | Default                                |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| render      | `(props: ComboboxRenderProps) => ReactElement`                                                                                                | Native button                          |
| children    | ReactNode; replaces the icon                                                                                                                  | Chevron / cross                        |
| aria-label  | string                                                                                                                                        | `'Show options'` / `'Clear selection'` |
| Other props | Button props except type, disabled, pending, variant, tone, controlSize, iconOnly, fullWidth, motion, tabIndex, ARIA wiring and pressed props | Native                                 |

ComboboxClear hides when nothing is selected.

### ComboboxPortal

| Prop     | Type      | Default |
| -------- | --------- | ------- |
| children | ReactNode | None    |

Renders next to the input; the popup uses the top layer.

### ComboboxContent

| Prop             | Type                               | Default                    |
| ---------------- | ---------------------------------- | -------------------------- |
| sideOffset       | number; gap from the input in px   | 4                          |
| collisionPadding | number; viewport margin in px      | 8                          |
| motion           | inherit / off                      | inherit                    |
| aria-label       | string; listbox name               | Input's label              |
| children         | ReactNode                          | An item per visible result |
| Other props      | div props except popover, role, id | Native                     |

### ComboboxItem

| Prop        | Type                                | Default         |
| ----------- | ----------------------------------- | --------------- |
| value       | string; must exist in `items`       | Required        |
| children    | ReactNode                           | Label and check |
| Other props | div props except id, role, tabIndex | Native          |

### ComboboxStatus

| Prop        | Type                  | Default     |
| ----------- | --------------------- | ----------- |
| children    | ReactNode             | Root status |
| Other props | div props except role | Native      |

### ComboboxTags

| Prop        | Type                      | Default       |
| ----------- | ------------------------- | ------------- |
| Other props | div props except children | Selected Tags |

Throws outside `type="multiple"`.

`useCombobox()` returns `{ value, query, open, disabled, setValue, setQuery, setOpen }` inside a single Combobox; `useCombobox({ type: 'multiple' })` does the same for a multiple one. Both return `null` elsewhere.

Exports `ComboboxProps`, `ComboboxMultipleProps`, `ComboboxOption`, `ComboboxState`, `ComboboxMultipleState`, `ComboboxRenderProps`, `ComboboxInputProps`, `ComboboxTriggerProps`, `ComboboxClearProps`, `ComboboxContentProps`, `ComboboxItemProps`, `ComboboxStatusProps` and `ComboboxTagsProps`.
