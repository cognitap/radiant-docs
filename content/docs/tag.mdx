## Usage

Use Tag for a filter, recipient or label that people can remove. Use [Badge](/docs/badge/) when the value is not removable, and [TagsInput](/docs/tags-input/) when people also type new values.

```tsx
<Tag
  removeLabel="Remove Research filter"
  onRemove={() => remove('research')}
>
  Research
</Tag>
```

`tone` only sets color, as on Badge: `neutral` (default) for information, `accent` for success or confirmation, `warning` for a problem the user can still avoid, and `danger` for a failure. The remove Button uses the same tone.

## State

Tag holds no state. The application owns the list, removes the value after `onRemove` and gives mapped Tags stable keys. Tag contributes no form value.

## Accessibility

The root is a passive `span`. The remove control is a native Button, and `removeLabel` is its accessible name. The visible content is not part of that name, so `removeLabel` must say what is removed, such as "Remove Ana Lima from reviewers". Keep labels distinct when several Tags sit together. An empty `removeLabel` throws.

| Key             | Behavior                         |
| --------------- | -------------------------------- |
| Tab / Shift+Tab | Visit each enabled remove Button |
| Enter / Space   | Call `onRemove`                  |

Disabled and pending Buttons do not call `onRemove`. After a Tag is removed, the application chooses where focus goes and announces the result when it matters.

## Motion

Tag has no motion. The remove Button uses `motion="off"`, and insertion or removal is not animated.

## Styling

| Part   | Element  | data-slot    | Data attributes         |
| ------ | -------- | ------------ | ----------------------- |
| Tag    | `span`   | `badge tag`  | `data-tone`             |
| Remove | `button` | `tag-remove` | Button's own attributes |

`className`, `style` and the ref reach the root span. `parts.remove` sets the remove Button's className and style. `components.tag.gap` (`--rad-tag-gap`, default `0.25rem`) sets the space between content and Button; other appearance follows [Badge](/docs/badge/).

## API

| Tag prop          | Type                                             | Default        |
| ----------------- | ------------------------------------------------ | -------------- |
| children          | ReactNode                                        | Required       |
| removeLabel       | string                                           | Required       |
| onRemove          | `(event: MouseEvent<HTMLButtonElement>) => void` | Required       |
| tone              | neutral / accent / warning / danger              | neutral        |
| disabled          | boolean                                          | false          |
| pending           | boolean                                          | false          |
| parts             | `{ remove?: { className, style } }`              | None           |
| className / style | string / ThemeStyle                              | None           |
| ref               | `Ref<HTMLSpanElement>`                           | None           |
| Other props       | Badge props except decorative                    | Badge defaults |

Exports: `Tag`; type `TagProps`.
