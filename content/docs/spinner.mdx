## Usage

Use Spinner for a short wait of unknown length. Use [Progress](/docs/progress/) when the amount of work is known, and [Skeleton](/docs/skeleton/) when the loading content's layout is known. For a running action, use [Button](/docs/button/)'s `pending`, which renders Spinner for you.

```tsx
<section aria-busy={loading}>
  {loading ? (
    <>
      <Spinner />
      <span>Loading account…</span>
    </>
  ) : (
    <AccountDetails />
  )}
</section>
```

## State

Spinner has no state and contributes no form value. The application decides when work starts, sets `aria-busy` on the region that is changing, and removes the spinner when the work finishes.

## Accessibility

Without `label`, Spinner is decorative: the SVG gets `aria-hidden="true"` and no role. Put visible loading text beside it. With `label`, it becomes `role="img"` named by that string. A blank label throws.

Spinner is never a live region and never announces on its own. Announce completion or failure through a status message such as [Alert](/docs/alert/), outside the busy region. A pending Button renders a decorative spinner and sets `aria-busy` on itself, so its own text stays the only name; see [Button](/docs/button/).

| Key             | Behavior                                |
| --------------- | --------------------------------------- |
| Tab / Shift+Tab | Skip the spinner; it is never focusable |

## Motion

The SVG rotates once per `--rad-spinner-duration`, `1s` by default. System reduced motion, `motion="off"` and a theme with motion off all stop the rotation and leave a static arc. `data-motion` is `off` for the prop or theme setting; it does not reflect system reduced motion.

## Styling

The root SVG has `data-slot="spinner"`, `data-control-size` and `data-motion`, and takes `className`, `style` and `ref`. `parts.track` and `parts.indicator` style the `spinner-track` circle and `spinner-indicator` arc. Forced colors draw both with `CanvasText`.

`components.spinner` or local variables set `--rad-spinner-size` (with `-small` and `-large`), `-stroke-width`, `-color`, `-duration` and `-track-opacity`.

## API

### Spinner

| Prop        | Type                                                                          | Default         |
| ----------- | ----------------------------------------------------------------------------- | --------------- |
| label       | string; names a standalone spinner                                            | None            |
| controlSize | small / medium / large                                                        | medium          |
| motion      | inherit / off                                                                 | inherit         |
| parts       | `{ track?: PartStyle; indicator?: PartStyle }`                                | None            |
| className   | string                                                                        | None            |
| style       | ThemeStyle, including `--rad-spinner-*`                                       | None            |
| data-slot   | Extra tokens after `spinner`                                                  | spinner         |
| ref         | `Ref<SVGSVGElement>`                                                          | None            |
| Other props | Native SVG props except role, ARIA naming, `tabIndex`, `viewBox` and children | Native defaults |

Exports: `Spinner`, `SpinnerProps`.
