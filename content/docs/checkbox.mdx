## Usage

Use [CheckboxGroup](/docs/checkbox-group/) for related options that share a value array. Use [Switch](/docs/switch/) for a setting that takes effect immediately.

## State

Use `defaultChecked` for the initial state or pass `checked` with `onChange` and read `event.currentTarget.checked`. Keep that choice until remount.

Use `indeterminate` for a partially selected group. The browser clears the mixed mark on activation, so derive it from the group’s selection.

An enabled, checked box submits its `name` and `value`. The default value is `on`. Form reset restores `defaultChecked`.

## Accessibility

Give each checkbox a `label`, a [Field](/docs/field/) label, `aria-label` or `aria-labelledby`. Press Space to toggle a focused checkbox. Assistive technology reports the indeterminate state as mixed.

## Styling

The checked state fills an inset square with the theme accent. Use `parts.wrapper`, `parts.label` and `parts.indicator` to style the row, text and marks. See [IconProvider](/docs/icon-provider/) for custom marks and [focus outlines](/docs/foundations/theming/#focus-outlines) for focus and error colors.

## API

Checkbox accepts native checkbox attributes and events.

| Prop                        | Purpose                                              |
| --------------------------- | ---------------------------------------------------- |
| `controlSize`               | `small`, `medium` (default), or `large`.             |
| `required`, `disabled`      | Inherit from Field.                                  |
| `className`, `style`, `ref` | Target the native input with `data-slot="checkbox"`. |
