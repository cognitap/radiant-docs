## Label a choice

```tsx
<Checkbox
  label="Email me updates"
  name="updates"
  value="email"
  defaultChecked
/>
```

Checkbox renders a native `input type="checkbox"`. Its decorative SVGs are
hidden from assistive technology. A convenience `label` makes the wrapper a
clickable label. For one [Field](/docs/field/)-wrapped checkbox, omit that prop
and let Field supply the accessible name:

```tsx
<Field
  label="Accept the terms"
  required
  error={error}
>
  <Checkbox
    name="terms"
    value="accepted"
  />
</Field>
```

Keep the actual input focusable and its focus ring visible.

## Selection and submission

`checked` is boolean selection. `value` is the payload submitted under `name`.
Unchecked and disabled checkboxes contribute no entry to FormData; omitting
`value` uses the native payload `on`. Disabled blocks activation.

Choose `defaultChecked` or `checked` with `onChange` for the entire mount.
Read `event.target.checked` for selection, `event.target.value` for data.

```tsx
const [enabled, setEnabled] = useState(false)
<Checkbox label="Enable exports" checked={enabled}
  onChange={event => setEnabled(event.target.checked)} />
```

Native reset restores an uncontrolled default. Reset controlled values and
validation in your form's `onReset`.

## Mixed selection

Derive `indeterminate` from your selected children. It sets the native DOM
property after mount; it is not a third checked value or submitted payload.
Recompute it after reset. Server HTML cannot express that property.

A select-all parent needs no `name`. Read named children with
`new FormData(form)` and `getAll('permissions')`. Exclude disabled choices from
select-all calculations.

A Field group renders a fieldset/legend. Give every option its own label.
Required on a group does not require every checkbox: the form owns rules such
as “choose at least one”. Field supplies inherited disabled/error relationships.

## Indicator motion

The first example's local `CheckboxFeedback` adapter uses public `useSpring`
and `parts.indicator` to animate the decorative mark. Selection and form data
update immediately. Theme motion off, live reduced motion and disabled changes
settle feedback. Indicator class/style customization takes ownership and opts
out of this example's spring. Root input styles pass through unchanged.

Copy the source adapter; Checkbox itself needs no motion prop. See

## Props and styling

Root `className`, typed `style`, native props and `ref` target the
`HTMLInputElement`. Keep `appearance-none` to avoid duplicate native glyphs.
`CheckboxProps` is exported.

| Prop                         | Purpose / default                                               |
| ---------------------------- | --------------------------------------------------------------- |
| `checked` / `defaultChecked` | Controlled boolean or browser-owned initial selection           |
| `indeterminate`              | Mixed presentation; default `false`                             |
| `label`                      | Optional convenience label; otherwise supply an accessible name |
| `onChange`, `onBlur`         | Native events                                                   |
| `name`, `value`, `form`      | Native data name, payload and form association                  |
| `required`, `disabled`       | Native state, also inherited from Field                         |
| `controlSize`                | `small`, `medium` (default), `large`                            |
| `parts`                      | Wrapper, label and indicator class/style hooks                  |
| `className`, `style`, `ref`  | Actual input customization / ref                                |
| Other native props           | Input attributes/events except fixed `type`                     |

| Hook              | Target / `data-slot`                                  |
| ----------------- | ----------------------------------------------------- |
| Root              | Input; `checkbox`, `data-control-size`, invalid state |
| `parts.wrapper`   | Label or unlabeled span; `checkbox-wrapper`           |
| `parts.label`     | Convenience text; `checkbox-label`                    |
| `parts.indicator` | Decorative SVGs; `checkbox-indicator`                 |
