## Usage

Use Checkbox for an independent yes/no choice or one option in a checklist. Use [CheckboxGroup](/docs/checkbox-group/) for a list with select-all and a `string[]` value, [Switch](/docs/switch/) for a setting that applies immediately, and [RadioGroup](/docs/radio-group/) for one choice out of several.

```tsx
<Checkbox
  label="Email me updates"
  name="updates"
  value="email"
  defaultChecked
/>
```

## State

Use `defaultChecked` for an uncontrolled checkbox, or `checked` with `onChange` and read `event.target.checked`. Choose one owner per mount; passing both, or switching owner, throws.

`indeterminate` shows a mixed mark for a select-all parent. It is separate from `checked`, never submitted, and the browser clears it when the user toggles, so derive it from the children, as the permissions example does.

A checked box submits `name=value`, with `value` defaulting to `on`. An unchecked or disabled box submits nothing. Read several with `FormData.getAll(name)`. Reset restores `defaultChecked`; a controlled checkbox keeps its current `checked`, so reset your state in `onReset`. `required` uses native validation and `form` links an outside form.

Checkbox does not accept `readOnly`; use `disabled`, or show the value as text.

## Accessibility

Checkbox renders a native `input type="checkbox"`. The browser reports `aria-checked="mixed"` while it is indeterminate. Name it with `label`, a [Field](/docs/field/) label, `aria-label` or `aria-labelledby`. Inside Field it takes Field's id, disabled, required, invalid state and description. The check and dash icons are hidden from assistive technology.

| Key             | Behavior                      |
| --------------- | ----------------------------- |
| Tab / Shift+Tab | Move focus to or from the box |
| Space           | Toggle checked                |

## Motion

Checkbox has no animation; the mark swaps instantly. The permissions example's `CheckboxFeedback` adapter springs `parts.indicator` with `useSpring`. Theme motion `mode: 'off'` and reduced motion settle it. See [motion setup](/docs/foundations/motion/).

## Styling

`className`, `style`, `ref` and native props target the input. It carries `data-slot="checkbox"`, `data-control-size`, and `data-invalid` when invalid. Set `--rad-checkbox-*` variables in `style` or a theme. Keep the focus ring visible.

| Part              | Element                                     | `data-slot`          |
| ----------------- | ------------------------------------------- | -------------------- |
| `parts.wrapper`   | The `<label>` row with `label`, else a span | `checkbox-wrapper`   |
| `parts.label`     | Label text                                  | `checkbox-label`     |
| `parts.indicator` | Check and dash icons                        | `checkbox-indicator` |

## API

| Checkbox prop       | Type                                          | Default   |
| ------------------- | --------------------------------------------- | --------- |
| checked             | boolean; pair with onChange                   | None      |
| defaultChecked      | boolean; uncontrolled start and reset value   | false     |
| onChange            | `ChangeEventHandler<HTMLInputElement>`        | None      |
| indeterminate       | boolean; mixed mark, not submitted            | false     |
| label               | ReactNode; omit when Field supplies it        | None      |
| controlSize         | small / medium / large                        | medium    |
| name / value        | string; submitted when checked                | None / on |
| form                | string; form id                               | None      |
| required / disabled | boolean; disabled is not submitted            | false     |
| aria-invalid        | boolean / 'true' / 'false'; sets data-invalid | None      |
| className / style   | string / ThemeStyle                           | None      |
| parts               | wrapper / label / indicator PartStyle         | None      |
| ref                 | `Ref<HTMLInputElement>`                       | None      |
| Native attributes   | Input attributes and events; type is fixed    | Native    |

Exports `Checkbox` and `CheckboxProps`.
